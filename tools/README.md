# Website maintenance

| Content | Source |
|---|---|
| People and portraits | `niil/content/members.json` |
| Research catalog and details | `niil/content/projects.json`, `project-locales.json`, `projects/` |
| Publications, photos, research outputs, application guide | Corresponding files under `niil/content/` |
| Stable member/project URLs | `niil/content/routes.json` |
| Course publication | Pinned `tools/course-source.json`; edit in the separate `courses` repository |
| Retired lab URLs | `tools/legacy-routes.json`; one browser resolver on `404.html` |
| Lab output ownership | `tools/site-output.json`; regenerated by `site_layout.py` |

Build with `python3 tools/build_niil.py` (Python, Pandoc and Node.js for resolver validation). It reproduces the pinned course import,
builds Korean and English lab pages, prunes obsolete owned HTML, generates
compatibility routes and refreshes SEO metadata. `--prepared-courses` is only for
a freshly imported course tree: it verifies every pinned file hash before framing.

Run `check_site.py`, `check_migration.py`, `check_course_source.py`,
`check_research.py`, `check_presentation.py`, `check_seo.py` and
`check_repository.py` before publishing. Keep all checks local and batch one
reviewed deployment. No student code is executed by these checks.

The course importer omits the obsolete root inventory and plaintext Easter-egg
cache; original HTML, native files and ZIPs retain their source hashes.

Keep the two live language trees; they are publications, not alternate sources.
Do not recreate the `/niil/ko/` mirror or obsolete Notion course pages. Old lab
addresses resolve through one routing table. Because GitHub Pages has no server
rewrite rules, these retired addresses first receive its 404 document, which
immediately directs browsers to the current page; only current URLs enter the
sitemap. Do not use this fallback for promised direct downloads.

`/courses/` contains only the 95 approved compatibility files through 2026-12-31.
Its HTML aliases preserve queries/fragments; binary downloads remain byte-identical.
Remove that tree and its compatibility generation/checks together after the cutoff.

Keep `AGENTS.md` local and ignored. Do not add source archives, obsolete portraits,
review reports or temporary deployments to the public repository. Preserve the
shared source-only Easter egg once in the common stylesheet. Git history retains
removed files; cleanup does not rewrite history.
