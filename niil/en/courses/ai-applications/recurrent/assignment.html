Week 12 · Remember previous characters to predict the next one

English translation

Before practice

01 Is the current character enough?

The two l characters in hello are followed by different characters. Can the next character be predicted from the current character alone?

Description
  • The first l is followed by l, and the second l by o. The current character alone cannot distinguish these situations.
  • Using previously read information allows the two positions to be distinguished. Here, order provides information needed for prediction.

Review related concepts ↗

02 Add memory to classification

Can the classification methods learned earlier also select the next character?

Description
  • Computing scores for candidate characters and comparing them with the target character is a classification task.
  • An RNN carries previous information through Hidden State for prediction. In this exercise, inspect each position's Input, Target, and prediction side by side.
