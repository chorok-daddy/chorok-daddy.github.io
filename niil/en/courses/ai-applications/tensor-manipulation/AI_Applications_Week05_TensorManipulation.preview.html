3. Find axis and operation errors

A must have as many columns as B has rows to compute A@B. First print both array shapes to check whether multiplication is possible.

A. Baseline example · Read and run first

A=torch.arange(6,dtype=torch.float32).reshape(2,3)
B=torch.arange(12,dtype=torch.float32).reshape(3,4)
print((A@B).shape)
print((A+torch.tensor([10,20,30])).shape)
assert (A@B).shape==(2,4)
