Week 13 · Split long text to predict the next character

English translation

Before practice

01 How to train on long data

If an entire long text is difficult to process at once, how could you organize an exercise that reads segments and predicts the next character?

Description
  • Use consecutive Windows as Input
  • Set the next character at each position as Target. Example: abcd → bcde

02 Remember necessary information

Information near the beginning of a sentence may be needed for predictions much later. What problem could arise if earlier information is continually overwritten?

Description
  • Control how much information is retained or updated
  • Compare performance and cost with the same data and conditions. More complex structures are not always better
