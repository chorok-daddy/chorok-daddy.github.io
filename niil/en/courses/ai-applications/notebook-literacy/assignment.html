Practice

Choose an AI topic of interest and create a Notebook containing explanations, code, and execution results. Start from your copy of this week's practice Notebook.

Submission location
The corresponding assignment on KLAS. Follow the latest announcement if any changes are announced.

1. Introduce your AI topic

Choose Computer Vision, NLP, Autonomous Driving, Robotics, Speech Recognition, Recommendation System, Generative AI, or another AI topic of interest.

  • In 3–5 sentences, explain what the technology does, what data it uses, the problem it addresses, and example applications.
  • Describe the AI processing sequence in an ordered list of at least 4 stages.

2. Elements to include in the document

  • At least 3 heading levels.
  • At least 1 use each of bold, italics, and inline code.
  • Use both unordered and ordered lists, each with at least 3 items. The AI processing sequence follows the 4-stage requirement above.
  • At least 1 image and 1–2 sentences explaining its relevance to the topic.
  • Table with at least 3 columns and 4 data rows. The header does not count as a data row.
  • At least 2 LaTeX equations and at least 1 sentence explaining each equation.
  • At least 1 related link and 1–2 sentences explaining its selection or content.

Explain the meaning of figures and equations rather than merely inserting them. Build around your own topic instead of submitting the example unchanged.

3. Code execution and cell types

Run the following code in a Code Cell.

ai_fields = [
    "Computer Vision",
    "Natural Language Processing",
    "Robotics",
    "Generative AI"
]
print("Number of AI fields:", len(ai_fields))

Check output Number of AI fields: 4. In the Markdown Cell immediately below, write the following.

  1. Why must this be written in a Code Cell?
  2. Explain at least 2 differences between Markdown Cells and Code Cells.

4. Fix Markdown errors

Correct the following content in the practice Notebook so that the heading, bold text, ordered list, and table render correctly. Identify the incorrect symbols as well.

5. Check before submission

  • Run all Code Cells from the top and check their outputs.
  • With Markdown rendered, check the headings, lists, tables, equations, and images.
  • Complete the response fields, remove hint text, and check your name, student ID, and filename.
  • Check that images, equations, and links have explanations.
