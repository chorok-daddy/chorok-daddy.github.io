Week 8 · Multiclass Classification and Logits

English translation

Before practice

01 Distinguish multiple categories

Example scenario You want to classify a photo as a cat, dog, or bird. How should targets and predictions be represented so the model can distinguish these three categories?

Description
  • Assign a Class ID to each category and configure the model to output a score for each category.
  • Class IDs are identifiers. Their magnitude does not imply category order or distance.

02 Prediction confidence

Does choosing one category mean that the model distinguishes it confidently? When would you want to withhold a decision?

Description
  • The position of the largest score specifies the predicted Class
  • Score differences and a separate confidence assessment are needed. A Logit itself is not a probability
