Week 7 · Distinguish probability from classification criteria

English translation

Before practice

01 Numerical prediction and classification

Example scenario How do the desired model outputs differ between predicting tomorrow's temperature and deciding whether a device is operating normally?

Description
  • Temperature prediction produces a number; deciding normal versus abnormal produces a category. Set the model output and training criterion according to the desired result.
  • Binary Classification learns a score for choosing one of two categories. Logistic Regression is a basic model for this purpose.

02 Turn predictions into decisions

Example scenario A model gives a numerical likelihood of failure. How should the criterion for triggering an actual alarm be set?

Description
  • A Threshold is needed to convert the model's score into an alarm decision.
  • Consider both the cost of missed failures and unnecessary alarms. Distinguish the scoring model from the criterion for taking action.
