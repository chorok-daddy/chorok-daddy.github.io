2 Hypothesis and Cost

yhypo=H(x)=w⋅x+by_{hypo} = H(x) = w \cdot x + b

  • Assuming linearity, the equations above must hold.
  • For 3 data points, [y1y2y3]=w⋅[x1x2x3]+b\begin{bmatrix} y_1 \\ y_2 \\ y_3 \end{bmatrix} = w \cdot \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} + b
    • Find ww and bb that satisfy this equation.
  • Use mean squared error as the cost function: 1N∑n=1n=N(yhypo,(n)−ytrain,(n))2\frac{1}{N} \sum_{n=1}^{n=N} (y_{hypo, (n)} - y_{train, (n)})^2
# Initialize the Model (input dim, output dim)

3 Cost Optimization

  • Use stochastic gradient descent as the optimizer.
# Configure the Optimizer (set learning rate = 0.01)
optimizer = opt.SGD(model.parameters(), lr=0.01)
# Repeat
for epoch in range(1000):

  # Compute Cost / mse_loss(predicted value, true value)
  y_hypo = model(x_train)
  cost = func.mse_loss(y_hypo, y_train)

  # Update the model using cost
  optimizer.zero_grad()
  cost.backward()
  optimizer.step()

  # Print intermediate results every 100 iterations
  if epoch % 100 == 99:
    params = list(model.parameters())
    w = params[0].item()
    b = params[1].item()
    print('Epoch {:4d}/{} w: {:.3f} b: {:.3f} Cost: {:.6f}'.format(
        epoch+1, 1000, w, b, cost.item()
    ))

4 Multivariable Linear Regression

yhypo=H(𝐱)=𝐖⋅𝐱+by_{hypo} = H(\textbf{x}) = \textbf{W} \cdot \textbf{x} + b

  • Under the linearity assumption, the equation above must hold: yhypo=[w1w2w3]⋅[x1x2x3]+[b]y_{hypo} = \begin{bmatrix} w_{1} && w_{2} && w_{3} \end{bmatrix} \cdot \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} + \begin{bmatrix} b \end{bmatrix}
    • Find ww and bb that minimize the MSE cost.
