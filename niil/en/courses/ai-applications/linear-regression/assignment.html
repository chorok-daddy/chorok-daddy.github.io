Week 6 · Find a line by reducing prediction error

English translation

Before practice

01 From equations to data

How does computing values from a line equation differ from finding a line equation from measurements?

Description
  • Previously you computed outputs from a known slope; now you will find a slope that explains the trend in the data.
  • This exercise fixes the intercept at 0 and adjusts only the slope, simplifying the set of lines allowed by the model.

Review related concepts ↗

02 Learning and assumptions

Can adjusting the slope repeatedly explain any data without error?

Description
  • Allowing only lines through the origin makes it difficult to accurately represent relationships that do not pass through the origin or data with a curved pattern.
  • Use Loss and Gradients to reduce error within the chosen model. Increasing the iteration count differs from changing the model's assumptions.
