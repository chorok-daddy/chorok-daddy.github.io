1. Regression through the origin

A's first column is input x; the 1 in its second column is a constant for Bias. This baseline problem fixes Bias, so use only the first column as A_prime. Hypothesis is model(A_prime), and Cost is MSE.

A. Baseline example · Read and run first

import sys, numpy as np, matplotlib.pyplot as plt
import torch
from torch import nn
import torch.nn.functional as F
torch.manual_seed(42)

print('Python:', sys.version.split()[0], '| PyTorch:', torch.__version__)

2. Training and records

train_linear(lr=0.01, epochs=1000) creates and trains a new model with the same Seed. For Learning Rate comparisons, change only lr and keep epochs fixed. Gradients point toward increasing Loss; SGD updates Weight in the opposite direction.

A. Baseline example · Read and run first

def train_linear(lr=0.01,epochs=1000):
    torch.manual_seed(42);model=nn.Linear(1,1,bias=False)
    opt=torch.optim.SGD(model.parameters(),lr=lr);history=[]
    for _ in range(epochs):
        pred=model(A_prime);loss=F.mse_loss(pred,B_prime)
        opt.zero_grad();loss.backward();opt.step();history.append(loss.item())
    return model,history
model,history=train_linear()
print('w:',model.weight.detach(),'MSE:',F.mse_loss(model(A_prime),B_prime).item())
plt.plot(history);plt.xlabel('Epoch');plt.ylabel('MSE');plt.grid();plt.show()
