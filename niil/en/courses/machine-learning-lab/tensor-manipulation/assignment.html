Tensor Operations

English translation

A matching shape does not guarantee the intended operation. Relate axes, matrix multiplication, and broadcasting to the meaning of the output.

Before practice

01 How do cat and stack change the shape?

Description

cat concatenates along an existing axis, while stack creates a new axis.

02 Which shapes permit matrix multiplication and elementwise multiplication?

Description

Matrix multiplication requires matching inner dimensions; elementwise multiplication requires the same shape or follows broadcasting rules.

Practice

Preview practice notebookDownload practice notebook

1. Batch and feature axes

Starting conditions

X=arange(12).reshape(3,4), where rows are samples and columns are features.

Procedure

  1. Record X's shape and dtype, and the meanings of X[1] and X[:,2].
  2. First predict the shapes of cat([X,X],dim=0/1) and stack([X,X],dim=0/1).
  3. Compare with the actual results and identify which operations create a new axis.

2. Elementwise multiplication and matrix multiplication

Starting conditions

Using the same X, calculate X*X, X.T@X, and X@X.T.

Procedure

  1. Predict the shape of each result.
  2. Calculate the (0,1) entry of X.T@X by hand, then check it.
  3. With Y=X+1, compare X*Y and X.T@Y.

3. Finding reshape and broadcasting errors

Starting conditions

Reshape the 12 elements into (2,6),(4,3),(2,2,3), and add the vector [1,2,3,4] to X.

Procedure

  1. Reshape X into the three specified shapes, and compare the results of numel() and flatten() with the original X. Record whether the element count and order are preserved.
  2. Keep X at shape (3,4)(3,4) and add [1,2,3,4] and [1,2,3] separately. Record the output shape for the successful operation and the error message for the failed call.
  3. To add 1, 2, and 3 to the respective rows, first write the shape needed for these three elements, then reshape them and perform the addition. Record the corrected input shape and resulting array.
