2 Hypothesis, Cost and Optimization

  • Assume the following equations hold. yhypo=H(x)=Softmax(Linear(x)) y_{hypo} = H(x) = Softmax( Linear(x) ) Linear(x)=W⋅x+b Linear(x) = W \cdot x + b Softmax(X)=[y1,...,yC],yi=exi∑j=1Cexj Softmax(X) = [y_1, ..., y_C], \;\; y_i = \frac{e^{x_i}}{\sum_{j=1}^C e^{x_j}}

  • Use cross entropy as the cost function. −∑i=1Cytrain,ilog(yhypo,i) - \sum_{i=1}^{C} y_{train, i}log(y_{hypo, i})

  • Note that PyTorch's cross entropy loss function already includes softmax.

    • Therefore, use a linear model directly.
    • Pass class indices as y_train (one-hot encoding is unnecessary).
# Configure the Optimizer (set learning rate = 1)
optimizer = opt.SGD(model.parameters(), lr=0.1)

# Repeat
for epoch in range(1000):

  # Compute Cost / mse_loss(predicted value, true value)
  y_hypo = model(x_train)
  cost = func.cross_entropy(y_hypo, y_train)

  # Update the model using cost
  optimizer.zero_grad()
  cost.backward()
  optimizer.step()

  # Print intermediate results every 10 iterations
  if epoch % 100 == 99:
    correct_prediction = y_hypo.argmax(dim=1) == y_train
    accuracy = correct_prediction.sum().item() / len(correct_prediction)
    print('Epoch {:4d}/{} Cost: {:.6f} Accuracy {:2.2f}%'.format(
            epoch, 1000, cost.item(), accuracy * 100,
    ))
