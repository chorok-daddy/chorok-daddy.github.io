1.1 The main purpose of coding == 'Automation'

  • Have someone else (a machine) do the work you do not want to do

  • What does it mean to program well?

    • Communicate so that a machine can understand you (why it is called a programming language).

  • What about an advanced programmer?

    • They can make machines perform advanced, high-value tasks well.

  • To become good at English, go to the US and communicate frequently in English;

    • to become good at programming, first turn on your computer and you need plenty of programming practice.

  • Background knowledge of the task you assign is also essential.

    • People who understand the work can give effective instructions.

  • Ultimately, the world divides into people who can delegate work and people who can only follow instructions.

    • You need programming skills to have others do work for you.
    • Jobs that only involve following instructions are likely to be replaced by AI.

1.2 Automation example 1 - Automatically retrieve and plot KOSPI closing prices

from matplotlib import pyplot as plt
import yfinance as yf

# Daily KOSPI Adjusted Close. Internet access is required on the first run.
df = yf.download("^KS11", period="5y", auto_adjust=False,
                 multi_level_index=False, progress=False)
if df.empty:
    raise RuntimeError("KOSPI 데이터를 받지 못했습니다. 네트워크 연결을 확인한 뒤 다시 실행하세요.")
y_values = df['Adj Close']
x_values = range(len(y_values))

plt.plot(x_values, y_values)
plt.show()

1.3 Automation example 2 - Automatically retrieve news headlines

import urllib.request
import xml.etree.ElementTree as ET

feed_url = 'https://www.yna.co.kr/rss/news.xml'
with urllib.request.urlopen(feed_url, timeout=15) as response:
    feed = ET.fromstring(response.read())

headlines = [item.findtext('title', default='').strip()
             for item in feed.findall('./channel/item')[:20]]
for title in headlines:
    print(title)
  • By explaining the procedure to a machine in a programming language, you can easily do this too.
