English translation

Examining how error decreases together with the resulting prediction equation helps you assess why a learning rate or bias is needed.

Before practice

01 Without bias, what types of prediction equations are possible?

Description

Only linear equations through the origin are possible. Consider what the output at input 0 means when making your judgment.

02 If loss diverges, how would you first distinguish learning rate issues from data issues?

Description

First isolate the cause of divergence by changing only the learning rate while keeping the inputs, initialization, and iteration count fixed.

2. Comparing learning rates for the same model

Starting conditions

Fix bias=True and epoch=200, and compare lr=.01,.05,.1.

Procedure

  1. Fix the initial seed and data for all runs.
  2. Record the final MSE and the loss at epochs 1, 20, and 200.
  3. Distinguish the smallest final loss from the fastest initial decrease.
