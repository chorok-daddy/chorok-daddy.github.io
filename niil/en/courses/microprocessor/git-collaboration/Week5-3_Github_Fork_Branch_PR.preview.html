1. Fork the target repository into your account

  • Find the repository URL yourself and open it.
  • Click Fork in the upper right.
  • Clicking forks the repository without a separate confirmation step.

2. Clone into your local repository

  • After forking, use it as if it were your own repository.
  • For convenience, use a temporary folder on Google Drive instead of the local drive of the person using the fork.
