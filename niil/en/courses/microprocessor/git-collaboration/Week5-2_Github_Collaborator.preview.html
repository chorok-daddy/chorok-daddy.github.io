1. Add a collaborator to your repository

  • Repository - Settings - Manage access - Invite a collaborator
  • An invited user becomes a collaborator upon accepting the invitation.
  • The following instructions are for the invited user.

5. Push to the remote repository

  • A collaborator has the same permissions as the repository owner, including permission to push to main.
