Represent sensor records with data structures

Starting conditions

The record is [(0,21.0),(1,21.5),(2,None),(3,22.0),(4,20.5)], where each pair is time [s] and temperature [°C].

Procedure

  1. Convert each list item to a dictionary with time and temperature.
  2. Calculate the count, mean, minimum, and maximum of samples excluding None.
  3. Write a summarize function that leaves the original input unchanged.

Results to retain

  • summarize(rows) input: a list of dictionaries with time and temperature.

  • Variable to summarize: temperature.

  • Returned fields: valid sample count, mean, minimum, and maximum. Keep the same fields.
