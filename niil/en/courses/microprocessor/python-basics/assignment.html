English translation

Sensor records include missing and boundary values. Try handling normal and exceptional data with the same function.

Before practice

01 What happens to the mean if missing values are replaced with 0?

Description

This mixes actual 0 values with failed observations. First define the intended rule, such as exclusion or error handling.

02 What should a function return for empty data?

Description

Since the mean is undefined, choose a rule the caller can distinguish, such as an exception or None.

1. Represent sensor records with data structures

Starting conditions

The record is [(0,21.0),(1,21.5),(2,None),(3,22.0),(4,20.5)], where each pair is time [s] and temperature [°C].

Procedure

  1. Convert each list item to a dictionary with time and temperature.
  2. Calculate the count, mean, minimum, and maximum of samples excluding None.
  3. Write a summarize function that leaves the original input unchanged.

Results to retain

  • A 5-row record table, 4 summary statistics, and function code.
  • summarize(rows) input: a list of dictionaries with time and temperature.
  • Variable to summarize: temperature.
  • Returned fields: valid sample count, mean, minimum, and maximum. Keep the same fields.

  • Did you avoid interpreting None as 0°C?

2. Boundary values and empty input

Starting conditions

Convert each of the three inputs in cases in the code to the same list of dictionaries as in Activity 1, then pass them to summarize. Leave the empty list unchanged, and map the first value of each pair to time and the second to temperature.

Procedure

  1. Define the behavior to return None for the mean when there are 0 valid samples.
  2. Check that the returned fields are the same for one sample and multiple samples.
  3. Use asserts to check empty input, input with missing values, and single-sample input separately.

  • A 3-row boundary value table and 3 passing asserts.
