Decision Tree and Random Forest

English translation

Choose model complexity by checking whether a tree that fits the training data well also performs well on new data.

Before practice

01 Is a deeper tree always a better model?

Description

Following detailed patterns in training data can increase errors on new data.

02 What should you compare when combining results from multiple trees?

Description

Compare predictions and errors of individual trees and an Ensemble using the same split and metrics.

1. Tree Depth and Generalization

Starting conditions

Split the Iris data with test_size=.3, random_state=7, stratify=y. Use depths 1,3,None.

Procedure

  1. Train three DecisionTreeClassifier models on the same data split.
  2. Record Train Accuracy, Test Accuracy, and the number of Leaves, and read the decision path for one Test sample.

2. Comparison with Random Forest

Starting conditions

Compare with RandomForest using n_estimators=50, max_depth=3 on the same split.

Procedure

  1. Use the same train/test split as before and train RandomForestClassifier(n_estimators=50,max_depth=3,random_state=7).
  2. Record the train and test accuracy of the depth-3 Decision Tree and Random Forest from the previous activity in the same table.
  3. Provide one shared Test sample to both models and record its true label and each prediction. Explain the difference between a single Tree's result and combining results from multiple Trees.

3. Checking Other Inputs

Starting conditions

Split once more using split seed=11 and check whether the model ranking holds.

Procedure

  1. Keep test_size=.3 and stratify=y unchanged, and change only the split's random_state to 11.
  2. Retrain the depth-3 Tree and the Forest with 50 Trees from the previous activity on the new Train set. Keep the other model settings unchanged.
  3. Tabulate split seed, model name, Train Accuracy, and Test Accuracy. Explain whether the ordering of Test Accuracy remains the same for seeds 7 and 11.
