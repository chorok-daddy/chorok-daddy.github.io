Features with Different Scales

Starting conditions

Create data with only the last column multiplied by 100, and compare column-wise means and standard deviations before and after standardization.

Procedure

  1. Preserve X and multiply only the last column of a copy, X2, by 100. Record each column's mean and standard deviation before and after the change.
  2. Subtract each column's mean from that column of X2, and divide by its standard deviation. Use ddof=0, matching NumPy's default.
  3. Record each column's means and standard deviations before and after Standardization side by side. Use both statistics to explain whether the column multiplied by 100 is now on the same scale as the other columns.

Checking Other Inputs

Starting conditions

Add a constant feature column and handle the case where the Standardization denominator is 0.

Procedure

  1. Append one column with the same value in every row to X, and record its value and column position. For example, append a column filled with 1.
  2. Calculate each column's mean and standard deviation, and identify columns whose standard deviation is 0. Add a rule to the code for dividing those columns. For example, set only those denominators to 1.
  3. Record the transformed constant column and np.isfinite(...).all() for the entire result. Explain what changes if you divide by the constant column's unmodified standard deviation.
