Unsupervised Learning

English translation

Changing the number of clusters and the scale can change how the same data are grouped. Interpret the structure without assigning meaning to cluster numbers themselves.

Run import numpy as np and import matplotlib.pyplot as plt in a code cell before the practice code. Use np for array operations and plt for plots.

Before practice

01 Does cluster number 0 have a special meaning?

Description

Numbers are arbitrary identifiers, so compare clusters using their centers and assignment structure.

02 Do different feature units change distances?

Description

Features with larger ranges can dominate distances, so compare results before and after Standardization.

2. Changing Feature Units

Starting conditions

Multiply only X's first column by 10, and compare the original data, modified data, and results of column-wise standardization.

Procedure

  1. Prepare the original X, X2 with its first column multiplied by 10, and X2 standardized column by column.
  2. Retrain KMeans with K∈{2,3,4}K\in\{2,3,4\} on each dataset. Keep random_state=7 and n_init=10 unchanged.
  3. Plot cluster assignments and centers for each data condition, and record Inertia and Silhouette by K in tables with the same format. Use the plots to judge whether scaling up the first column changed assignments and centers, and explain your evidence.

Results to retain

  • Cluster plots for all three data conditions and a metrics table by K.

Starting conditions

Procedure

  3. Distinguish the fact that the data were generated with three centers from whether the scatter plot visibly shows three clearly separated groups.
