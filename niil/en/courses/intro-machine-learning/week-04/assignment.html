Bundle the inputs and decision rule into a function, with the Threshold as a separate argument.

2. Changing the Threshold

Starting conditions

Compare passing-student counts and boundary samples at threshold=50,60,80.

Procedure

  1. Call pass_flags with each Threshold in 50,60,8050,60,80. Keep the four scores unchanged.
  2. Tabulate the four pass/fail decisions and the passing-student count for each Threshold. Check whether the comparison operator used when a sample's score equals the Threshold is >=.
  3. Identify scores whose decisions changed with the Threshold and explain why.

3. Checking Other Inputs

Starting conditions

Check the function's boundary values using scores [59,60,61] and an empty List.

Procedure

  1. Keep Threshold 60 and write the expected function return values for scores [59,60,61] and an empty List before running.
  2. Call pass_flags on both inputs and record expected and actual return values side by side. Explain the decision for score 60 and the form of the return value for an empty input.
