Learning objectives

A single boundary value changes the decision. Turn a conditional into a function and compare ordinary and boundary inputs.

Conditions and loops

Starting conditions

Scores=[45,60,75,90], and the passing criterion is 60 or higher.

Procedure

  1. Use for and if to determine whether each score passes.
  2. Implement the same process as pass_flags(scores,threshold) and compare the two results.

Results to retain

  • A 4-row table and a reusable function.
scores=[45,60,75,90]
def pass_flags(values,threshold=60):
    return [v>=threshold for v in values]
print(pass_flags(scores))

Starting conditions

Procedure
