Checking Other Inputs

Starting conditions

Compare a model that always predicts 0 on 100 synthetic Labels, 10% of which are Class 1.

Procedure

  1. Create a Label array with 10 Class 1 samples and 90 Class 0 samples, and a prediction array filled with 0.
  2. Before running the code, calculate TP, FP, FN, TN, and Accuracy. Calculate the same values in code and compare them. Also record the number of missed Class 1 samples.
  3. Even if accuracy is high, can you conclude that the model reduces missed detections? Explain using your recorded FN.
