Week 13 · Comparing Steady-State Error with P and PI

English translation

Before practice

01 Persistent error

It stops approaching the reference at a slightly lower value. Could this persistent difference be used to adjust the input?

Description
  • Error accumulated over time
  • PI uses the current and accumulated error. Closed-loop stability is a prerequisite for evaluating its effect.

02 Tracking a moving target

Are maintaining a fixed velocity and tracking a continuously increasing target velocity the same problem? What changes when comparing control methods?

Description
  • Step and ramp are different tracking problems
  • Assess steady-state error using both the reference signal and system type
