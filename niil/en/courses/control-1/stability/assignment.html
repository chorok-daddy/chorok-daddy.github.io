Week 14 · Comparing Stability and Performance Indices

English translation

Before practice

01 Why check stability first?

Some systems initially behave well but oscillate more strongly over time. What should you check before evaluating speed or accuracy?

Description
  • Check stability before comparing performance
  • A small error over a short observation interval cannot establish long-term behavior

02 Evaluation suited to the purpose

One response deviates greatly but recovers quickly; another stays slightly off target for a long time. How should we decide which is better?

Description
  • ISE, IAE, and ITAE apply different weights to magnitude and duration
  • Choose metrics suited to the purpose and compare using the same input and observation interval
