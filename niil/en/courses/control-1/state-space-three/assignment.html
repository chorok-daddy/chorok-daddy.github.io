Week 7 · Does Changing the Model Representation Preserve the Response?

English translation

Before practice

01 Represent the same system differently

The motion of the same object can be expressed in different units or coordinates. When can changing the representation help the calculation?

Description
  • Changing units or coordinates can rescale numerical values or simplify relations for calculation.
  • In this exercise, check whether changing state coordinates preserves the physical response.

02 What remains unchanged when the representation changes

Can different numbers and matrices represent the same system? What must remain the same to establish this?

Description
  • The same physical initial state and input must produce the same output.
  • For the new coordinates, change not only the model matrices but also the initial state and output relation.

2. Responses before and after transformation

  1. Keep A,B,D in the first code section, change to C=[0 1], then rebuild sys and G=tf(sys).
  2. Calculate step(sys,t) and step(G,t) on the same time axis, and record the maximum absolute difference between their outputs. Determine whether it is less than 10−810^{-8}.
  3. Write the output equations y=Cxy=Cx and DC gains before and after the change side by side. Explain why changing the selected state changes the output and DC gain.

3. Rescale the state coordinates

  1. Change to P=diag([3 2]), recalculate Az,Bz,Cz using Az=P\(A*P), Bz=P\B, and Cz=C*P, and record the matrix.
  2. Calculate the step responses of the original and transformed models on the same time axis, and record the maximum absolute difference between their outputs. Determine whether it is less than 10−810^{-8}.
