2. State Transition Matrix

Calculate e^{At} in MATLAB using expm(A*t). At t=0, no time has elapsed, so the initial state must remain unchanged. Thus, Phi(0) is the identity matrix; the code below checks this condition. The similarly named exp applies the exponential function to each element separately, so substituting it for expm here produces a different result.

A=[0 1;-2 -3];
Phi=expm(A*.5);disp(Phi);
assert(norm(expm(A*0)-eye(2))<1e-12);
disp(norm(Phi-exp(A*.5)));

4. Decompose the total response

Compare using the same input, output, and time axis.
Prediction before running: ⟦enter here⟧
sys=ss([0 1;-2 -3],[0;1],[1 0],0);t=(0:.01:8)';u=ones(size(t));x0=[1;0];
yTotal=lsim(sys,u,t,x0);yInitial=initial(sys,x0,t);yInput=lsim(sys,u,t);
err=max(abs(yTotal-yInitial-yInput));disp(err);assert(err<1e-8);
figure;plot(t,[yTotal,yInitial,yInput]);legend('total','initial','input');grid on;
