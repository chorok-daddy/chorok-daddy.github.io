Week 6 · State Transition and System Responses

English translation

Before practice

01 Effect of the starting state

The same object responds differently when starting at rest and when already moving. How can this difference be reflected in the calculation?

Description
  • Specify the starting position and velocity as the initial state. Different initial states produce different responses even with the same subsequent input.
  • State transition describes how this initial state evolves over time.

02 Distinguish the causes of motion

How could separating the object's initial motion from the effect of subsequently applied force help you understand the response?

Description
  • Decompose a linear model into responses due to the initial state and the input
  • Calculate the total response by adding the input response with initial state 0

4. Decompose the total response

  1. Using sys,t defined in the total-response decomposition code, calculate each of the following cases.
