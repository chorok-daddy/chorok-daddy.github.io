2. Baseline response of the parallel RLC circuit

The input is current [A], and the output is voltage [V]. With all initial conditions at 0, the transfer function has numerator s and denominator C*s^2 + (1/R)*s + 1/L.
Prediction before running: What will the voltage be initially and after a long time? Response: ______
R0 = 0.5; % ohm
L0 = 1; % H
C0 = 5; % F
t_rlc = linspace(0,25,1001);
g0 = tf([1 0], [C0 1/R0 1/L0]);
disp(g0);
figure('Name','RLC baseline');
step(g0,t_rlc);
grid on;
title('Parallel RLC: 1 A current step');
xlabel('Time (s)'); ylabel('Voltage (V)');
Observation: Describe what matches or differs from your prediction. Write: ______
Write coefficient arrays in descending powers of s. Omitting the final 0 in numerator [1 0] produces a different model.

Change R, L, and C one at a time

The baseline values are Ω, H, and F. The input is current [A], and the output is voltage [V].
  1. Run the baseline model's unit-step response, then set parameter to "R", "L", and "C" in turn. For each parameter, rerun the corresponding section with factor=2 and factor=0.5. Keep the two unselected parameters at their baseline values.
  2. Compare peak voltage, oscillation, and convergence between baseline and modified curves for each run. Record the changed parameter, its values before and after the change, and observed differences in the corresponding observation-table row.
  3. For each parameter, explain one observed change in relation to the roles of resistance, inductance, and capacitance. Include a legend identifying conditions and units for time and voltage in the plot.
parameter = "R"; % Student changes: "R", "L", "C"
factor = 1; % Student changes: 2 or 0.5
assert(any(parameter == ["R","L","C"]), 'parameter는 R, L, C 중 하나여야 합니다.');
assert(isscalar(factor) && isfinite(factor) && factor > 0, 'factor는 양수여야 합니다.');
R = R0; L = L0; C = C0;
switch parameter
case "R"
R = R0*factor;
case "L"
L = L0*factor;
case "C"
C = C0*factor;
end
g_changed = tf([1 0], [C 1/R 1/L]);
figure('Name','RLC comparison');
step(g0,g_changed,t_rlc);
grid on;
legend('Baseline',char(parameter + " x " + string(factor)), 'Location','best');
title('Change one parameter');
xlabel('Time (s)'); ylabel('Voltage (V)');

3. Baseline response of the mass–spring–damper

The input is force [N], and the output is displacement from equilibrium [m]. The equation is My'' + by' + k*y = u. The numerator is 1, and the denominator coefficients are [M b k].
Prediction before execution: Will displacement keep increasing under a continuously applied constant force? Write: ______
M = 1; b = 2; k = 5;
t_msd = linspace(0,15,1001);
g_msd = tf(1,[M b k]);
figure('Name','Mechanical baseline');
step(g_msd,t_msd);
grid on;
title('Mass-spring-damper: 1 N force step');
xlabel('Time (s)'); ylabel('Displacement (m)');
