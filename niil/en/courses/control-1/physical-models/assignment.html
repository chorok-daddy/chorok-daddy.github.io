Before practice

01 Motion models already learned

When calculating position with constant-velocity or constant-acceleration equations, what did you assume remained unchanged?

Description
  • Constant-velocity motion fixes velocity; constant-acceleration motion fixes acceleration. Restricting these changes lets position be calculated with simple equations.
  • If force changes due to a spring or friction, include that relation in the model. This exercise compares how those forces affect motion.

Review related concepts ↗

02 The model and actual characteristics

If the object becomes heavier or the spring changes, what must change in the model?

Description
  • Change a parameter representing the mass or spring stiffness. The numbers in the equations relate to the properties of the actual device.
  • Changing one characteristic at a time makes it easier to identify why the motion changes.

  1. Run the baseline model's unit-step response, then set parameter to "R", "L", and "C" in turn. For each parameter, rerun the corresponding section with factor=2 and factor=0.5. Keep the two unselected parameters at their baseline values.
