Applying the nominal controller to other actual models

Starting conditions

kg, N·s/m, N/m. Fix K and N at the values designed for .

Procedure

  1. Keep the nominal controller fixed and compare the poles and responses of the three actual models.
  2. Find the final value and 2% settling time of each response, and identify the slowest condition.

Results to retain

A0=[0 1;-2 -3]; B0=[0;1]; C=[1 0]; K=place(A0,B0,[-2 -4]); N=8;
t=linspace(0,6,1201)'; figure; hold on

A=[0 1;-2/m -3/m]; B=[0;1/m]; p=eig(A-B*K);

fprintf('mass %.2f\n',m); disp(p); plot(t,y,'DisplayName',sprintf('m=%g',m));
end
xlabel('Time [s]'); ylabel('Position'); legend; grid on

Procedure

With input delay and saturation

Starting conditions

Euler-integrate the nominal model's state with dt=.002 s steps for 6 s. Input delays are 0,.08,.2 s, and the input limit is ±4.

Procedure

  1. Use the practice notebook's function to plot outputs and inputs for the three delays.
  2. Halve dt and check that the main responses remain similar.
  3. Explain why linear-pole stability alone is insufficient to assess an implementation with delay and saturation.

Results to retain

  • Output and input curves, RMS tracking error (after 2 s), input saturation fraction (the full 0–6 s record), and comparison of integration time steps.
figure; hold on
for delay=[0 .08 .2]
[tt,yy,uu]=delayedInput(delay,.002,A0,B0,K,N); keep=tt>=2;
disp([delay sqrt(mean((1-yy(keep)).^2)) mean(abs(uu)>=4-1e-8)]);
plot(tt,yy,'DisplayName',sprintf('delay=%g',delay));
end
xlabel('Time [s]'); ylabel('Position'); legend; grid on

function [times,ys,us]=delayedInput(delay,dt,A0,B0,K,N)
times=(0:dt:6)'; x=zeros(2,1); commands=zeros(size(times)); ys=zeros(size(times)); us=zeros(size(times)); lag=round(delay/dt);
for n=1:numel(times)
command=min(max(N-K*x,-4),4); commands(n)=command;
if n>lag, u=commands(n-lag); else, u=0; end
ys(n)=x(1); us(n)=u; x=x+dt*(A0*x+B0*u);
end
end
