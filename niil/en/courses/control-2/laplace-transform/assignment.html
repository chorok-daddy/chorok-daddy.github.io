Laplace Transform

English translation

Directly verify that the solution obtained by transforming a time-domain differential equation satisfies the original problem.

MATLAB: Symbolic Math Toolbox required.

If ver('symbolic') returns an empty result, install Symbolic Math Toolbox from MATLAB Add-Ons.

Before practice

01 How should values that make the denominator 0 be handled before cancellation?

Description

Even after cancellation simplifies an expression, values that make the original denominator 0 cannot be substituted. First identify the excluded values in the original expression.

02 Where does the initial condition enter the Laplace domain?

Description

Since the transform of y′ is sY(s)−y(0), the initial value remains as a separate term.
