Frequency Response

English translation

Understanding how amplitude and phase change at each frequency connects Bode plots to actual signals.

Before practice

01 What aspect of the output does Bode gain describe?

Description

It is the ratio of steady-state output amplitude to input amplitude at the same frequency.

02 How does a remaining transient affect phase estimation?

Description

Mixing the steady-state sinusoid with the transient introduces amplitude and phase estimation errors.

Execution conditions

Read magnitude and phase from python-control's ctl.frequency_response. Phase is returned in radians; convert it to degrees in the table.

If the module is missing, run %pip install control==0.10.2 in a Colab or Jupyter code cell.

Procedure
