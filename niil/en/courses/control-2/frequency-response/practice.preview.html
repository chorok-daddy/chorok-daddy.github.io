Measuring gain and phase with sinusoids

Starting conditions

G(s)=1s2+0.5s+1G(s)=\frac1{s^2+0.5s+1}, u=sin⁡(ωt)u=\sin(\omega t), ω∈{.2,1,3}\omega\in\{.2,1,3\} rad/s. 0≤t≤2000\le t\le 200 s, Δt=.01\Delta t=.01 s.

Procedure

  1. Calculate the output using ctl.forced_response, and plot the input and output for only the final two periods.
  2. Fit the output to asin⁡(ωt)+bcos⁡(ωt)a\sin(\omega t)+b\cos(\omega t) by least squares to obtain gain a2+b2\sqrt{a^2+b^2} and phase atan2⁡(b,a)\operatorname{atan2}(b,a).
  3. Compare with the magnitude and phase from ctl.frequency_response. Phase is returned in radians. Convert both phase calculations to degrees in the table.

Results to retain

  • A frequency table with 3 rows and 3 plots comparing the final two periods.
import numpy as np
import matplotlib.pyplot as plt
import control as ctl
s = ctl.tf('s')
G=1/(s*s+.5*s+1)
omega=1.;t=np.arange(0,200,.01);u=np.sin(omega*t)

Comparing damping and resonance

Starting conditions

Set the denominator to s2+as+1s^2+as+1 and compare a∈{.2,.5,1}a\in\{.2,.5,1\}. Use ω=logspace(-2,2,400).

Procedure

  1. Plot the gains and phases of the three models on the same frequency axis.
  2. Tabulate each model's maximum gain, its frequency, and DC gain.
  3. Choose one sinusoidal condition near the maximum gain and check it using the method from the first activity.

Results to retain

import numpy as np
import matplotlib.pyplot as plt
import control as ctl
s = ctl.tf('s')
omega=np.logspace(-2,2,400)
for a in [.2,.5,1.]:
