PID Control

English translation

Selecting a gain based only on response speed can leave the system vulnerable to overshoot or model changes. Compare different performance metrics.

The Python option uses python-control. If the module is missing, run %pip install control==0.10.2 in a Colab or Jupyter code cell.

MATLAB · Control System Toolbox

Before practice

01 What error information does each P, I, and D term respond to?

Description

They respond to current error, accumulated error, and error changes. Examine their actual effects in the closed-loop response.

02 What becomes hard to distinguish when several gains change simultaneously?

Description

It becomes difficult to isolate which gain caused the response change.

2. Changing one term at a time

Starting conditions

Starting from the PID baseline (500,300,30), change only Kp to 250,500,750. Keep Ki and Kd fixed.

Procedure

  1. Use the PID result from Activity 1, (500,300,30)(500,300,30), as the baseline, and change only KpK_p to 250 and 750 in turn. Keep Ki=300K_i=300, Kd=30K_d=30, the plant, and the time axis unchanged.
  2. Plot the unit-step responses of both settings alongside the baseline curve in the same figure. Record overshoot, settling time, and steady-state error using the same ctl.step_infostepinfo settings and the same columns as Activity 1.
  3. Choose one of the two additional settings. Use the table values to explain which metric you aim to improve over the baseline and which changes you are willing to accept.

Procedure

  1. In the supplied PI simulation, plot the actual input alongside the input before limiting.
  2. Compare conditional integration enabled and disabled.
  3. Explain why the error persists after lowering the reference, relating it to the integrator state.
