Changing one term at a time

Starting conditions

Starting from the PID baseline (500,300,30), change only Kp to 250,500,750. Keep Ki and Kd fixed.

Procedure

  1. Use the PID result from Activity 1 as the baseline, and change only to 250 and 750 in turn. Keep , , the plant, and the time axis unchanged.
  2. Plot both unit-step responses alongside the baseline curve in the same figure. Use the same stepinfo settings to calculate overshoot, settling time, and steady-state error, and record them in the same columns as Activity 1.
  3. Choose one of the two additional settings. Use the table values to explain which metric you aim to improve over the baseline and which changes you are willing to accept.

Results to retain

  • Response plots and a performance table for both settings. One sentence explaining your choice.
s=tf('s'); G=.01/((.01*s+.1)*(.5*s+1)+.01^2);
for kp=[250 500 750]
T=feedback((kp+300/s+30*s)*G,1); disp(kp); disp(dcgain(T));
end

Input limits and integrator windup

Starting conditions

1st-order plant , reference 2→.5 (changes at 5 s), , dt=.01 s. Use , .

Procedure

  1. In the supplied PI simulation, plot the actual input alongside the input before limiting.
  2. Compare conditional integration enabled and disabled.
  3. Explain why the error persists after lowering the reference, relating it to the integrator state.

Results to retain

  • Three plots of output, input, and integrator state, and a comparison table.
In the comparison table, IAE is from the reference-change time to the final recording time. Calculate input saturation duration by multiplying the number of samples where the limited u is 0 or 1 over the entire record by dt.
Use the same interval and calculation method for both integration approaches.
figure; hold on
for flag=[false true]
[time,trace]=simulateAntiWindup(flag); plot(time,trace(:,2),'DisplayName',string(flag));
end
xlabel('Time [s]'); ylabel('Output'); legend; grid on

function [t,rows]=simulateAntiWindup(antiwindup)
t=(0:.01:11.99)'; y=0; integral=0; rows=zeros(numel(t),5);
for n=1:numel(t)
ref=2; if t(n)>=5, ref=.5; end
e=ref-y; raw=2*e+integral; u=min(max(raw,0),1);
if ~antiwindup || (raw>0 && raw<1) || (raw>=1 && e<0) || (raw<=0 && e>0)
integral=integral+e*.01;
end
y=y+(-y+u)*.01; rows(n,:)=[ref y raw u integral];
end
end
