Reference Tracking and Optimal Control

English translation

Examine why reference error remains even with a stable controller, and compare tracking performance with control-input cost.

Before practice

01 Does a stable system necessarily track its reference exactly?

Description

Stability concerns responses to initial states and inputs, while steady-state reference error also depends on the gain along the input–output path.

02 What receives more emphasis when Q increases?

Description

Assign a higher cost to deviations of that state from its reference. Record output error and control input separately to examine the trade-off.
