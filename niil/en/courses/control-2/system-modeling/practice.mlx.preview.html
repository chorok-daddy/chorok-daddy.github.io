Estimating a model from a measured response

Starting conditions

Synthetic sensor step record: . s, 151 points, noise standard deviation .03, seed=7.

Procedure

  1. Read the supplied step_measurements.csv and estimate using fminsearch in the starter code. Keep the code that optimizes the logarithms of the estimated variables.
  2. Apply the same estimation separately to the full 0–15 s record and the first 0–3 s. Tabulate the sample count and estimated for each interval.
  3. Plot each fitted curve on the same time axis as the measurements, and plot residuals as measured minus estimated values. Based on the final values and residual patterns, choose one time interval where you would like more measurements and explain why.

Results to retain

  • A table of estimates for both measurement intervals and response and residual plots.
dataFile=fullfile(fileparts(mfilename('fullpath')),'step_measurements.csv');
if ~isfile(dataFile)
websave(dataFile,'https://chorok-daddy.github.io/niil/courses/control-2/system-modeling/step_measurements.csv');
end
data=readmatrix(dataFile); tm=data(:,1); measured=data(:,2);
response=@(time,par) par(1)*(1-exp(-time/par(2)));
for finish=[3 15]
select=tm<=finish;
loss=@(logpar) sum((response(tm(select),exp(logpar))-measured(select)).^2);
logpar=fminsearch(loss,log([1 2]),optimset('Display','off','TolX',1e-10,'TolFun',1e-12));
parameters=exp(logpar); disp(finish); disp(parameters);
end
