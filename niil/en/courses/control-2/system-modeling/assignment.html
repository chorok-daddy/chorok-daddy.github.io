System Modeling

English translation

Use the model to determine whether changing mass or resistance affects the transient response, the steady-state value, or both.

The Python option uses python-control. If the module is missing, run %pip install control==0.10.2 in a Colab or Jupyter code cell.

MATLAB · Control System Toolbox

Place the measurement file step_measurements.csv in the same folder as the script. The code downloads it if it is missing.

To obtain positive gain and time constant, estimate their logarithms using fminsearch.

Before practice

01 Does increasing mass also change the final velocity?

Description

With the same resistance coefficient and force, steady-state velocity is unchanged and the time constant changes.

02 Which coefficients change if only resistance changes in the same motor?

Description

The electrical term Ls+R in the denominator changes, affecting the poles and DC gain.
