MATLAB Vectors and Sensor Data

English translation

Learning objectives

Combine time, height, and battery records into an array, then select and inspect the intervals and conditions you need.

Execution conditions

Use MATLAB or MATLAB Online. The basic activities run in MATLAB alone and do not require a drone connection.

Convert a measurement table to an array

Starting conditions

Use the example's time, height, and battery columns.

Procedure

  1. Create three column vectors and combine them into a 5×3 array.
  2. Use size to check the dimensions, and extract the third row and the height column separately.

Results to retain

  • Row/column selection results and a measurement table with units.
t=(0:4)';height_m=[0;.4;.9;.7;.1];battery_pct=[92;91;90;89;88];
measurements=[t,height_m,battery_pct];
disp(size(measurements));disp(measurements(3,:));

Select by height condition and time interval

Starting conditions

Select height≥.5 m and 1≤t≤3 seconds separately.

Procedure

  1. Create two logical arrays and check which rows are selected.
  2. Select records that satisfy both conditions, and record time, height, and battery together.
  3. Change the height condition to .8 m and check which rows are excluded.

Results to retain

  • Selection results for each condition and selected points marked on a height plot.
above=height_m>=.5;
in_window=t>=1 & t<=3;
disp(measurements(above & in_window,:));

Handle empty selection results

Starting conditions

No records satisfy height≥2 m.

Procedure

  1. Select rows with height at least 2 m, and record the results of size and isempty. If no heights are selected, branch to display 'No results' instead of the maximum.
  2. Before running the selection code, append one value to each column vector t, height_m, and battery_pct, then rerun measurements=[t,height_m,battery_pct]. The new elements of all three vectors must form the same measurement row. Set the added row's height to at least 2 m and record the three values.
  3. Rerun the same selection code and record the selected row count, displayed result, and maximum selected height before and after the addition, side by side.

Results to retain

  • Empty results and results after adding a new measurement.
selected=measurements(height_m>=2,:);
disp(size(selected));disp(isempty(selected));
