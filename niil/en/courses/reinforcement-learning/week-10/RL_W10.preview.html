Soft Actor-Critic (SAC)

[Soft Actor-Critic (SAC) algorithm overview]

  • Assume a continuous action space problem.
  • Off-policy actor–critic methods
    • Non-real-time learning using memory
  • Maximum entropy reinforcement learning
    • Maximize policy entropy along with expected reward
    • Expected to improve exploration and stabilize training

[The continuous action space problem]

  • Discrete action space vs. continuous action space
    • Discrete action space
      • Actions consist of finitely many choices
        • CartPole (move the pole left/right)
        • Atari games (joystick up/down/left/right, button presses, etc.)
      • Can be addressed with conventional Q-learning concepts
        • Because Q-values for all possible actions can be calculated in any state
    • Continuous action space
      • Actions are real-valued and range continuously
        • Car steering: steering angle (-90° ~ +90°)
        • Robot joint control: each joint's angle (0° ~ 360°)
        • Drone propeller speed control: each propeller's rotational speed (0 RPM ~ 10000 RPM)
      • Calculating Q-values for all possible actions is impossible
      • Q-learning family algorithms are difficult to apply directly
  • Q-networks in continuous action spaces
    • Example scenario: an autonomous car maintaining its lane
      • State: car position relative to the lane center, current speed, distance to the car ahead, etc.
      • Action: steering angle (-90° ~ +90°)
    • Q-learning Q-network
      • Takes only the state as input and must calculate values for all possible actions
      • In this example, it cannot determine the optimal angle among the countless possible steering angles -90°, -89.9°, -89.8°, …, 89.8°, 89.9°, 90°
    • What if the Q-network takes state and action together as inputs?
      • It can evaluate Q-values for particular state–action pairs as follows
        • What is the value of turning the wheel 10° in the current state?
        • What is the value of turning the wheel -5° in the current state?
  • Policy network in a continuous action space
    • As in A2C, take a state as input and output an action probability distribution.
      • Sample an action (e.g., 11 degrees) from this distribution. The Q-network takes both the sampled action (11 degrees) and current state as input to compute the Q-value.

[Soft Actor-Critic (SAC) features]

1. Represent and sample continuous actions using a Gaussian policy

  • SAC uses a Gaussian policy to represent and sample continuous actions
    • a∼ℕ(μ(s),σ(s)2)a \sim \mathbb{N}(\mu(s), \sigma(s)^2)
      • aa: Action
      • μ(s)\mu(s): Mean for state ss
      • σ(s)\sigma(s): Standard deviation for state ss
  • A Gaussian policy represents actions by means and standard deviations, enabling smooth action control
  • Examples
    • Precisely control motor torque in robot control.
    • Smoothly adjust the steering angle in autonomous driving.
  • Particularly useful when fine adjustments unavailable in discrete action spaces are needed

2. Efficient off-policy learning

  • An actor–critic variant that reuses past experience off-policy (as DQN does) to improve learning efficiency

  • Higher sample efficiency than conventional algorithms helps address data-hungry problems in continuous action spaces

    • Entropy reward (entropy regularization)
      • Strengthen the exploration–exploitation balance through entropy rewards
      • Encourage high entropy to try diverse actions and find an optimal policy
      • Entropy rewards have their greatest effect in continuous action spaces because there is more space to explore
    • Automatically adjust temperature parameter α\alpha
    • Automatically adjust the temperature parameter during training
      • If entropy is below the target, increase alpha to encourage exploration
      • If it is above the target, decrease alpha to encourage exploitation
    • Maximize learning efficiency and play an important role in maintaining balance in continuous action spaces

3. Reduce Q-value overestimation — two Q-networks

  • SAC uses two Q-networks to reduce positive bias that can arise during policy improvement.
    • Use the minimum of the two Q-network outputs when updating the policy network (advantage calculation).

4. V-network — Predict the soft state value

  • In SAC, V(s)V(s) is the soft state value, including the entropy term.
  • Instead of directly computing the expectation over all continuous actions, train a network to approximate it using actions sampled from the policy.
  • The provided code uses Q(s,a)−V(s)Q(s,a)-V(s) as a baseline-subtracted term in the policy update.

[SAC network architecture]

1. Q-network

  • Output the Q-value of a state–action pair given a state and an action
    • Input: State (ss) and action (aa)
    • Hidden layers: Multiple hidden layers using ReLU activation functions
    • Output: Q-value of the state–action pair

(State,Action)↓Input Layer↓Hidden Layer↓Output Layer↓Q\begin{array}{c} \boxed{(State, Action)} \\ \downarrow \\ \boxed{\text{Input Layer}} \\ \downarrow \\ \boxed{\text{Hidden Layer}} \\ \downarrow \\ \boxed{\text{Output Layer}} \\ \downarrow \\ \boxed{Q} \end{array}

  • SAC uses two Q-networks (q1, q2) for stable training

2. Target Q-Network

  • The target Q-networks have the same architecture as the Q-networks (target q1, target q2).
  • Weights are updated periodically (soft update).
  • Helps improve training stability

3. Policy network

  • The policy network takes a state as input and outputs an action probability distribution (usually a Gaussian mean and standard deviation).
    • Input: State (ss)
    • Hidden layers: Multiple hidden layers using ReLU activation functions
    • Output: Mean (μ\mu) and standard deviation (σ\sigma) representing the action distribution

State↓Input Layer↓Hidden Layer↓Output Layer↓(Meanμ,Stdσ)\begin{array}{c} \boxed{State} \\ \downarrow \\ \boxed{\text{Input Layer}} \\ \downarrow \\ \boxed{\text{Hidden Layer}} \\ \downarrow \\ \boxed{\text{Output Layer}} \\ \downarrow \\ \boxed{(\text{Mean} \;\mu , \text{Std}\;\sigma)} \end{array}

4. V-network

  • Estimate the soft state value of a state given as input
    • Input: State (ss)
    • Hidden layers: Multiple hidden layers using ReLU activation functions
    • Output: Estimated soft state value of the state

(State)↓Input Layer↓Hidden Layer↓Output Layer↓V\begin{array}{c} \boxed{(State)} \\ \downarrow \\ \boxed{\text{Input Layer}} \\ \downarrow \\ \boxed{\text{Hidden Layer}} \\ \downarrow \\ \boxed{\text{Output Layer}} \\ \downarrow \\ \boxed{V} \end{array}

[Loss calculation and update process]

1. Sampling

  • Sample a minibatch from the replay buffer: (st,at,rt,st+1,donet)∼𝖣(s_t, a_t, r_t, s_{t+1}, done_t) \sim \mathsf{D}
    • sts_t: state at time t
    • ata_t: action at time t
    • rtr_t: reward at time t
    • st+1s_{t+1}: next state at time t+1
    • donetdone_t: termination at time t (boolean: ended=1, otherwise=0)
    • 𝖣\mathsf{D}: replay buffer

2. Compute the target V-value

  • Estimate the next-state value using the target V-network: Ṽ(st+1)=Vψ‾(st+1)\tilde{V}(s_{t+1}) = V_{\bar{\psi}}(s_{t+1})

    • Vψ‾V_{\bar{\psi}}: Target V-network (parameters: ψ‾\bar{\psi})

3. Compute target Q-values

  • Compute Q-values of next-state–action pairs using two Q-networks: Q̃1(st+1,at+1)=Qϕ1(st+1,at+1)\tilde{Q}_1(s_{t+1}, a_{t+1}) = Q_{\phi_1}(s_{t+1}, a_{t+1}) Q̃2(st+1,at+1)=Qϕ2(st+1,at+1)\tilde{Q}_2(s_{t+1}, a_{t+1}) = Q_{\phi_2}(s_{t+1}, a_{t+1})

    • Qϕ1Q_{\phi_1}, Qϕ2Q_{\phi_2}: Two Q-networks (parameters: ϕ1\phi_1, ϕ2\phi_2)

  • Clipped Double Q-Learning (select the minimum): Q̃(st+1,at+1)=min⁡(Q̃1(st+1,at+1),Q̃2(st+1,at+1))\tilde{Q}(s_{t+1}, a_{t+1}) = \min(\tilde{Q}_1(s_{t+1}, a_{t+1}), \tilde{Q}_2(s_{t+1}, a_{t+1}))

  • Final target Q-value calculation: Q̂(st,at)=rt+γ(1−donet)(Q̃(st+1,at+1)−αlog⁡πθ(at+1|st+1))\hat{Q}(s_t, a_t) = r_t + \gamma (1 - done_t) (\tilde{Q}(s_{t+1}, a_{t+1}) - \alpha \log \pi_\theta(a_{t+1} | s_{t+1}))

    • γ\gamma: discount factor
    • α\alpha: entropy regularization coefficient (temperature parameter)

4. Q-networks Loss (Critic Loss)

  • Compute the mean squared error (MSE) loss for each Q-network: JQ(ϕi)=𝔼(st,at,rt,st+1)∼𝖣[12(Qϕi(st,at)−Q̂(st,at))2],i=1,2J_Q(\phi_i) = \mathbb{E}_{(s_t, a_t, r_t, s_{t+1}) \sim \mathsf{D}} \left[ \frac{1}{2} (Q_{\phi_i}(s_t, a_t) - \hat{Q}(s_t, a_t))^2 \right], \quad i = 1, 2

  • Final Q-loss (sum of both losses): JQ(ϕ)=JQ(ϕ1)+JQ(ϕ2)J_Q(\phi) = J_Q(\phi_1) + J_Q(\phi_2)

5. V-network Loss (Critic Loss)

  • Compute action-related values at the next state using the policy network: μθ(st+1),log⁡σθ(st+1)=πθ(st+1)\mu_{\theta}(s_{t+1}), \log \sigma_{\theta}(s_{t+1}) = \pi_\theta(s_{t+1})

    • πθ\pi_\theta: Policy network (parameters: θ\theta)
    • μθ(st+1)\mu_{\theta}(s_{t+1}): Mean action output by the policy network at next state st+1s_{t+1}
    • log⁡σθ(st+1)\log \sigma_{\theta}(s_{t+1}): Log standard deviation of the action output by the policy network at next state st+1s_{t+1}

  • Sample the next action: at+1=ftanh⁡(zt+1)a_{t+1} = f\tanh(z_{t+1})

    • zt+1∼𝖭(μθ(st+1),σθ(st+1))z_{t+1} \sim \mathsf{N}(\mu_{\theta}(s_{t+1}), \sigma_{\theta}(s_{t+1})): a value sampled from a normal distribution
    • tanh\tanh: map values to -1 ~ 1 with the tanh\tanh function
      • Further scaling may be needed for the problem

  • Calculate the sampled next action's log probability

    • Explain the concepts using source code\

    dist = Normal(mean, std)
z = dist.rsample()
action = torch.tanh(z)
log_prob = (dist.log_prob(z) - torch.log(1 - action.pow(2) + 1e-7)).sum(axis=-1, keepdim=True)
    • dist = Normal(mean, std)
      • z∼𝖭(μ,σ2)z \sim \mathsf{N}(\mu, \sigma^2)
      • With mean (mean) μ\mu and standard deviation (std) σ\sigma, create a normal distribution object dist
    • z = dist.rsample()
      • From distribution dist, generate sample z using the reparameterization trick
      • The rsample() method works internally as follows
        • z=μ+σ⋅ϵz = \mu + \sigma \cdot \epsilon, where [ϵ∼𝖭(0,1)\epsilon \sim \mathsf{N}(0, 1)]
    • action = torch.tanh(z)
      • a=tanh⁡(z)a = \tanh(z)
      • Transform sampled z with the hyperbolic tangent function (tanh) to obtain action\
      • The tanh function restricts output to between -1 and 1
    • Since z was transformed to action (applying tanh), adjust the probability density accordingly
      • dist.log_prob(z): calculate the log probability density of z under distribution dist
        • (provided by PyTorch)
      • torch.log(1 - action.pow(2) + 1e-7): a correction term for the probability density change caused by applying tanh
      • The change of variables formula gives the following relationship (proof omitted)
        • log⁡p(a)=log⁡p(z)−log⁡|dadz|\log p(a) = \log p(z) - \log \left| \frac{da}{dz} \right|
          • p(a)p(a): probability density of action
          • dadz\frac{da}{dz}: derivative of action with respect to z (Jacobian)
            Since a=tanh⁡(z)a = \tanh(z), dadz=1−tanh⁡2(z)=1−a2\frac{da}{dz} = 1 - \tanh^2(z) = 1 - a^2
        • −log⁡|dadz|=−log⁡(1−a2)- \log \left| \frac{da}{dz} \right| = -\log(1 - a^2)
          • Add a very small value (ϵ≃1e−7\epsilon \simeq 1e-7) for numerical stability (to avoid log(0))
        • −log⁡(1−a2+ϵ)-\log(1 - a^2 + \epsilon)
      • .sum(axis=-1, keepdim=True): for a multivariate normal distribution, sum the log probabilities of each dimension to calculate the total log probability
        • ∑i[logp(zi)−log(1−ai2+ϵ)]\sum_{i} \left[ \log p(z_i) - \log(1 - a_i^2 + \epsilon) \right]
    • ∴log⁡σθ(at|st)=∑i[logp(zi)−log(1−ai2+ϵ)]\therefore \log \sigma_\theta (a_t|s_t) = \sum_{i} \left[ \log p(z_i) - \log(1 - a_i^2 + \epsilon) \right]

  • Q-value calculation: Q̃(st,at)=min⁡(Qϕ1(st,at),Qϕ2(st,at))\tilde{Q}(s_{t}, a_{t})= \min(Q_{\phi_1}(s_t, a_t), Q_{\phi_2}(s_t, a_t))

  • Target V-value calculation: V̂(st)=Q̃(st,at)−αlog⁡σθ(at|st)\hat{V}(s_t) = \tilde{Q}(s_{t}, a_{t}) - \alpha \log \sigma_\theta (a_t|s_t)

  • V-network loss (MSE) calculation: JV(ψ)=𝔼st∼𝖣,at∼πθ[12(Vψ(st)−V̂(st))2]J_V(\psi) = \mathbb{E}_{s_t \sim \mathsf{D}, a_t \sim \pi_\theta} \left[ \frac{1}{2} (V_\psi(s_t) - \hat{V}(s_t))^2 \right]

    • VψV_\psi: V-network (parameters: ψ\psi)

6. Policy Loss (Actor Loss)

  • Compute the log probability of the sampled action:
    • Use the values computed earlier.
  • Compute the Q-value for the sampled action (Clipped Double Q-Learning):
    • Use the values computed earlier.
  • Policy loss calculation: Jπ(θ)=𝔼st∼𝖣,ϵt∼𝖭[αlogσθ(at|st)−Adv]J_\pi(\theta) = \mathbb{E}_{s_t \sim \mathsf{D}, \epsilon_t \sim \mathsf{N}} \left[ \alpha \log \sigma_\theta (a_t|s_t) - Adv \right] Adv=Q̃(st,at)−Vψ(st)Adv = \tilde{Q}(s_{t}, a_{t}) - V_\psi(s_t)
    • AdvAdv: advantage estimate

7. Alpha Loss (Temperature Parameter Loss)

  • Compute the log probability of the sampled action:
    • Use the values computed earlier.
  • Alpha loss calculation: J(α)=𝔼at∼πθ[−αlogπθ(at|st)−α𝖧‾]J(\alpha) = \mathbb{E}_{a_t \sim \pi_\theta} \left[ -\alpha \log \pi_\theta(a_t | s_t) - \alpha \bar{\mathsf{H}} \right]
    • 𝖧‾\bar{\mathsf{H}}: target entropy

8. Network Update

  1. Q-network updates:
  • ϕi←ϕi−λQ∇̂ϕiJQ(ϕi)\phi_i \leftarrow \phi_i - \lambda_Q \hat{\nabla}_{\phi_i} J_Q(\phi_i) for i=1,2i = 1, 2 (λQ\lambda_Q: Q-network learning rate)
  1. Update the V-network:
  • ψ←ψ−λV∇̂ψJV(ψ)\psi \leftarrow \psi - \lambda_V \hat{\nabla}_{\psi} J_V(\psi) (λV\lambda_V: V-network learning rate)
  1. (Delayed) policy network update:
  • θ←θ−λπ∇̂θJπ(θ)\theta \leftarrow \theta - \lambda_\pi \hat{\nabla}_{\theta} J_\pi(\theta) (λπ\lambda_\pi: policy learning rate)
  1. Alpha update
  • α←α−λα∇̂αJ(α)\alpha \leftarrow \alpha - \lambda_{\alpha} \hat{\nabla}_{\alpha}J(\alpha) (λα\lambda_\alpha: alpha learning rate)
  1. Update the target V-network:
  • ψ‾←τψ+(1−τ)ψ‾\bar{\psi} \leftarrow \tau \psi + (1 - \tau) \bar{\psi}

2. Define the neural network model

  • PolicyNetwork samples an action using the mean and standard deviation, then outputs it with its log probability.
  • QNetwork takes a state and an action as input and outputs a Q-value.
  • Value takes a state and outputs a V-value
def init_layer_uniform(layer: nn.Linear, init_w: float = 3e-3) -> nn.Linear:
    """Init uniform parameters on the single layer."""
    layer.weight.data.uniform_(-init_w, init_w)
    layer.bias.data.uniform_(-init_w, init_w)

    return layer


class PolicyNetwork(nn.Module):
    def __init__(self, state_dim, action_dim, hidden_dim=256, log_std_min=-20, log_std_max=2):
        super(PolicyNetwork, self).__init__()
        self.log_std_min = log_std_min
        self.log_std_max = log_std_max

        self.linear1 = nn.Linear(state_dim, hidden_dim)
        self.linear2 = nn.Linear(hidden_dim, hidden_dim)

        self.log_std_linear = nn.Linear(hidden_dim, action_dim)
        self.log_std_linear = init_layer_uniform(self.log_std_linear)
        self.mean_linear = nn.Linear(hidden_dim, action_dim)
        self.mean_linear = init_layer_uniform(self.mean_linear)

    def forward(self, state):
        x = F.relu(self.linear1(state))
        x = F.relu(self.linear2(x))

        mean = self.mean_linear(x).tanh()
        log_std = self.log_std_linear(x).tanh()
        log_std = self.log_std_min + 0.5 * (self.log_std_max - self.log_std_min) * (log_std + 1)
        std = torch.exp(log_std)

        # sampling
        dist = Normal(mean, std)
        z = dist.rsample()
        action = z.tanh()

        # Enforce action bounds (for continuous action space) 1e-7: Prevent evaluating log(0)
        log_prob = (dist.log_prob(z) - torch.log(1 - action.pow(2) + 1e-7)).sum(axis=-1, keepdim=True)

        return action, log_prob


class QNetwork(nn.Module):
    def __init__(self, state_dim, action_dim, hidden_dim=256):
        super(QNetwork, self).__init__()
        self.linear1 = nn.Linear(state_dim + action_dim, hidden_dim)
        self.linear2 = nn.Linear(hidden_dim, hidden_dim)
        self.linear3 = nn.Linear(hidden_dim, 1)
        self.linear3 = init_layer_uniform(self.linear3)

    def forward(self, state, action):
        x = torch.cat((state, action), dim=-1)
        x = F.relu(self.linear1(x))
        x = F.relu(self.linear2(x))
        x = self.linear3(x)

        return x


class VNetwork(nn.Module):  # Optional: Target V-network
    def __init__(self, state_dim, hidden_dim=256):
        super(VNetwork, self).__init__()
        self.linear1 = nn.Linear(state_dim, hidden_dim)
        self.linear2 = nn.Linear(hidden_dim, hidden_dim)
        self.linear3 = nn.Linear(hidden_dim, 1)
        self.linear3 = init_layer_uniform(self.linear3)

    def forward(self, state):
        x = F.relu(self.linear1(state))
        x = F.relu(self.linear2(x))
        x = self.linear3(x)

        return x

3. Replay Buffer class

  • Stores episode experiences in memory
  • Sample batches of step experiences from memory
class ReplayBuffer:
    """A simple numpy replay buffer."""

    def __init__(self, obs_dim: int, act_dim: int, size: int, batch_size: int = 32):
        """Initializate."""
        self.obs_buf = np.zeros([size, obs_dim], dtype=np.float32)
        self.next_obs_buf = np.zeros([size, obs_dim], dtype=np.float32)
        self.acts_buf = np.zeros([size, act_dim], dtype=np.float32)
        self.rews_buf = np.zeros([size], dtype=np.float32)
        self.done_buf = np.zeros([size], dtype=np.float32)
        self.max_size, self.batch_size = size, batch_size
        self.ptr, self.size = 0, 0

    def store(
        self,
        obs: np.ndarray,
        act: np.ndarray,
        rew: float,
        next_obs: np.ndarray,
        done: bool,
    ):
        """Store the transition in buffer."""
        self.obs_buf[self.ptr] = obs
        self.next_obs_buf[self.ptr] = next_obs
        self.acts_buf[self.ptr] = act
        self.rews_buf[self.ptr] = rew
        self.done_buf[self.ptr] = done
        self.ptr = (self.ptr + 1) % self.max_size
        self.size = min(self.size + 1, self.max_size)

    def sample_batch(self) -> Dict[str, np.ndarray]:
        """Randomly sample a batch of experiences from memory."""
        idxs = np.random.choice(self.size, size=self.batch_size, replace=False)
        return dict(
            obs=self.obs_buf[idxs],
            next_obs=self.next_obs_buf[idxs],
            acts=self.acts_buf[idxs],
            rews=self.rews_buf[idxs],
            done=self.done_buf[idxs],
        )

    def __len__(self) -> int:
        return self.size

3. SAC Agent class

  • Define an agent class that implements SAC
  • Initialize actor, critic, and value networks
  • The select_action function selects a stochastic action in a given state
  • The step function advances the environment by 1 step using the given action.
  • The update model function calculates losses and updates alpha and the actor, critic, and value networks
  • The train function trains for a fixed number of iterations
class SACAgent:
    """Simplified SAC agent interacting with environment."""
    def __init__(self, env: gym.Env, seed: int =777):
        """Initialize."""
        obs_dim = env.observation_space.shape[0]
        action_dim = env.action_space.shape[0]

        self.env = env
        self.memory = ReplayBuffer(obs_dim, action_dim, memory_size, batch_size)
        self.seed = seed

        self.device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
        print(self.device)

        # Automatic entropy tuning
        self.target_entropy = -np.prod((action_dim,)).item()  # A widely used approach, though no fixed rule exists
        self.log_alpha = torch.zeros(1, requires_grad=True, device=self.device)
        self.alpha_optim = optim.Adam([self.log_alpha], lr=lr_alpha)

        # Networks
        self.actor = PolicyNetwork(obs_dim, action_dim).to(self.device)
        self.v_net = VNetwork(obs_dim).to(self.device)
        self.target_v_net = VNetwork(obs_dim).to(self.device)
        self.target_v_net.load_state_dict(self.v_net.state_dict())
        self.q_net1 = QNetwork(obs_dim, action_dim).to(self.device)
        self.q_net2 = QNetwork(obs_dim, action_dim).to(self.device)

        # Optimizers
        self.actor_optim = optim.Adam(self.actor.parameters(), lr=lr_actor)
        self.v_optim = optim.Adam(self.v_net.parameters(), lr=lr_critic)
        self.q_optim1 = optim.Adam(self.q_net1.parameters(), lr=lr_critic)
        self.q_optim2 = optim.Adam(self.q_net2.parameters(), lr=lr_critic)

        # transition to store in memory
        self.transition = list()

        # total steps count
        self.total_step = 0

        # mode: train / test
        self.is_test = False


    def select_action(self, state: np.ndarray) -> np.ndarray:
        """Select an action from the input state."""
        if self.total_step < initial_random_steps and not self.is_test:
            selected_action = self.env.action_space.sample()
        else:
            act, _= self.actor(torch.FloatTensor(state).to(self.device))
            selected_action = act.detach().cpu().numpy()
        self.transition = [state, selected_action]

        return selected_action

    def step(self, action: np.ndarray) -> Tuple[np.ndarray, float, bool]:
        """Take an action and return the response of the env."""
        # Scale the network action output from -1~1 to the pendulum action space of -2~2
        action_input = action * self.env.action_space.high
        next_state, reward, terminated, truncated, _ = self.env.step(action_input)
        done = terminated or truncated

        if not self.is_test:
            self.transition += [reward, next_state, done]
            self.memory.store(*self.transition)

        return next_state, reward, done


    def update_model(self) -> None:
        """Update the model by gradient descent."""
        samples = self.memory.sample_batch()
        state = torch.FloatTensor(samples["obs"]).to(self.device)
        next_state = torch.FloatTensor(samples["next_obs"]).to(self.device)
        action = torch.FloatTensor(samples["acts"]).to(self.device)
        reward = torch.FloatTensor(samples["rews"].reshape(-1, 1)).to(self.device)
        done = torch.FloatTensor(samples["done"].reshape(-1, 1)).to(self.device)

        new_action, log_prob = self.actor(state)

        # train alpha (dual problem)
        alpha_loss = (-self.log_alpha.exp() * (log_prob + self.target_entropy).detach()).mean()
        self.alpha_optim.zero_grad()
        alpha_loss.backward()
        self.alpha_optim.step()
        alpha = self.log_alpha.exp()  # used for the actor loss calculation

        # q_net loss
        mask = 1 - done
        q1 = self.q_net1(state, action)
        q2 = self.q_net2(state, action)
        target_v = self.target_v_net(next_state)
        target_q = reward + gamma * target_v * mask
        q_net1_loss = F.mse_loss(q1, target_q.detach())
        q_net2_loss = F.mse_loss(q2, target_q.detach())

        # v_net loss
        v = self.v_net(state)
        q = torch.min(self.q_net1(state, new_action), self.q_net2(state, new_action))
        target_v = q - alpha * log_prob
        v_loss = F.mse_loss(v, target_v.detach())

        if self.total_step % policy_update_interval == 0:
            # actor loss
            advantage = q - v.detach()
            actor_loss = (alpha * log_prob - advantage).mean()

            # actor update
            self.actor_optim.zero_grad()
            actor_loss.backward()
            self.actor_optim.step()

            # target_v_net update
            self._target_soft_update()
        else:
            actor_loss = torch.zeros(())

        # q_net update
        self.q_optim1.zero_grad()
        q_net1_loss.backward()
        self.q_optim1.step()

        self.q_optim2.zero_grad()
        q_net2_loss.backward()
        self.q_optim2.step()

        q_loss = q_net1_loss + q_net2_loss

        # v_net update
        self.v_optim.zero_grad()
        v_loss.backward()
        self.v_optim.step()


    def train(self, num_frames: int = num_frames, plotting_interval: int = 500):
        """Train the agent."""
        self.is_test = False

        state, _ = self.env.reset(seed=self.seed)
        scores = []
        score = 0

        for self.total_step in range(1, num_frames + 1):
            action = self.select_action(state)
            next_state, reward, done = self.step(action)

            state = next_state  # Update current state
            score += reward

            if done:
                state, _ = self.env.reset(seed=self.seed)
                scores.append(score)
                score = 0

            if len(self.memory) >= batch_size and self.total_step > initial_random_steps:
                self.update_model()

            if self.total_step % plotting_interval == 0:
                self._plot(self.total_step, scores)

            # Early stop condition
            if self.total_step > initial_random_steps:
              if np.min(scores[-early_stop_patience:]) >= early_stop_threshold:
                  print(f"Early stopping triggered! at Step: {self.total_step+1} Score: {score}")
                  break

        self.env.close()


    def _target_soft_update(self):
        """Soft-update target network."""
        for target_param, param in zip(self.target_v_net.parameters(), self.v_net.parameters()):
            target_param.data.copy_(tau * param.data + (1.0 - tau) * target_param.data)

    def _plot(self, frame_idx: int, scores: List[float],):
        """Plot the training progresses."""
        clear_output(wait=True)
        plt.figure(figsize=(4, 3))
        plt.title(f"Frame: {frame_idx}, Avg. Score: {np.mean(scores[-10:]):.2f}")
        plt.plot(scores)
        plt.show()
