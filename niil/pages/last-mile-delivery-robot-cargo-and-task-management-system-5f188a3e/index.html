관련 계약

  • 말단 배송 로봇 작업 내역 확인 모듈 제작
  • 배송로봇용 화물정보 인식 모듈 시작품 설계 및 제작
  • 택배 배송로봇 작업지시 및 배송 내역 확인 모듈 제작

배송로봇이 화물을 이해하도록

적재함에 들어온 택배의 운송사·바코드·파손 정보를 읽고, 로봇과 관제시스템에 전달하는 엣지 인식 모듈을 개발했습니다. 2022–2024년 화물정보 인식과 작업지시·배송 확인 모듈을 개발했습니다.

핵심 결과

  • 엣지 모듈 통합: 카메라·조명·GPU 연산장치와 ROS 통신을 연결해 배송로봇 내부에서 인식 결과를 활용하도록 구성했습니다.
  • 송장 반복시험: 2024년 보고서는 송장 6종을 10회 반복 투입한 자체시험에서 인식 성공률 100%를 기록했다고 설명합니다.
  • 운영 환경에 맞춘 데이터: 실제 적재함의 카메라 위치와 조명을 반영한 모사환경에서 데이터를 구축했습니다.

주요 기여

화물 인식을 독립적인 화면 시연에 그치지 않고 배송로봇의 작업 흐름에 연결했습니다. 운송사 정보와 파손 인식을 통합하고, 바코드 디코딩 결과를 로봇·관제시스템이 사용할 수 있게 전달하는 구조가 핵심입니다.

검증 범위

100%는 자체 반복시험 조건에서의 결과입니다. 보고서의 공인시험 항목은 예정으로 기재되어 있습니다.
