## 상담원의 선택을 학습으로 연결한 FAQ 추천 시스템

고객 질문과 FAQ의 의미적 유사도를 학습하고, 상담원이 선택한 답변을 재학습 데이터로 변환하는 온라인 상담 지원 시스템을 구현했습니다. 언어·벡터화·검색 모델과 웹 애플리케이션, API 인터페이스 및 프로토타입을 완성했습니다.

## 핵심 성과

| 지표 | 종료 보고서의 결과 |
|---|---|
| 검색 대상 FAQ 목록 | 2,808개 |
| 상위 3개 후보 기준 정확도 | 94% |
| 처리량 | 초당 33건 |

## 주요 기여

- **의미 기반 답변 추천:** 문장 특징과 문장 간 유사성을 학습해 고객 질문에 가까운 FAQ 후보를 제시했습니다.
- **상담 피드백의 데이터화:** 상담원이 최종 선택한 답변을 학습 데이터로 자동 변환하고 재학습에 연결하는 구조를 구현했습니다.
- **서비스로 통합:** 모델 개발에 그치지 않고 웹 애플리케이션과 API, 상담 지원 프로토타입까지 연결했습니다.

## 평가 범위

수치는 2022년 종료 보고서의 연구결과 요약문에 보고된 평가 결과입니다. 공개 요약에는 시험 하드웨어, 표본 구성과 세부 평가 절차가 없어 실제 서비스의 처리량이나 정확도를 보장하는 값으로 해석하지 않습니다.
