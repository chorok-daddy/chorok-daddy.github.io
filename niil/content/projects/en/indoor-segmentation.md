## Overview

This project implements deep-learning methods that turn indoor spatial geometry into object-level information.

## Scope

- Review prior object segmentation and classification methods.
- Experiment with deep-learning algorithms and analyze results.
- Document the development environment and source-code structure.

## Application

Object-level spatial understanding supports robot perception and the use of indoor spatial information.
