주파수 응답 · 실습

Colab 노트북 다운로드Colab 실행 ↗

학습 목표

주파수마다 입력의 진폭과 위상이 어떻게 변하는지 알면 Bode plot을 실제 신호와 연결할 수 있습니다.

실행 조건

원본의 오래된 bode 반환값 분해 대신 ctl.frequency_response의 magnitude·phase를 사용합니다. phase는 radian이므로 표에는 degree로 변환하세요.

정현파로 이득·위상 측정

시작 조건

G=1/(s²+.5s+1), u=sin(ωt), ω=.2,1,3 rad/s. t=0~200 s, Δt=.01 s입니다.

진행 방법

  1. forced_response로 출력을 계산하고 마지막 두 주기만 골라 입력과 출력을 그리세요.
  2. 출력을 asin(ωt)+bcos(ωt)에 최소제곱 적합해 이득 sqrt(a²+b²)와 위상 atan2(b,a)를 구하세요.
  3. frequency_response가 주는 이득·위상과 같은 단위로 비교하세요.

남길 결과

  • 주파수 3행 표와 마지막 두 주기의 비교 그림 3개. 
import numpy as np
import matplotlib.pyplot as plt
import control as ctl
s = ctl.tf('s')
G=1/(s*s+.5*s+1)
omega=1.;t=np.arange(0,200,.01);u=np.sin(omega*t)
response=ctl.forced_response(G,t,u)
y=np.asarray(response.outputs).reshape(-1)
keep=t>=t[-1]-4*np.pi/omega

Damping과 공진 비교

시작 조건

분모를 s²+a*s+1로 두고 a=.2,.5,1을 비교합니다. ω는 logspace(-2,2,400)입니다.

진행 방법

  1. 세 모델의 이득·위상을 같은 주파수축에 그리세요.
  2. 각 모델의 최대 이득과 그 주파수, DC Gain을 표로 적으세요.
  3. 최대 이득 부근의 정현파 한 조건을 골라 첫 활동의 방법으로 확인하세요.

남길 결과

  • Bode 형태의 그림 1세트와 공진 비교 표. 
import numpy as np
import matplotlib.pyplot as plt
import control as ctl
s = ctl.tf('s')
omega=np.logspace(-2,2,400)
for a in [.2,.5,1.]:
    response=ctl.frequency_response(1/(s*s+a*s+1),omega)
    print(a,np.max(response.magnitude))
