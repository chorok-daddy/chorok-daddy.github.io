기준 Plant와 Lead 설계점

시작 조건

G=40/(s(s+2)). 원본의 목표 ζ=.4, ωn=10 rad/s를 사용합니다.

진행 방법

  1. 목표 복소 Pole의 실수부·허수부를 계산하고 Root Locus 위에 표시하세요.
  2. 원본 Lead 설계 절차로 Zero·Pole·Gain을 정하고 보상기 식을 표에 적으세요.
  3. 선택한 지점과 실제 Closed-loop Pole의 거리를 계산하세요.

import matplotlib.pyplot as plt
import control as ctl
