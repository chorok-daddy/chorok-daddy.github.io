학습 목표

같은 계수라도 연결 방식이나 상쇄 조건에 따라 응답이 달라집니다. 계수에서 동작을 예측하는 연습입니다.

실행 조건

Pole과 Zero는 python-control의 ctl.poles와 ctl.zeros로 구합니다.

모듈이 없으면 Colab·Jupyter 코드 셀에서 %pip install control==0.10.2를 실행하세요.

계수에서 Pole·Zero로

  • num: 분자 다항식의 계수 배열.
  • den: 분모 다항식의 계수 배열.
  • 배열 순서: 차수가 높은 항부터.

시작 조건

  • A: num=[2]\mathrm{num}=[2], den=[5,1]\mathrm{den}=[5,1].
  • B: num=[1,2]\mathrm{num}=[1,2], den=[1,3,2]\mathrm{den}=[1,3,2].
  • C: num=[1,1]\mathrm{num}=[1,1], den=[1,2,5]\mathrm{den}=[1,2,5].

진행 방법

  1. A를 기준 예제로 실행하세요. 분자·분모를 다항식으로 쓰고 np.roots와 ctl.poles/ctl.zeros로 계산합니다.
  2. B와 C에도 같은 절차를 적용하세요. 분자·분모의 차수와 유한 Zero 개수를 구분하고, 복소근은 실수부·허수부를 함께 기록합니다.
  3. 세 모델의 Pole·Zero를 한 복소평면에 표시하세요. Pole은 ×, Zero는 ○로 구분하고 모델별 색을 달리합니다.

직렬·병렬·Feedback 대조

시작 조건

H1(s)=2sH_1(s)=\frac2s, H2(s)=34s+1H_2(s)=\frac3{4s+1}. Feedback은 H1H2H_1H_2에 대한 음의 단위 Feedback입니다.

진행 방법

  1. Hs=H1H2H_s=H_1H_2, Hp=H1+H2H_p=H_1+H_2, T=Hs1+HsT=\frac{H_s}{1+H_s}를 식으로 구하세요.
  2. ctl.series, ctl.parallel, ctl.feedback로 같은 모델을 만들고, ω=[0.1,1,10] rad/s에서 직접 만든 식과 비교하세요.
  3. T의 Unit Step을 0≤t≤500\le t\le 50 s에서 그리세요. Hs·Hp의 원점 Pole과 DC Gain의 의미를 구분합니다.

남길 결과

  • 연결 3종의 계수 표 1개와 T의 Step plot 1개.
  • 오차는 같은 주파수에서 복소 응답 차이의 절댓값으로 기록합니다. 
import numpy as np
import matplotlib.pyplot as plt
import control as ctl
s = ctl.tf('s')
H1=ctl.tf([2],[1,0]); H2=ctl.tf([3],[4,1])
Hs=ctl.series(H1,H2); Hp=ctl.parallel(H1,H2); T=ctl.feedback(Hs,1)
print(Hs, Hp, T)
t=np.linspace(0,50,2501)
t,y=ctl.step_response(T,t)
plt.plot(t,y); plt.xlabel('Time [s]'); plt.ylabel('Output'); plt.grid()
