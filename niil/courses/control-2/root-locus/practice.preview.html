실행 준비

Python 경로는 python-control을 사용합니다. 모듈이 없으면 Colab·Jupyter의 코드 셀에서 %pip install control==0.10.2를 실행하세요.

학습 목표

Gain 하나를 고르는 문제가 Pole 위치와 Time Response에 어떻게 이어지는지 확인합니다.

Gain과 Closed-loop Pole

시작 조건

L(s)=s+7s(s+5)(s+15)(s+20)L(s)=\frac{s+7}{s(s+5)(s+15)(s+20)}. K∈{100,500,1000}K\in\{100,500,1000\}을 사용합니다.

진행 방법

  1. Root Locus를 그리고 각 K에서 feedback(K*L,1)의 Pole을 별도 기호로 표시하세요.
  2. 각 Pole의 실수부와 안정 여부를 표에 기록하세요.
  3. 기준 조건 K=500K=500에 비해 Pole 이동과 응답 변화의 예상을 적으세요.

남길 결과

  • Root Locus 그림 1개와 K별 Pole 표. 
import numpy as np
import matplotlib.pyplot as plt
import control as ctl
s = ctl.tf('s')
L=(s+7)/(s*(s+5)*(s+15)*(s+20))
ctl.root_locus_plot(L)
for k in [100,500,1000]: print(k,ctl.poles(ctl.feedback(k*L,1)))

import numpy as np
import matplotlib.pyplot as plt
import control as ctl
s = ctl.tf('s')
L=(s+7)/(s*(s+5)*(s+15)*(s+20))
t=np.linspace(0,8,1601)
T=ctl.feedback(500*L,1)
t,y=ctl.step_response(T,t)
plt.plot(t,y);plt.xlabel('Time [s]');plt.grid()
