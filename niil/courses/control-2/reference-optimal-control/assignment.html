참조입력과 최적제어

안정한 제어기에서도 목표값 오차가 남는 이유를 확인하고, 추종 성능과 제어입력 비용을 비교합니다.

실습 전에

01 안정한 시스템이면 목표값도 정확히 따라갈까요?

설명

안정성은 초기 상태와 입력에 대한 응답의 성질이고, 목표값의 Steady State 오차는 입력·출력 경로의 이득에도 달려 있습니다.

02 Q를 키우면 무엇을 더 중요하게 보나요?

설명

해당 상태가 기준에서 벗어나는 비용을 더 크게 봅니다. 출력 오차와 제어입력은 별도로 기록해 절충을 확인합니다.
