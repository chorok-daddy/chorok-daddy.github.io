이번에 배울 내용

위치만 측정하는 시스템에서 속도를 추정해 제어하고, 추정 속도와 잡음 민감도를 함께 비교합니다.

설계 전에 확인할 두 조건

Controllability는 입력으로 상태를 움직일 수 있는지, Observability는 출력의 시간 변화로 초기 상태를 구분할 수 있는지를 묻습니다. 두 상태 모델에서는 [B, AB]와 [C; CA]의 rank를 상태 수 2와 비교합니다.

측정하지 않은 상태로 제어하기

State Feedback u=−Kx+Nr에서 속도를 직접 측정하지 못하면 추정 상태를 사용합니다. Observer는 모델 예측에 측정 오차를 더해 갱신합니다.

x̂̇=Ax̂+Bu+L(y−Cx̂)\dot{\hat x}=A\hat x+Bu+L(y-C\hat x)

ė=(A−LC)e\dot e=(A-LC)e

이상적인 선형 모델에서는 제어기와 추정기의 Pole을 따로 설계할 수 있습니다. 하지만 Observer를 지나치게 빠르게 하면 측정 잡음이 제어입력으로 전달되는 영향도 살펴봐야 합니다.

MATLAB으로 같은 설계 확인하기

Control System Toolbox의 place·ss·lsim을 사용합니다. 배열의 값과 설계 조건은 Python 예제와 같습니다.

MATLAB 코드 다운로드

같은 모델의 제어기와 추정기

두 Pole 배치 결과를 계산하고 입력과 무관한 추정 오차의 수렴을 확인합니다. 

import numpy as np
from scipy.signal import place_poles, StateSpace, lsim
import matplotlib.pyplot as plt
A=np.array([[0.,1.],[-2.,-3.]])
B=np.array([[0.],[1.]])
C=np.array([[1.,0.]])
K=place_poles(A,B,[-2.,-4.]).gain_matrix
L=place_poles(A.T,C.T,[-8.,-10.]).gain_matrix.T
print('K =',K,'L =',L.ravel())
assert np.allclose(K,[[6.,3.]]) and np.allclose(L.ravel(),[15.,33.])
t=np.linspace(0,4,801)
_,error,_=lsim(StateSpace(A-L@C,np.zeros((2,1)),np.eye(2),np.zeros((2,1))),np.zeros(len(t)),t,X0=[1.,0.])
fig,axes=plt.subplots(2,1,sharex=True)
for j,unit in enumerate(['Position error [m]','Velocity error [m/s]']):
    axes[j].plot(t,error[:,j]);axes[j].set_ylabel(unit);axes[j].grid()
axes[-1].set_xlabel('Time [s]')
print('error at 4 s:',error[-1])

K = [[6. 3.]] L = [15. 33.]
error at 4 s: [-3.16455446e-14 -2.21548551e-13]
