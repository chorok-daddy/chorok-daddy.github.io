온도 모델의 계단응답 읽기

문제 상황

히터 전력 입력 P [W]에 대한 외기 대비 온도 차 θ [K]의 전달함수는 G(s)=2/(4s+1)입니다. 시간 단위는 s이며 초기 온도 차는 0입니다. 입력 크기 1 W인 계단응답을 t=0,2,4,6,8에서 읽습니다.

이해하고 적용할 내용

  • 전달함수의 계수·입력 크기와 응답의 최종값·속도를 연결하기
  • 반환 배열의 시간 대응과 선택 조건을 추적하고, 일부 시점의 값과 정상상태 값을 구분하기

참고자료로 확인할 정보

step 계열 함수의 반환 형식·배열 크기와 표본 선택 문법은 제공 API 요약을 사용합니다.

제공 참고자료

tf(num,den)
s의 내림차순 계수로 전달함수를 만듭니다. tf(2,[4 1])은 2/(4s+1)입니다.
[y,t_out]=step(g,t)
이 사례의 단일 입력·단일 출력 모델에서 지정한 시간의 단위 계단응답을 반환합니다. 열벡터 t를 주면 y와 t_out은 같은 길이의 열벡터입니다.
dcgain(g)
연속시간 모델의 s=0 이득을 반환합니다. 이 사례의 단위는 K/W입니다. 안정한 모델의 일정 입력에 대한 최종 출력은 이 이득과 입력 크기를 곱한 값입니다.
연산·응답식
(0:2:8)'은 [0;2;4;6;8]. y(mask)는 참인 위치를 고릅니다. G=K/(τs+1)의 영 초기조건 단위 계단응답은 y(t)=K(1−e^(−t/τ))입니다.
계산용 지수값
e^(−0.5)≈0.6065, e^(−1)≈0.3679, e^(−1.5)≈0.2231, e^(−2)≈0.1353. 소수 넷째 자리 수준의 근삿값이면 충분합니다.
원문 문서
  • MATLAB step
  • MATLAB dcgain
g = tf(2,[4 1]);
t = (0:2:8)';
[y,t_out] = step(g,t);
gain = dcgain(g);
picked = y(t_out >= 4);
plot(t_out,y);
xlabel('Time [s]');
ylabel('Temperature rise [K]');

문항

  1. g의 전달함수와 gain의 값·단위를 쓰세요. 입력이 크기 3 W인 계단으로 바뀌면 최종 출력이 어떻게 바뀌는지도 설명하세요.
  2. t_out과 y의 값·배열 크기를 쓰세요. 응답식에 t=4를 대입한 계산을 보이세요.
  3. picked의 값·배열 크기를 쓰고, 조건을 t_out>4로 바꾸면 어떤 시점이 빠지는지 설명하세요.
  4. 분모를 [8 1]로 바꾼 두 번째 모델의 응답을 같은 좌표축에 개략적으로 그리세요. 초기값·최종값·상대적인 응답 속도를 표시하고, t=8의 값이 최종값과 다른 이유도 설명하세요.
답안 작성 예시
  1. G(s)=2/(4s+1), gain=G(0)=2 K/W입니다. 1 W 계단의 최종 온도 차는 2 K, 3 W 계단에서는 6 K입니다. 입력 크기가 바뀌어도 모델의 이득은 2 K/W로 같습니다.
  2. t_out=[0;2;4;6;8], y≈[0;0.7869;1.2642;1.5537;1.7293]로 둘 다 5×1입니다. y(4)=2(1−e^(−1))≈1.2642입니다.
  3. picked≈[1.2642;1.5537;1.7293], 3×1입니다. >4로 바꾸면 t=4 표본이 빠져 [1.5537;1.7293], 2×1이 됩니다.
  4. 기준은 y=2(1−e^(−t/4)), 변경 후는 2(1−e^(−t/8))입니다. 두 곡선은 0에서 시작해 2로 접근하지만 변경 모델이 더 느립니다. t=8은 유한한 관찰 시점이므로 기준도 약 1.7293이며 아직 최종값 2에 도달하지 않았습니다.
