온도 모델의 Step Response 읽기

문제 상황

히터 전력 입력 P [W]에 대한 외기 대비 온도 차 θ[K]\theta\,[\mathrm K]의 Transfer Function은 G(s)=24s+1G(s)=\frac2{4s+1}입니다. 시간 단위는 s이며 초기 온도 차는 0입니다. 입력 크기 1 W인 Step Response를 t=0,2,4,6,8t=0,2,4,6,8에서 읽습니다.

이해하고 적용할 내용

  • Transfer Function의 계수·입력 크기와 응답의 최종값·속도를 연결하기
  • 반환 배열의 시간 대응과 선택 조건을 추적하고, 일부 시점의 값과 Steady State 값을 구분하기

제공 참고자료

ct.tf(num,den)
s의 내림차순 계수로 Transfer Function을 만듭니다. ct.tf([2],[4,1])은 24s+1\frac2{4s+1}입니다.
ct.step_response(g,timepts=t,squeeze=True)
지정한 시간의 영 Initial Condition 단위 Step Response를 반환합니다. 이 단일 입력·단일 출력 사례에서 response.time과 response.outputs는 길이가 같은 1차원 배열입니다.
ct.dcgain(g)
연속시간 모델의 s=0s=0 이득을 반환합니다. 이 사례의 단위는 K/W입니다. 안정한 모델의 일정 입력에 대한 최종 출력은 이 이득과 입력 크기를 곱한 값입니다.
배열·응답식
np.arange(0,9,2)는 9 미만까지 2씩 증가하는 [0,2,4,6,8]입니다. y[mask]는 참인 위치를 선택합니다. G(s)=Kτs+1G(s)=\frac K{\tau s+1}의 단위 Step Response는 y(t)=K(1−e−t/τ)y(t)=K(1-e^{-t/\tau})입니다.
계산용 지수값
e−0.5≈0.6065e^{-0.5}\approx0.6065, e−1≈0.3679e^{-1}\approx0.3679, e−1.5≈0.2231e^{-1.5}\approx0.2231, e−2≈0.1353e^{-2}\approx0.1353. 소수 넷째 자리 수준의 근삿값이면 충분합니다.
원문 문서
  • Python Control step_response
  • Python Control dcgain
import control as ct
import numpy as np
import matplotlib.pyplot as plt

g = ct.tf([2],[4,1])
t = np.arange(0,9,2)
response = ct.step_response(g,timepts=t,squeeze=True)
t_out = response.time
y = response.outputs
gain = ct.dcgain(g)
picked = y[t_out >= 4]
plt.plot(t_out,y)
plt.xlabel('Time [s]')
plt.ylabel('Temperature rise [K]')

답안 작성 예시
  1. G(s)=24s+1G(s)=\frac2{4s+1}, gain=G(0)=2K/W\mathrm{gain}=G(0)=2\,\mathrm{K/W}입니다. 1 W 계단의 최종 온도 차는 2 K, 3 W 계단에서는 6 K입니다. 입력 크기가 바뀌어도 모델의 이득은 2 K/W로 같습니다.
  2. t_out=[0,2,4,6,8], y≈[0,0.7869,1.2642,1.5537,1.7293]로 둘 다 shape (5,)입니다. y(4)=2(1−e−1)≈1.2642y(4)=2(1-e^{-1})\approx1.2642입니다.
  3. picked≈[1.2642,1.5537,1.7293], shape (3,)입니다. >4이면 t=4 표본이 빠져 [1.5537,1.7293], shape (2,)가 됩니다.
  4. 기준은 y(t)=2(1−e−t/4)y(t)=2(1-e^{-t/4}), 변경 후는 2(1−e−t/8)2(1-e^{-t/8})입니다. 두 곡선은 0에서 시작해 2로 접근하지만 변경 모델이 더 느립니다. t=8은 유한한 관찰 시점이므로 기준도 약 1.7293이며 아직 최종값 2에 도달하지 않았습니다.
