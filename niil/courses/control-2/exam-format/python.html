Python 코드 해석 시험 예시

일별 주문 수 집계

코드를 실행하지 않고 값·배열 크기·처리 과정을 손으로 설명하는 형식 예시입니다.

문항 예시

orders의 각 행은 1·2·3일차, 각 열은 매장·온라인·전화 주문 수입니다. 하루 총 주문 수가 6건 이상인 날을 고릅니다.

제공 참고자료

X.sum(axis=0)
각 열의 합을 열 수 길이의 1차원 배열로 반환합니다.
X.sum(axis=1)
각 행의 합을 행 수 길이의 1차원 배열로 반환합니다.
X[:, j]
인덱스 j인 열 전체를 선택합니다. Python의 인덱스는 0부터 시작합니다.
v[mask]
mask가 True인 위치의 원소를 선택합니다.
plt.bar(x, y)
x 위치에 높이 y인 막대를 그립니다.
import numpy as np
import matplotlib.pyplot as plt

orders = np.array([[2, 0, 3],
                   [1, 5, 0],
                   [0, 2, 5]])
daily = ________       # 일별 총 주문 수
online = orders[:, 1]
busy = daily >= 6
result = daily[busy]
plt.bar([1, 2, 3], daily)
plt.xlabel('Day')
plt.ylabel('Orders')
  1. daily 계산의 빈칸을 한 줄로 채우세요.
  2. daily, online, busy, result의 값과 shape를 각각 쓰세요.
  3. daily >= 6을 daily > 6으로 바꾸면 선택 결과가 어떻게 달라지는지 설명하세요.
  4. 막대그래프를 개략적으로 그리세요. orders.sum(axis=0)을 썼을 때 일별 집계가 되지 않는 이유도 설명하세요.
답안 작성 예시
  1. orders.sum(axis=1). 각 행이 하루이므로 같은 행의 세 주문 채널을 합합니다.
  2. daily=[5, 6, 7], online=[0, 5, 2], busy=[False, True, True]는 모두 shape (3,)인 1차원 배열입니다. busy의 dtype은 bool입니다. result=[6, 7]의 shape는 (2,)입니다.
  3. busy=[False, False, True], result=[7] (shape (1,))이 됩니다. 총 6건인 2일차가 제외되며, 선택 결과는 원소가 하나여도 1차원 배열입니다.
  4. 가로축은 Day 1·2·3, 세로축은 Orders이고 막대 높이는 5·6·7입니다. orders.sum(axis=0)은 채널별 3일 합계 [3, 7, 8] (shape (3,))이므로 일별 합계와 의미가 다릅니다.

답안에 담을 내용

  • 값과 함께 shape를 쓰고, 1차원 배열과 스칼라를 구분합니다.
  • 열 인덱스와 합산 축을 데이터의 행·열 의미에 맞춰 설명합니다.
  • 그래프에는 축 이름과 막대 높이가 드러나도록 표시합니다.
