이번에 배울 내용

시간 영역의 미분방정식을 변환해 푼 답이 원래 문제를 만족하는지 직접 검증합니다.

전체 흐름

미분방정식·초기값 → s 영역의 식 → Y(s) → 시간응답·잔차

식과 적용 범위를 함께 보기

분수식의 공통 인자를 지우면 계산은 쉬워집니다. 하지만 원래 분모가 0이 되는 값은 계속 제외해야 합니다. 예를 들어 (x−1)/(x−1)은 x≠1에서 1이고, x=1에서는 원래 식에 값을 대입할 수 없습니다.

미분방정식을 대수식으로 바꾸기

y′+2y=1에 Laplace 변환을 적용하면 입력과 초기 상태의 영향이 별도 항으로 나타납니다.

(s+2)Y(s)=1s+y(0)(s+2)Y(s)=\frac{1}{s}+y(0)

초기값이 다를 때의 두 해는 다음과 같습니다.

y(t)=12+(y(0)−12)e−2ty(t)=\frac12+\left(y(0)-\frac12\right)e^{-2t}

y(0)=0과 1을 대입하면 정상상태 값은 같고 시작점과 과도응답은 달라집니다.

초기값이 다른 두 응답

y′+2y=1에서 y(0)=0과 1을 비교합니다. 두 해를 같은 시간축으로 그리고 초기값·정상상태 값을 확인합니다. 

import numpy as np
import matplotlib.pyplot as plt
t=np.linspace(0,4,401)
for initial in [0,1]:
    y=.5+(initial-.5)*np.exp(-2*t)
    plt.plot(t,y,label=f'y(0)={initial}')
plt.axhline(.5,color='gray',linestyle='--');plt.xlabel('Time [s]');plt.ylabel('y');plt.legend();plt.grid()
