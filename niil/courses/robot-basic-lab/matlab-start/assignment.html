MATLAB 시작과 Live Script

명령을 실행하고 변수를 확인한 뒤, 입력 조건과 결과가 함께 남는 Live Script를 만듭니다.

실습 전에

01 세미콜론을 붙이면 변수도 사라질까요?

설명

화면 출력만 생략합니다. 변수는 Workspace에 남습니다.

02 일부 Section만 실행해도 항상 같은 결과일까요?

설명

앞서 정의한 변수의 현재 값에 영향을 받을 수 있어 입력부터 다시 실행해 확인해야 합니다.

실행 조건

MATLAB 또는 MATLAB Online을 사용합니다. 기본 활동은 MATLAB만으로 실행하며 드론 연결은 필요하지 않습니다.

실습

실습용 mlx 스크립트 미리보기실습용 mlx 스크립트 다운로드

1. 입력과 단위부터 확인하기

시작 조건

거리 .5 m, 속도 .25 m/s로 시작합니다.

진행 방법

  1. 변수를 만들고 Workspace에서 이름·값·크기를 확인하세요.
  2. 이동 시간을 계산하고 세미콜론 유무에 따른 표시 차이를 확인하세요.

남길 결과

  • 단위를 표시한 계산 예와 변수 목록.
기록 항목과 확인할 점
거리 [m]
속도 [m/s]
시간 [s]

확인할 점

  • 속도와 시간을 서로 다른 변수로 보관했는가?
  • 단위를 바꾸지 않고 계산값을 비교했는가?

2. 스크립트로 묶고 조건 바꾸기

시작 조건

거리를 .5→.8 m로 바꾸고 속도는 .25 m/s로 유지합니다.

진행 방법

  1. 입력·계산·결과 설명을 별도 Section으로 정리하세요.
  2. 거리만 바꿔 다시 실행하고 두 조건의 시간을 비교하세요.
  3. 입력 정의 없이 계산 Section만 실행하면 어떤 변수에 의존하는지 확인하세요.

남길 결과

  • 두 조건 비교와 입력→계산→출력 순서의 Live Script.
기록 항목과 확인할 점
조건
거리 [m]
속도 [m/s]
계산 시간 [s]

확인할 점

  • 출력만 복사하지 않고 입력 정의도 저장했는가?
  • 변경한 조건과 마지막 출력이 같은 실험인가?

3. 오류 메시지로 수정 지점 찾기

시작 조건

speed_mps를 speed_ms로 잘못 쓴 경우와 speed_mps=0인 경우를 살펴봅니다.

진행 방법

  1. 오타와 0으로 나눈 결과를 별도로 확인하세요.
  2. 이동 시간을 계산하기 전에 speed_mps>0인지 검사하세요.
  3. 파일을 처음부터 실행해 입력·검사·계산이 모두 수행되는지 확인하세요.
