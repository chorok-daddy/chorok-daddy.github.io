MATLAB 시작과 Live Script · 학습

이번에 배울 내용

명령을 실행하고 변수를 확인한 뒤, 입력 조건과 결과가 함께 남는 Live Script를 만듭니다.

Command Window와 Workspace

Command Window에서 계산을 실행하면 변수와 값이 Workspace에 남습니다. 세미콜론은 화면 출력을 생략하며 변수 저장 여부를 바꾸지 않습니다. 먼저 짧은 명령으로 결과를 확인한 뒤 Live Script에 옮깁니다.

코드를 다시 실행할 수 있게 쓰기

Live Script는 설명·코드·출력을 한 문서에 둡니다. 입력 변수는 사용하는 코드보다 앞에서 정의하고, 이름에 단위를 드러내면 거리·시간을 혼동하기 어렵습니다. 파일을 새로 열어 위에서부터 실행해도 같은 결과가 나와야 합니다.

Onramp와 연결하기

공식 Onramp의 Commands와 MATLAB Desktop and Editor에서 명령 입력·변수·스크립트 실행을 체험합니다. 아래 예제에서는 그 기능으로 이동 거리와 시간을 계산합니다.

풀이 예제

0.6 m를 0.3 m/s로 이동하는 데 필요한 시간을 계산합니다. 계산만 수행하며 드론 명령은 보내지 않습니다.
distance_m=0.6;
speed_mps=0.3;
travel_time_s=distance_m/speed_mps;
angle_deg=90; angle_rad=deg2rad(angle_deg);
disp(travel_time_s); disp(angle_rad);
assert(abs(travel_time_s-2)<1e-12);

예제 결과

이동 시간은 2초이고 90도는 π/2 rad입니다.
