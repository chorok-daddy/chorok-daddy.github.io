1. 내 Repository에 대상 Repo를 Fork하기

  • 직접 해당 repo의 url을 알아내 찾아가야한다
  • 우측 상단에 fork 클릭
  • 클릭하면 별도의 확인절차 없이 fork된다

2. 내 Local Repository에 Clone하기

  • Fork 이후에는, 마치 내 Repository인 것처럼 사용하면 된다
  • 편의상, ’Fork해 사용하는 사람’의 Local 드라이브 대신, 구글드라이브에 임시 폴더에서 진행한다
