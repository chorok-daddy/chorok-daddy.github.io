Timestamp 간격에 따른 Vertical Velocity 계산

시작 조건 t=[0,1,2,4] s, 높이=[0,.4,.9,.7] m입니다. 진행 방법 1. diff로 높이 변화와 시간 간격을 구하고 구간 평균 Vertical Velocity를 계산하세요. 2. Height와 Vertical Velocity를 별도 그래프에 그리세요. 속도 표본을 어느 시각에 놓았는지 표시합니다. 3. 마지막 시간 간격도 1초라고 가정한 결과와 비교하세요. 남길 결과 - Height·Vertical Velocity 그림과 마지막 구간의 비교.
t=[0;1;2;4];height_m=[0;.4;.9;.7];
velocity_mps=diff(height_m)./diff(t);
midpoint_s=(t(1:end-1)+t(2:end))/2;
plot(midpoint_s,velocity_mps,'o-');xlabel('Time [s]');ylabel('Velocity [m/s]');grid on;

계산 규칙을 함수로 재사용하기

시작 조건 segmentLength=@(dx,dy) hypot(dx,dy)를 새 좌표 변화에도 적용합니다. 진행 방법 1. 길이가 같은 두 벡터를 함수에 전달하세요. 2. 한 입력은 행벡터, 다른 입력은 열벡터인 경우 크기가 어떻게 되는지 확인하세요. 3. 같은 shape의 입력만 받도록 검사하거나 입력 shape를 통일하세요. 남길 결과 - 작은 재사용 함수와 잘못된 입력 예 1개.
segmentLength=@(dx,dy) hypot(dx,dy);
