dx=[0.30.40]\mathrm{dx}=\begin{bmatrix}0.3&0.4&0\end{bmatrix}, dy=[0.400.2]\mathrm{dy}=\begin{bmatrix}0.4&0&0.2\end{bmatrix}를 열벡터로 만듭니다.

2. Timestamp 간격에 따른 Vertical Velocity 계산

시작 조건

t=[0124]t=\begin{bmatrix}0&1&2&4\end{bmatrix} s, 높이=[0,.4,.9,.7] m입니다.

진행 방법

  1. diff(height)와 diff(t)를 구하고 원소별로 나누어 세 구간의 평균 Vertical Velocity를 계산하세요.
  2. Height는 측정 시각에, Vertical Velocity는 각 구간의 중간 시각에 그리세요. 각 그래프의 축 이름과 단위를 표시하세요.
  3. 마지막 구간 22–44 s에서 실제 시간 차를 쓴 값과 1 s라고 가정한 값을 각각 계산하세요. Height 변화량·사용한 시간 차·계산한 Vertical Velocity를 두 행으로 적어 차이를 설명하세요.
