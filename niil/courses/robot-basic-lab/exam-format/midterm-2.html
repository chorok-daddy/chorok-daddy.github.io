배터리 조건과 반복 중단

중간시험 · 예시 2

문제 상황

각 이동 전 배터리가 [70,55,18,16]%입니다. 20% 미만이면 이동을 시작하지 않고 반복을 끝냅니다.

이해하고 적용할 내용

  • 반복문의 실행 순서와 검사 시점을 추적하기
  • 경계값과 중단·건너뛰기의 차이를 실제 동작에 연결하기

제공 참고자료

break / continue
break는 가장 안쪽 반복문을 끝냅니다. continue는 해당 반복의 나머지를 생략하고 다음 반복으로 갑니다.
검사 시점
levels는 이동 직전에 얻은 배터리 값입니다. 조건이 참이면 그 구간은 실행하지 않습니다.
경계
x<20은 20을 포함하지 않고 x≤20은 포함합니다. Python에서는 ≤를 <=로 씁니다.
levels = [70,55,18,16]
for battery in levels:
    if battery < 20:
        break
    move_one_segment()

문항

  1. 구간 번호별 배터리와 실행 여부를 쓰고, 실제 이동 횟수·중단 위치를 구하세요.
  2. 기준을 <=20으로 바꿀 때 현재 자료의 결과가 바뀌는지 설명하세요.
  3. levels=[70,20,18,55]일 때 <20과 <=20의 이동 횟수를 각각 구하세요.
  4. 원래 코드에서 break를 continue로 바꾸면 위 새 자료에서 몇 구간을 실행하는지 쓰고, 연속 비행 정책으로 적절한지 설명하세요.
답안 작성 예시
  1. 1구간 70% 실행, 2구간 55% 실행, 3구간 18%에서 중단합니다. 4구간은 검사하지 않으며 총 두 번 이동합니다.
  2. 정확히 20%인 값이 없으므로 현재 자료의 결과는 같습니다.
  3. <20이면 70·20%에서 두 번 이동 후 3구간에서 중단합니다. <=20이면 두 번째 값에서 중단해 한 번 이동합니다.
  4. <20 조건에서 continue를 쓰면 70·20·55%인 세 구간이 실행됩니다. 배터리 저하 후 작업을 종료하려는 정책이라면 중단 이후 재개되는 continue는 맞지 않습니다.
