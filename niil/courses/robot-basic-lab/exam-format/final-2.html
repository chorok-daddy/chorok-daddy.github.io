영상 오차와 명령 한계

기말시험 · 예시 2

문제 상황

영상 중심 x=80, 검출 중심 x=120입니다. e=x_detect−80, u=clip(.02*e,−.5,.5)입니다.

이해하고 적용할 내용

  • 오차의 부호·비례 이득·포화를 순서대로 해석하기
  • 검출의 유효성을 확인한 뒤 이동 명령을 결정하기

참고자료로 확인할 정보

clip과 좌표·명령 규약은 아래 자료에서 확인합니다.

제공 참고자료

np.clip(v,lo,hi)
v가 lo보다 작으면 lo, hi보다 크면 hi, 사이면 v를 반환합니다.
좌표·명령 규약
e=x_detect−80 [pixel]. u>0은 오른쪽, u<0은 왼쪽 명령입니다. 명령 범위는 −0.5≤u≤0.5입니다.
검출 실패 정책
검출이 None이면 u=0으로 전환하고 새 유효 검출을 기다립니다.
원문 문서
  • NumPy clip
u=np.clip(.02*e,-.5,.5)

문항

  1. x_detect=120일 때 오차·포화 전 명령·최종 명령을 순서대로 쓰세요.
  2. x_detect=60일 때도 같은 값을 구하고 이동 방향을 설명하세요.
  3. 검출이 80을 지나는 경우와 명령 포화가 시작되는 경계 좌표를 구하세요.
  4. 검출이 None일 때 이전 명령을 유지하는 것과 제공된 정책을 비교하세요.
답안 작성 예시
  1. e=40 pixel, 0.02e=0.8, clip 후 u=0.5로 오른쪽 명령입니다.
  2. e=−20 pixel, 0.02e=−0.4, u=−0.4로 왼쪽 명령입니다.
  3. 중심 80에서는 u=0. 포화 경계는 |0.02e|=0.5, 즉 |e|=25이므로 x=55·105입니다. 이 범위 밖의 명령은 ±0.5로 제한됩니다.
  4. 이전 명령을 유지하면 대상을 잃은 상태에서도 이동할 수 있습니다. 제공 정책은 u=0으로 멈추고 검출이 다시 유효해질 때 갱신합니다.
