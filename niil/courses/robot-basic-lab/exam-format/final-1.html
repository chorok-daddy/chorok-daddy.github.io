시험 형식과 답안 작성 예시

Mask의 중심 좌표

이 자료는 시험 형식과 답안 작성 수준을 보여주는 예시이며, 예상문제가 아닙니다. 시험 준비는 공지된 출제 범위를 기준으로 하세요.

문제 상황

검출 Pixel의 (row,col)은 (10,20),(10,22),(12,20),(12,22)입니다. 아래 rows와 cols에는 각각 행 좌표와 열 좌표를 저장했습니다.

답안 작성 포인트

  • 영상 배열의 행·열과 기하 좌표 x·y를 구분하기
  • 검출 실패 상태를 유효 좌표와 구별해 다음 동작을 결정하기

제공 참고자료

좌표 규약
이 사례의 영상 좌표는 0부터 셉니다. Pixel 좌표는 (row,col), 출력 중심은 (x,y)=(열 평균,행 평균)입니다.
평균
선택된 n개 좌표의 평균은 합/n입니다.
미검출 규약
이 사례의 검출 함수는 Pixel이 없으면 valid=False, center=None을 반환합니다. 정지 명령을 내고 새 영상을 기다리도록 정합니다.
rows = [10 10 12 12];
cols = [20 22 20 22];
x = mean(cols);
y = mean(rows);

문항

  1. 중심 (x,y)를 대입 과정과 함께 구하세요.
  2. 마지막 Pixel (12,22) 하나가 빠졌을 때 중심을 다시 구하고 이동 방향을 설명하세요.
  3. Pixel이 하나도 없을 때 반환 상태와 다음 동작을 쓰세요.
  4. 검출 중심이 실제로 (0,0)인 경우와 미검출을 구별해 기록하는 방법을 설명하세요.
답안 작성 예시
  1. x=20+22+20+224=21x=\frac{20+22+20+22}4=21, y=10+10+12+124=11y=\frac{10+10+12+12}4=11입니다.
  2. x=623≈20.67x=\frac{62}3\approx20.67, y=323≈10.67y=\frac{32}3\approx10.67입니다. 빠진 Pixel의 반대쪽인 왼쪽·위쪽으로 중심이 이동합니다.
  3. valid=False, center=None을 받고 정지 명령을 내며 다음 영상을 기다립니다. 임의의 (0,0)을 만들지 않습니다.
  4. 검출 성공은 valid=True, center=(0,0), 미검출은 valid=False, center=None으로 둡니다. 좌표 값과 검출의 유효성을 별도 정보로 기록합니다.
