이동 거리와 시간

중간시험 · 예시 1

문제 상황

거리 [0.4,0.6,0.2] m를 각 구간에서 .2 m/s로 이동합니다. 구간 사이 정지 시간은 0입니다.

이해하고 적용할 내용

  • 이동 모델의 단위와 구간별 시간을 연결하고 전체 실행 순서를 계산하기
  • 같은 목적의 명령도 API별 단위와 허용 범위에 맞춰 변환하기

참고자료로 확인할 정보

거리 단위·호출 형식·허용 범위는 제공된 가상 API 명세에서 확인합니다.

제공 참고자료

이동 모델
등속 구간의 시간 t=d/v입니다. 구간 사이 정지와 가감속 시간은 이 사례에서 0입니다.
단위
1 m=100 cm. 시간은 s, 속도는 m/s입니다.
이 예시의 API
move_cm(d)는 정수 cm만 받고, 한 번에 20≤d≤100을 허용합니다. 이 규약은 문제에서 정한 것입니다.
distance_m=[.4 .6 .2];
time_s=distance_m/.2;

문항

  1. 구간별 시간과 총 이동 시간을 계산 과정·단위와 함께 쓰세요.
  2. 세 구간을 move_cm으로 실행할 인수 목록을 쓰고 허용 범위를 확인하세요.
  3. 세 구간의 종료 시각을 t=0 기준으로 쓰세요.
  4. 1.4 m 직선 이동을 같은 속도로 실행하려 합니다. 규약에 맞는 두 번의 호출과 총 시간을 제시하세요.
답안 작성 예시
  1. 0.4/0.2=2 s, 0.6/0.2=3 s, 0.2/0.2=1 s로 총 6 s입니다.
  2. move_cm(40), move_cm(60), move_cm(20). 모두 정수이고 범위 안입니다.
  3. 누적 종료 시각은 2,5,6 s입니다. 구간 시간 [2,3,1]과 누적 시각은 다릅니다.
  4. 예를 들어 move_cm(100), move_cm(40)입니다. 총 시간은 1.4/0.2=7 s이며, 각 호출의 거리도 허용 범위 안입니다.
