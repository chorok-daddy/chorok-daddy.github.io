드론 이동

앞·옆 이동의 기준이 회전 후에도 같다고 생각하면 경로가 어긋납니다. 좌표계를 계산으로 먼저 확인합니다.

실습 전에

01 회전한 뒤의 앞으로 이동은 어느 축을 따를까요?

설명

동체 좌표의 전방을 따르므로 세계 좌표에서의 이동 방향은 yaw에 따라 달라집니다.

02 명령 순서가 달라져도 도착점이 같을까요?

설명

이동과 회전의 순서는 일반적으로 교환되지 않습니다. 경로를 좌표로 누적해 대조합니다.

실행 조건

이 실습은 좌표 시뮬레이션입니다. 실제 비행으로 확장할 때는 제공 장비의 좌표계·단위와 명령 응답 방식을 별도로 대조합니다.

실습

실습용 노트북 미리보기실습용 노트북 다운로드

1. 이동 명령의 좌표 확인

시작 조건

시작 위치 (0,0) m, yaw=0°. 전방은 body +x, 오른쪽은 body -y, yaw는 반시계방향입니다. 제공 commands 5개를 사용합니다.

진행 방법

  1. 각 명령 후의 body 변위·world 변위·누적 위치·yaw를 표에 한 행씩 기록하세요.
  2. body_to_world 함수를 사용해 예상한 위치를 코드와 비교하세요.
  3. xy 궤적에 명령 순서 번호와 축 단위를 표시하세요.

남길 결과

  • 명령 5행 표와 xy 궤적 1개.

  • 회전 변환 전후 변위 벡터의 길이가 같은가?

2. 같은 목적지의 다른 경로

시작 조건

첫 명령열의 최종 위치를 목적지로 두고, yaw=0을 유지하는 world 축 정렬 경로를 새로 만듭니다.

진행 방법

  1. 직접 정한 두 번째 명령열을 명시하세요.
  2. 두 경로의 최종 위치 오차·총 이동 거리·회전 횟수를 비교하세요.
  3. 최단 거리와 실제 명령 수행 편의가 같은 기준인지 설명하세요.

3. 명령 오차를 넣은 경로

시작 조건

이동 길이에 각각 ±5% 오차를 넣습니다. seed=7, 반복 30회로 고정하고 yaw 오차는 0으로 둡니다.

진행 방법

  1. 각 반복에서 거리 명령만 perturb하고 최종 위치를 저장하세요.
  2. 최종 위치 산점도와 목적지 거리 오차의 평균·최댓값을 구하세요.
  3. 오차율을 0%,5%,10%로 바꾸어 결과를 비교하세요.
