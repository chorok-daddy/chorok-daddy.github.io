시험 형식과 도구 사용

필기시험과 MATLAB 코드 해석 시험을 각각 치르며, 두 시험 모두 손으로 답안을 작성합니다. 각 시험은 60분 기준입니다.

  • 필기시험: 제공된 참고 수식을 활용해 모델을 세우고, 계산 과정과 적용한 조건을 설명합니다.
  • MATLAB 코드 해석 시험: 1페이지의 시험용 참고자료를 제공합니다. 주어진 코드의 핵심 부분을 채우거나, 중간 데이터와 출력값을 구하고 그래프의 변화를 해석합니다. 긴 프로그램 전체를 작성하는 시험은 아닙니다.

이전에 안내한 AI를 허용하는 컴퓨터 실습 시험에서 참고자료를 활용하는 손답안형 시험으로 변경되었습니다. 시험 중 MATLAB이나 AI를 실행하는 방식이 아닙니다. 시험 일시·장소와 최종 운영 사항은 실습시간에 안내되는 내용을 우선합니다.

별도 요구가 없으면 답은 분수·근호·기호식으로 남겨도 됩니다. 그래프는 축, 주요 값, 변화 방향이 드러나도록 그리세요. 같은 의미의 식이나 같은 동작을 하는 코드는 인정합니다.

시험 유형·답안 예시

수업 개념을 다른 수치·상황에 적용하는 공개 연습 예시입니다. 실제 시험문항과 구분해 활용하세요.

1. 질량계의 모델과 상태

질량 m=2 kg, 감쇠 b=4 N·s/m, 스프링 k=8 N/m입니다. 외력 u에서 변위 y까지의 모델을 구합니다.

x=[y; dy/dt]
  1. 미분방정식과 초기조건 0일 때 G(s)를 쓰세요.
  2. A,B,C,D를 쓰세요.
답안 예시와 풀이
  1. 2y″+4y′+8y=u, G(s)=1/(2s²+4s+8).
  2. A=[[0,1],[-4,-2]], B=[[0],[.5]], C=[1,0], D=0.

2. 초기 상태의 응답

입력은 0이며 A=diag(-1,-3), x(0)=[2,1]ᵀ, y=[1,1]x입니다.

Phi=expm(A*t);
x=Phi*x0;
  1. Φ(t), x(t), y(t)를 쓰세요.
  2. y(0)과 t→∞의 y를 확인하세요.
답안 예시와 풀이
  1. Φ=diag(e^(−t),e^(−3t)), x=[2e^(−t),e^(−3t)]ᵀ, y=2e^(−t)+e^(−3t).
  2. y(0)=3, 최종값=0.
