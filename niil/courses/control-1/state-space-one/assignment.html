실습 전에

01 예측에 필요한 정보

예시 상황 같은 위치에 있는 두 물체의 다음 움직임을 예상하려면, 현재 위치 외에 무엇을 알아야 할까요?

설명
  • 현재 속도도 알아야 합니다. 하나는 정지하고 다른 하나는 움직이고 있다면 이후 위치가 달라집니다.
  • 등가속 운동 식에서도 출발 위치와 속도를 함께 사용했습니다. 이번에는 가속도가 위치·속도·힘에 따라 달라지는 모델로 확장합니다.

관련 개념 복습 ↗

02 가속도와 State

위치와 속도를 State로 정했다면, 가속도도 따로 기억해야 할까요?

설명
  • 이번 모델에서는 현재 위치·속도와 가하는 힘으로 가속도를 계산할 수 있으므로 별도의 State로 넣지 않습니다.
  • 속도는 위치의 변화율, 가속도는 속도의 변화율입니다. 두 관계를 함께 쓰면 위치의 2차 미분방정식을 1차 미분방정식 두 개로 표현할 수 있습니다.

관련 개념 복습 ↗

03 State와 Output

움직임을 계산하는 데 필요한 정보와 관찰하려는 값은 항상 같아야 할까요?

설명
  • 위치와 속도가 계산에 모두 필요해도 관찰하려는 Output은 위치 하나일 수 있습니다.
  • 실습에서는 같은 State 모델에서 Output을 위치 또는 속도로 선택합니다. 어떤 정보를 유지하고 어떤 값을 보여주는지 구분하는 과정입니다.

먼저 계산하고 MATLAB으로 확인하기

아래 계산을 먼저 수행한 뒤 MATLAB 결과와 비교하세요.

  1. 병렬 RLC에서 위 Node의 전압을 vv, 위에서 아래로 흐르는 인덕터 전류를 iLi_L, 공급 전류를 uu로 정하세요. R=1,L=1,C=1R=1,\ L=1,\ C=1에서 KCL과 v=LdiLdtv=L\frac{di_L}{dt}를 이용해 𝐱=[v,iL]T\mathbf x=[v,i_L]^T의 두 미분방정식과 출력 y=vy=v를 직접 쓰고 A,B,C,DA,B,C,D를 구하세요. 초기조건 0에서 두 식을 Laplace Transform하고 IL(s)I_L(s)를 소거하여 V(s)U(s)\frac{V(s)}{U(s)}를 구하세요.
  2. 일정 전류 1 A를 충분히 오래 공급하면 vv와 iLi_L이 각각 얼마가 되는지 먼저 적으세요. 직접 구한 행렬로 ss 모델을 만들고 tf·dcgain으로 검증하세요. 이 병렬 회로는 아래 RL 직렬 가지 회로와 구성이 다릅니다. 이번에는 RL 회로의 RR 반복 세 값 중 한 값을 이 비교로 대신하세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. Mechanical State Space

b=0.5,2,10을 각각 다시 모델링하고 응답을 비교하세요. Output을 속도로 바꾼 경우 Cout과 DC Gain도 확인하세요.

2. Electrical State Space

R=1,3,10에서 모델을 다시 만들고 일정 입력 1A에 대한 최종 출력 전압을 비교하세요. Ccap은 Capacitance 값, Cout은 State에서 출력 전압을 계산하는 행렬임을 적고, Cout이 원하는 전압을 선택하는지 확인하세요.

3. State 좌표와 초기값

초기 상태 [0;1]과 [1;0]을 비교하세요. 이 결과가 초기조건을 모두 0으로 두고 계산한 Step Response과 다른 이유를 적으세요.
