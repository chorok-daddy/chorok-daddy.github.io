02 계산 도구를 사용하는 이유

실제 장치를 바로 바꾸기 전에 컴퓨터로 반응을 살펴보면 어떤 도움이 될까요?

설명
  • 모델로 여러 조작 방법의 반응을 비교하면 실제 장치에서 시험할 후보를 좁힐 수 있습니다.
  • MATLAB은 계산과 시각화를 돕습니다. 결과가 적절한지는 목표와 모델의 가정을 기준으로 판단합니다.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. 환경 확인

a를 0:0.5:3으로 바꾸어 원소 수와 제곱 결과를 확인하세요.

2. 첫 그래프

cos 곡선을 같은 Figure에 추가하고 Legend를 구분하세요.
