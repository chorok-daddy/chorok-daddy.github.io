실행 방법

Live Editor에서 코드 안을 클릭하고 Run Section으로 현재 Section을 실행하세요(Windows/Linux Ctrl+Enter, Mac ⌘+Enter). Run은 문서 전체를 실행합니다. 설명·작성란은 직접 편집하세요.
처음에는 위에서부터 실행하고, 값을 바꾼 Section은 다시 실행하세요. 변수가 없다는 오류가 나면 앞 Section부터 실행하세요. 출력은 코드 아래 또는 오른쪽에 표시됩니다.
환경: MATLAB Online. 이번 실습은 기본 MATLAB 기능으로 실행합니다.

1. 환경 확인

MATLAB 버전과 기본 계산을 확인합니다.
실행 전 예상: ⟦직접 입력⟧
disp(version);
a=1:5;
disp(a.^2);
직접 수행:
  1. a=0:0.5:3으로 바꾸고 numel(a)와 a.^2를 출력하세요. 원소 수와 각 원소의 제곱값을 결과에 남기세요.

예상과 차이 및 원인: ⟦직접 입력⟧

2. 첫 그래프

코드 안을 클릭하고 Run Section을 누릅니다.
실행 전 예상: ⟦직접 입력⟧
t=0:0.05:2*pi;
figure;plot(t,sin(t));grid on;xlabel('Time (s)');ylabel('Amplitude');title('Sine');
직접 수행:
  1. 기준 코드와 같은 t에서 cos(t)를 계산해 sin(t)와 같은 Figure에 그리세요.
  2. 어느 곡선이 sine이고 cosine인지 Legend로 구분하세요. 두 곡선이 보이는 Figure를 남기세요.

반복 숙달과 제출 전 확인

앞의 직접 수행에서 비교한 조건 세 가지를 아래에 정리하세요. 이미 수행한 실험을 추가로 반복할 필요는 없습니다. 예상은 정확한 수치 대신 증가·감소 방향으로 적어도 됩니다.
반복 1 — 조건: ⟦직접 입력⟧ / 예상: ⟦직접 입력⟧ / 실제: ⟦직접 입력⟧
반복 2 — 조건: ⟦직접 입력⟧ / 예상: ⟦직접 입력⟧ / 실제: ⟦직접 입력⟧
반복 3 — 조건: ⟦직접 입력⟧ / 예상: ⟦직접 입력⟧ / 실제: ⟦직접 입력⟧
선택:
예: Array 연산의 점 연산자를 빠뜨린 경우
  1. a=1:5에서 a.^2를 a^2로 바꾼 줄만 따로 실행하고 오류 메시지를 남기세요.
  2. 행렬 거듭제곱과 원소별 제곱 중 원하는 연산을 적으세요. 해당 줄을 a.^2로 되돌리고 결과 다섯 개를 기록하세요.
