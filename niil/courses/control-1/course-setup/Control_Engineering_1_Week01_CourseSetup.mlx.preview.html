Run Section 실행 안내

실행할 코드 안을 클릭한 뒤 Live Editor → Run Section을 누르세요. 현재 Section 전체를 실행합니다. Run은 문서 전체 실행입니다. 단축키는 Windows/Linux Ctrl+Enter, Mac ⌘+Enter입니다. 설명과 작성란은 직접 수정하며 실행할 필요가 없습니다.
처음에는 위에서부터 실행하세요. 값을 바꾸면 그 Section을 다시 실행해야 출력이 바뀝니다. 변수 오류가 나면 필요한 앞 Section을 먼저 실행합니다. 출력은 코드 아래 또는 오른쪽에 표시됩니다.
환경: MATLAB Online. 이번 실습은 기본 MATLAB 기능으로 실행합니다.
실습 안내: https://chorok-daddy.github.io/courses/control-1/course-setup/assignment.html

1. 환경 확인

MATLAB 버전과 기본 계산을 확인합니다.
실행 전 예상: ⟦직접 입력⟧
disp(version);
a=1:5;
disp(a.^2);
직접 수행: a를 0:0.5:3으로 바꾸어 원소 수와 제곱 결과를 확인하세요.

2. 첫 그래프

figure;plot(t,sin(t));grid on;xlabel('Time (s)');ylabel('Amplitude');title('Sine');

반복 숙달과 제출 전 확인

앞의 직접 수행에서 비교한 조건 세 가지를 아래에 정리하세요. 이미 수행한 실험을 추가로 반복할 필요는 없습니다. 예상은 정확한 수치 대신 증가·감소 방향으로 적어도 됩니다.
반복 1 — 조건: ⟦직접 입력⟧ / 예상: ⟦직접 입력⟧ / 실제: ⟦직접 입력⟧
반복 2 — 조건: ⟦직접 입력⟧ / 예상: ⟦직접 입력⟧ / 실제: ⟦직접 입력⟧
반복 3 — 조건: ⟦직접 입력⟧ / 예상: ⟦직접 입력⟧ / 실제: ⟦직접 입력⟧
선택: 계수 하나·Input 크기·시간 구간·행렬 크기 중 하나를 잘못 설정한 예를 만들고 원인을 설명한 뒤 수정하세요. 새 세션에서 다시 실행하여 본인 사본을 저장합니다.
