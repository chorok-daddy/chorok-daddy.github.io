1. 기준 Gain과 Sensitivity

Sensitivity는 Gain을 아주 조금 바꿨을 때의 상대 변화 비율입니다. +10%처럼 유한한 변화에서는 이 값으로 예측한 변화와 원래 함수로 다시 계산한 변화가 조금 다를 수 있습니다. 전체 Gain T=Ka/(1+beta*Ka)를 미분하면 dT/dKa=1/(1+beta*Ka)^2입니다. 이를 S=(Ka/T)*(dT/dKa)에 넣어 S=1/(1+beta*Ka)를 얻습니다. 작은 변화에서 ΔT≈(dT/dKa)ΔKa이므로 ΔT/T≈S*(ΔKa/Ka)입니다. 아래 approx는 이 식을, exact는 변경 전후 T를 직접 비교한 식을 사용합니다.
실행 전 예상: ⟦직접 입력⟧
Ka=5000;beta=.05;
Topen=Ka;Tclosed=Ka/(1+Ka*beta);
Sopen=1;Sclosed=1/(1+Ka*beta);
disp(table(Topen,Tclosed,Sopen,Sclosed));
직접 수행: Ka=1000,5000,10000에서 Open-loop·Closed-loop Gain과 Sensitivity를 표로 계산하세요.

2. 변화율 검증

상대 변화율은 (변경 후 Gain−변경 전 Gain)/변경 전 Gain입니다. 바뀐 Gain으로 나누지 않도록 확인하세요.
실행 전 예상: ⟦직접 입력⟧
Ka=5000;beta=.05;delta=.1;
T0=Ka/(1+Ka*beta);T1=(Ka*(1+delta))/(1+Ka*(1+delta)*beta);
exact=(T1-T0)/T0;approx=delta/(1+Ka*beta);
disp(table(exact,approx));
직접 수행: delta=0.01,0.1,0.2를 비교하세요. 각 delta에서 근사 변화율과 정확한 변화율의 차이를 표로 적으세요. 변화가 클 때 두 값이 더 벌어지는지, Feedback이 없을 때와 비교해 전체 Gain이 얼마나 덜 변하는지 설명하세요.

3. 반복 검사

Ka 값을 차례로 바꾸며 같은 Sensitivity 식으로 계산해 곡선을 그립니다. Ka가 커질수록 Sensitivity가 어떻게 변하는지 확인하세요.
실행 전 예상: ⟦직접 입력⟧
beta=.05;Ka=logspace(1,5,100);S=1./(1+Ka*beta);
figure;semilogx(Ka,S);xlabel('Amplifier gain Ka');ylabel('Sensitivity');grid on;
직접 수행: beta=0.01과 0.1을 추가하고 곡선을 비교하세요. 전체 Gain의 값과 Sensitivity를 각각 기록하세요. 출력의 크기가 작아진 것인지, Ka를 바꿨을 때 출력이 덜 변하는 것인지 설명하세요.
