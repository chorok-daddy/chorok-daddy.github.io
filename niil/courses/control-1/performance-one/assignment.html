11주차 · Step Response 성능 지표

실습 전에

01 좋은 응답의 기준

목표에 빨리 도달하지만 많이 흔들리는 응답과, 조금 느리지만 곧 정착하는 응답 중 어느 쪽이 좋을까요? 무엇을 기준으로 정해야 할까요?

설명
  • Rise Time·Settling Time·Overshoot는 서로 다른 특성 측정
  • 설계 목적에 맞는 지표와 허용 범위 지정

02 성능을 숫자로 표현하기

그래프를 보고 “빠르다”, “많이 흔들린다”고 말하는 대신 수치로 나타내면, 설계를 비교할 때 어떤 도움이 될까요?

설명
  • Rise Time·Settling Time·Overshoot로 응답의 서로 다른 특성을 측정할 수 있습니다.
  • 같은 기준으로 측정해야 비교가 가능합니다. Input, 최종값, 정착 범위 등을 함께 확인합니다.

실습

1. 응답을 수치로 측정

Rise Time·Settling Time·Overshoot의 단위를 적고 그래프의 어느 부분을 측정한 것인지 표시하세요.

2. 최종값을 잘못 넣은 측정 수정

  1. 기준 코드의 correct와 wrong에서 Rise Time·Settling Time·Overshoot를 나란히 기록하세요. 두 호출에서 최종값 인자만 다른 점을 설명하세요.
  2. 분모 [1 2 4]는 유지하고 분자를 1로 바꾸어 T의 DC Gain을 0.25로 만드세요. 같은 시간 vector에서 y를 다시 구하세요.
  3. 같은 y,t에 최종값을 각각 1과 dcgain(T)로 지정해 stepinfo를 호출하고, 두 결과를 같은 방식으로 기록하세요.
  4. 모델을 바꾸어 오류를 숨기는 대신, stepinfo의 최종값 인자만 실제 DC Gain으로 수정하세요. 어떤 기준값 때문에 지표가 달라졌는지 적으세요.

3. Pole·Zero 조건 변경

  1. base, withZero, slowPole 각각에 대해 dcgain과 stepinfo를 구하세요.
  2. 모델마다 한 행을 사용해 DC Gain, Rise Time, Settling Time, Overshoot를 기록하세요. 같은 stepinfo 설정을 사용합니다.
  3. 추가 Zero를 −2-2로 바꿀 때는 (s+2)/2*base, 추가 Pole을 −10-10으로 바꿀 때는 10/(s+10)*base를 사용하세요. 기준 모델 base는 바꾸지 않습니다.
  4. 바꾼 두 모델의 결과를 같은 표에 덧붙이세요. 먼저 DC Gain이 base와 같은지 확인합니다. 그런 다음 Zero 변경은 기존 withZero와, Pole 변경은 기존 slowPole과 대조하세요.
  5. 각 변경에서 Rise Time·Settling Time·Overshoot가 커졌는지 또는 작아졌는지 적으세요. 같은 최종값에서도 Transient Response가 달라지는지 이 결과로 설명하세요.

선택 실습

예: 2% Settling Time을 구하면서 20%를 지정한 경우

  1. 첫 코드 Section의 같은 T에서 stepinfo(T,'SettlingTimeThreshold',.02)와 stepinfo(T,'SettlingTimeThreshold',.2)를 계산하세요.
  2. 두 Settling Time과 사용한 허용 비율을 나란히 적으세요. 2% 기준이 되도록 두 번째 호출의 인자만 .02로 바꾸고 모델은 유지하세요.
