13주차 · P와 PI의 Steady-state Error(Steady-state 오차) 비교하기 실습

실습 전에

01 계속 남는 오차

목표보다 조금 낮은 값에서 더 이상 가까워지지 않습니다. 이 차이가 계속 남는다는 사실을 조작에 활용할 수 있을까요?

설명
  • 시간에 따라 누적된 Error
  • PI는 현재 Error와 누적 Error를 활용. 효과 판단의 전제는 Closed-loop 안정성

02 움직이는 목표 따라가기

정해진 속도를 유지하는 것과 계속 높아지는 목표 속도를 따라가는 것은 같은 문제일까요? 제어 방법을 비교할 때 무엇이 달라질까요?

설명
  • Step과 Ramp는 서로 다른 추종 문제

실습

먼저 계산하고 MATLAB으로 확인하기

아래 계산을 먼저 수행한 뒤 MATLAB 결과와 비교하세요.

  1. P와 PI의 Step 추종 Section에서 CPI(s)=10+5sC_{\mathrm{PI}}(s)=10+\frac5s와 G(s)=10.5s+1G(s)=\frac1{0.5s+1}를 사용하세요. 실행 전에 L(s)=CPI(s)G(s)L(s)=C_{\mathrm{PI}}(s)G(s)와 1+L=01+L=0에서 얻는 특성다항식을 손으로 쓰세요. 2차 다항식의 세 계수가 양수이면 두 Pole의 실수부가 음수라는 기준으로 안정성을 확인하세요.
  2. L의 원점 Pole 수로 System Type을 정하고 Kp=lim⁡s→0L(s)K_p=\lim_{s\to0}L(s), Kv=lim⁡s→0sL(s)K_v=\lim_{s\to0}sL(s)를 구하세요. 안정성을 확인한 뒤 Unit Step 오차 11+Kp\frac1{1+K_p}와 Unit Ramp 오차 1Kv\frac1{K_v}를 계산하고 실행 결과와 비교하세요. 이 계산을 KiK_i=5의 기준 기록으로 사용합니다.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. Pole 위치 비교

같은 ζ\zeta를 유지하고 ωn\omega_n만 바꾸는 모델 쌍을 만들어 비교하세요. 원래 두 모델과 어떤 조건이 다른지 적으세요.

2. P와 PI의 Step 추종

KpK_p를 20으로 바꾸어 P의 이론 오차를 검증하세요. KiK_i=2,5,10에서 PI의 Step 오차와 Transient Response을 비교하세요.

3. Ramp 추종

Loop Transfer Function에서 원점 Pole을 세어 System Type을 구하세요. 해당 Type의 Unit Ramp 오차 공식을 적용한 뒤, KiK_i=10에서 계산한 오차가 시뮬레이션에서 충분히 시간이 지난 뒤의 오차와 같은지 비교하세요.
