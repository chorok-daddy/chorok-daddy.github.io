먼저 계산하고 MATLAB으로 확인하기

아래 계산을 먼저 수행한 뒤 MATLAB 결과와 비교하세요.
1. P와 PI의 Step 추종 Section에서 C_PI(s)=10+(5)/(s)와 G(s)=(1)/(0.5s+1)를 사용하세요. 실행 전에 L(s)=C_PI(s)G(s)와 1+L=0에서 얻는 특성다항식을 손으로 쓰세요. 2차 다항식의 세 계수가 양수이면 두 Pole의 실수부가 음수라는 기준으로 안정성을 확인하세요.
2. L의 원점 Pole 수로 System Type을 정하고 K_p=lim⁡_s→0L(s), K_v=lim⁡_s→0sL(s)를 구하세요. 안정성을 확인한 뒤 Unit Step 오차 (1)/(1+K_p)와 Unit Ramp 오차 (1)/(K_v)를 계산하고 실행 결과와 비교하세요. 이 계산을 K_i=5의 기준 기록으로 사용합니다.
코드 실행 전 — 손으로 계산한 식과 값: ⟦여기에 계산을 적으세요⟧ 코드 실행 후 — 비교할 MATLAB 출력값: ⟦출력값을 적으세요⟧

1. Pole 위치 비교

두 모델은 Damping Ratio도 달라진다는 점을 확인합니다.
실행 전 예상: ⟦직접 입력⟧
T1=tf(10,[1 2 10]);T2=tf(100,[1 10 100]);
disp(pole(T1));disp(pole(T2));
figure;step(T1,T2,0:.005:10);legend('T1','T2');grid on;
직접 수행: 같은 ζ를 유지하고 ω_n만 바꾸는 모델 쌍을 만들어 비교하세요. 원래 두 모델과 어떤 조건이 다른지 적으세요.

2. P와 PI의 Step 추종

충분히 긴 시간으로 느린 Mode를 포함합니다.
실행 전 예상: ⟦직접 입력⟧
s=tf('s');G=1/(.5*s+1);P=10;PI=10+5/s;
Tp=feedback(P*G,1);Tpi=feedback(PI*G,1);t=0:.01:30;
figure;step(Tp,Tpi,t);legend('P','PI');grid on;
disp([1-dcgain(Tp),1-dcgain(Tpi)]);
직접 수행: K_p를 20으로 바꾸어 P의 이론 오차를 검증하세요. K_i=2,5,10에서 PI의 Step 오차와 Transient Response을 비교하세요.

3. Ramp 추종

시간 끝값과 극한값을 분리합니다.
실행 전 예상: ⟦직접 입력⟧
s=tf('s');G=1/(.5*s+1);Tp=feedback(10*G,1);Tpi=feedback((10+5/s)*G,1);
t=(0:.01:30)';r=t;yp=lsim(Tp,r,t);yi=lsim(Tpi,r,t);
figure;plot(t,r-yp,t,r-yi);legend('P error','PI error');xlabel('Time (s)');ylabel('Tracking error');grid on;
disp([r(end)-yi(end),1/5]);
직접 수행: Loop Transfer Function에서 원점 Pole을 세어 System Type을 구하세요. 해당 Type의 Unit Ramp 오차 공식을 적용한 뒤, K_i=10에서 계산한 오차가 시뮬레이션에서 충분히 시간이 지난 뒤의 오차와 같은지 비교하세요.
