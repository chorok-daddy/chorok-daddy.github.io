제어공학1 · 시험 유형 예시

실제 시험과 다른 소재로 제공 자료의 설명 수준과 답안 작성 분량을 보여 줍니다. 아래 3세트는 짧은 발췌 예시이며, 실제 시험 범위·문항 수·난이도·배점을 예고하지 않습니다. 중간·기말 안내에서 공통으로 참고할 수 있습니다.

먼저 참고자료를 읽고, 문제의 빈칸이나 요청한 값만 손으로 작성해 보세요. 설치·파일 불러오기·그림 꾸미기 같은 주변 코드는 작성하지 않습니다. 답안 예시의 ‘작성할 답’은 학생이 적을 분량을, ‘풀이’는 이해를 돕는 추가 설명을 뜻합니다.

이 예시에 제공하는 참고자료

실제 시험의 참고 수식·MATLAB 문법 자료에 해당하는 영역입니다. 예시를 풀 때 계속 참고해도 됩니다. 공식의 적용 대상과 함수의 역할을 함께 제공합니다.

직사각형과 원

직사각형의 가로를 w, 세로를 h라 하면 둘레는 2(w+h), 넓이는 wh입니다. 원의 반지름이 r이면 넓이는 πr²입니다. 원의 넓이에서 반지름을 구할 때는 제곱근을 사용합니다. 반지름은 0 이상입니다.

sqrt(a)       % a의 제곱근
pi            % 원주율: 답에 pi 또는 π로 남겨도 됨
x=a:d:b;      % a부터 간격 d로 b 이하까지의 값
x.^2          % x의 각 원소를 제곱
x.*y          % 같은 위치의 원소끼리 곱함
x(end)        % 마지막 원소
max(x)        % 가장 큰 원소
plot(x,y)     % 같은 위치의 x, y를 좌표로 삼아 점들을 직선으로 연결

표와 누적 수량

MATLAB의 Index는 1부터 시작합니다. A(:,j)는 모든 행의 j번째 열, A(i,:)는 i번째 행입니다. sum(A,2)는 행마다 열 방향으로 더해 열벡터를 만듭니다. cumsum(v)는 벡터의 앞에서부터 누적합을 구합니다. 예를 들어 cumsum([1 3 2])는 [1 4 6]입니다.

예시 1 · 둘레에서 넓이까지

문제의 조건 · 직사각형의 둘레가 20cm이고 가로가 6cm입니다. 세로와 넓이를 구한 뒤, 같은 넓이의 원의 반지름을 계산합니다.

perimeter=20; width=6;
height=___A___;
area=___B___;
radius=sqrt(area/pi);

답할 내용

  1. A와 B에 들어갈 식을 기존 변수로 쓰세요.
  2. height, area, radius를 차례로 구하세요. radius는 근호와 π를 포함한 식으로 남겨도 됩니다.
  3. 가로를 w로 바꾸고 둘레 20cm를 유지할 때 넓이를 w의 식으로 쓰세요.
답안 예시와 풀이

작성할 답

A: perimeter/2-width
B: width*height
height=4 cm, area=24 cm², radius=√(24/π) cm
넓이: w(10-w) cm²

풀이 · 둘레의 절반은 가로와 세로의 합이므로 세로는 10−6=4입니다. 앞에서 구한 세로를 넓이 계산에 사용하고, 그 넓이를 원의 넓이 식에 넣습니다. 마지막 항목은 같은 관계에서 가로만 기호 w로 바꾼 것입니다.

예시 2 · 상자에 든 물건 수 읽기

문제의 조건 · 세 상자의 연필·지우개 수를 표로 적었습니다. 행은 상자, 첫째 열은 연필, 둘째 열은 지우개입니다. 각 상자에 든 물건 수와 두 번째 상자의 연필 수를 구합니다.

items=[2 1;
       4 3;
       1 2];
totals=sum(items,___A___);
pencils=items(___B___,___C___);

답할 내용

  1. A, B, C를 채우세요.
  2. totals의 값과 행·열 크기, pencils의 값을 쓰세요.
답안 예시와 풀이

작성할 답

A: 2, B: 2, C: 1
totals=[3;7;3], 크기 3×1
pencils=4

풀이 · 한 상자의 두 종류를 더하므로 같은 행에서 열 방향으로 합합니다. 상자가 세 개여서 합도 세 개이며, MATLAB의 sum(items,2)는 이를 열벡터로 반환합니다.

예시 3 · 독서 기록의 그래프와 코드 수정

문제의 조건 · 월요일부터 목요일까지 읽은 페이지 수가 3, 5, 0, 4입니다. total에는 그날까지 읽은 누적 페이지 수를 저장합니다. 표시된 날짜 사이의 실제 독서 시점은 알 수 없으며, 그래프는 기록한 점을 직선으로 연결한 것입니다.

day=1:4;
pages=[3 5 0 4];
total=cumsum(pages);
plot(day,total);
finished=total(1); % 마지막 날까지 읽은 총량을 저장하려 함

답할 내용

  1. total의 값을 쓰세요.
  2. 코드가 그리는 그래프를 그리세요. 네 점의 좌표를 표시하세요.
  3. finished가 목적에 맞는 값을 갖도록 마지막 줄의 오른쪽 식만 고치고, 그 값을 쓰세요.
답안 예시와 풀이

작성할 답

total=[3 8 8 12]
그래프: (1,3) → (2,8) → (3,8) → (4,12)를 직선으로 연결
수정: total(end), 값: 12

실제 답안에는 위 네 점을 찍고 연결한 그래프를 그립니다. 2일째와 3일째 사이 구간은 수평입니다.

풀이 · cumsum은 앞날의 합에 그날의 값을 더합니다. total(1)은 첫날의 누적량이므로, 마지막 원소를 선택해야 마지막 날까지의 총량을 얻습니다.
