1. Transfer Function 구성

계수는 높은 차수부터 입력합니다.
실행 전 예상: ⟦직접 입력⟧
G=tf(1,[1 2 5]);
T=feedback(G,1);
disp(G);disp(T);
assert(abs(dcgain(G)-.2)<1e-10);
직접 수행: M=2,b=3,k=6으로 바꾸어 Transfer Function을 만들고 DC Gain을 1/k와 비교하세요.

2. Block 연결과 응답

같은 시간축으로 비교합니다.
실행 전 예상: ⟦직접 입력⟧
G=tf(1,[1 2 5]);T=feedback(G,1);t=0:.01:10;
figure;step(G,T,t);legend('Open-loop','Unity feedback');grid on;
직접 수행: H=2인 Feedback을 추가하고 분모가 어떻게 바뀌는지 식과 MATLAB 결과를 대조하세요.

3. Simulink 모델 열기

함께 배포한 .slx를 MATLAB Drive에서 열거나 아래처럼 동일 모델을 만드세요.
실행 전 예상: ⟦직접 입력⟧
modelName='Control_Engineering_1_Week04_Block_Model';

else

end
직접 수행: Step→Transfer Fcn→Scope를 직접 연결하세요. Step time=0, Final value=1, Denominator=[1 2 5], Stop time=10으로 설정하고 MATLAB 응답과 비교하세요.
