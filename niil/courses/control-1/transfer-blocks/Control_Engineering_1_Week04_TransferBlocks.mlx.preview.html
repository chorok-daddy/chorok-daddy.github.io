1. Transfer Function 구성

계수는 높은 차수부터 입력합니다.
실행 전 예상: ⟦직접 입력⟧
G=tf(1,[1 2 5]);
T=feedback(G,1);
disp(G);disp(T);
assert(abs(dcgain(G)-.2)<1e-10);
직접 수행:
  1. , , 을 기계 모델의 Transfer Function 에 넣어 MATLAB 모델을 만드세요.
  2. 사용한 Transfer Function을 적고, dcgain(G)와 손으로 계산한 를 나란히 기록하세요. 두 값의 일치 여부를 적으세요.

2. Block 연결과 응답

같은 시간축으로 비교합니다.
실행 전 예상: ⟦직접 입력⟧
G=tf(1,[1 2 5]);T=feedback(G,1);t=0:.01:10;
figure;step(G,T,t);legend('Open-loop','Unity feedback');grid on;
직접 수행:
  1. 기준 G=tf(1,[1 2 5])는 유지하고 인 음의 Feedback을 연결하세요.
  2. Closed-loop Transfer Function을 손으로 정리한 식과 feedback(G,2)의 결과를 나란히 적으세요.
  3. 두 식의 분모 계수를 같은 차수 순서로 적어 대조하세요. 일 때와 비교해 어느 계수가 달라졌는지도 표시하세요.

3. Simulink 모델 열기

함께 배포한 .slx를 MATLAB Drive에서 열거나 아래처럼 동일 모델을 만드세요.
실행 전 예상: ⟦직접 입력⟧
modelName='Control_Engineering_1_Week04_Block_Model';
if isfile([modelName '.slx'])
open_system(modelName);
else
disp('블로그 자료 모음에서 Week04 .slx 파일을 같은 폴더에 받으세요.');
end
직접 수행:
  1. Simulink에서 Step → Transfer Fcn → Scope를 연결하세요. 기준 G=tf(1,[1 2 5])에 대응하도록 분자는 [1], 분모는 [1 2 5]로 설정합니다.
  2. Step time=0, Final value=1, Stop time=10으로 실행하세요.
  3. Scope의 출력과 MATLAB의 step(G,0:0.01:10) 곡선을 나란히 제시하세요. 두 그림은 같은 시간 범위와 출력 축 범위로 놓고, 최종값과 곡선 형태가 일치하는지 적으세요. 이 Block Diagram은 Feedback을 연결하지 않은 G에 대응합니다.
