12주차 · 2차 시스템의 감쇠와 속도 조절하기 실습

실습 전에

01 응답의 속도와 진동

빠르게 움직이면서 목표를 지나쳐 흔들리지 않게 만들고 싶습니다. 속도와 진동을 구분해서 조절하려면 무엇을 알아야 할까요?

설명
  • 표준 2차 모델에서는 Natural Frequency와 Damping Ratio로 응답의 시간 규모와 진동 특성을 살펴볼 수 있습니다.
  • 각 값을 바꿔 그래프를 비교하면서, 모델의 계수와 실제 움직임의 관계를 확인합니다.

02 여러 조건을 만족하는 설계

원하는 빠르기와 허용할 진동의 크기를 정했습니다. 두 조건을 만족하는 모델을 어떻게 찾고 확인할 수 있을까요?

설명
  • 여러 Parameter 조합이 조건을 만족할 수 있음
  • 근사식으로 후보를 찾고 실제 모델 응답으로 조건 충족 여부 검증

실습

먼저 계산하고 MATLAB으로 확인하기

아래 계산을 먼저 수행한 뒤 MATLAB 결과와 비교하세요.

  1. 설계 후 검증 Section의 첫 실행은 ζ=0.7,ωn=5\zeta=0.7,\quad\omega_n=5로 하세요. 먼저 Mp=100e−πζ/1−ζ2M_p=100e^{-\pi\zeta/\sqrt{1-\zeta^2}} [%], Ts≈4ζωnT_s\approx\frac{4}{\zeta\omega_n}로 Overshoot와 Settling Time을 손으로 구하세요. 수치 비교에는 e−0.7π/0.51≈0.046e^{-0.7\pi/\sqrt{0.51}}\approx0.046을 사용하세요.
  2. Mp≤10%M_p\le10\%, Ts≤2T_s\le2 s를 각각 만족하는지 판단하고, ζ=0.7\zeta=0.7을 유지할 때 TsT_s 조건을 만족하는 ωn\omega_n의 범위를 부등식으로 구하세요. 그 뒤 ωn\omega_n을 5로 수정하고 stepinfo를 실행해 근사식과 측정 결과를 비교하세요. 이 조건을 기존 설계 조합 중 한 개로 기록하세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. 표준형 변환

K1=9,K2=3과 K1=16,K2=8을 반복 계산하고 Damping 유형을 판별하세요.

2. Damping Ratio 비교

동일한 ζ\zeta에서 ωn\omega_n을 2배로 바꾸어 Overshoot와 시간 지표가 어떻게 달라지는지 비교하세요.

3. 설계 후 검증

다른 ζ\zeta·ωn\omega_n 조합 두 개를 찾아 같은 조건을 만족하는지 검증하세요. 만족하지 않는 조합도 하나 기록하고 어느 지표에서 실패했는지 설명하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.
