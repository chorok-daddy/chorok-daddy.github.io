1. Stability 판별

Pole의 실수부가 0인 경우에는 모든 Pole의 실수부가 음수라는 조건을 만족하지 않습니다. 경계값을 넣었을 때 Pole이 어디에 놓이는지 확인하세요.
실행 전 예상: ⟦직접 입력⟧
polynomials={[1 3 2],[1 1 2 8],[1 0 1]};
for j=1:numel(polynomials)
p=roots(polynomials{j});strictStable=all(real(p)<-1e-9);
disp(p);disp(strictStable);
end
직접 수행: s³+3s²+2s+K의 Routh 첫 열을 유도하고 K=1,6,7을 비교하세요. K=6에서 Pole을 구하고 실수부가 0인 Pole이 있는지 확인하세요. 모든 Pole의 실수부가 음수인 경우와 응답이 어떻게 다른지 설명하세요.

2. Tracking Error와 비교점 Error

y는 실제 출력이고 Hy는 센서를 거친 측정값입니다. 목표값에서 각각을 빼면 r−y와 r−Hy가 됩니다. 두 값을 나란히 계산해 센서 때문에 차이가 생기는지 확인합니다.
실행 전 예상: ⟦직접 입력⟧
s=tf('s');K=4;G=1/(s+2);H=2/(s+4);T=feedback(K*G,H);
assert(isstable(T));
tracking=1-dcgain(T);comparator=1-dcgain(H*T);disp([tracking comparator]);
직접 수행: K=2,4,8에서 목표값에서 실제 출력을 뺀 r−y와, 목표값에서 센서 측정값을 뺀 r−Hy를 각각 계산하세요. 실제 출력이 목표값에 가까운지 판단할 때 사용할 오차가 어느 쪽인지 적으세요.

3. 유한 구간 Performance Index

동일 시간·동일 간격으로 trapz 적분합니다.
실행 전 예상: ⟦직접 입력⟧
s=tf('s');G=1/(s^2+2*s+1);t=(0:.01:20)';
for K=[1 2 4]
T=feedback(K*G,1);[y,~]=step(T,t);e=1-y;
disp([K trapz(t,e.^2) trapz(t,abs(e)) trapz(t,t.*abs(e))]);
end
직접 수행: 구간을 10초·20초·40초로 바꾸어 ISE가 달라지는 이유를 설명하세요. 종료 시간을 늘려도 적분값이 일정한 값에 가까워지는지 확인하고, 현재 계산한 값이 어느 시간 구간의 결과인지 적으세요.

4. Optimization과 Approximation

설계 범위와 비교 구간을 명시합니다.
실행 전 예상: ⟦직접 입력⟧
K3=.1:.01:10;ISE=1./K3+.1*K3;[v,idx]=min(ISE);disp([K3(idx),sqrt(10),v]);
s=tf('s');GH=1/(1+11*s/6+s^2+s^3/6);GL=1/(1+1.615*s+.624*s^2);
t=(0:.01:15)';yh=step(GH,t);yl=step(GL,t);
figure;plot(t,yh,t,yl);legend('GH','GL');grid on;disp(max(abs(yh-yl)));
직접 수행: K3의 검색 간격을 바꾸어 최적값 오차를 비교하세요. GL의 계수 하나를 10% 바꾸고 Approximation 오차를 기록하세요.
