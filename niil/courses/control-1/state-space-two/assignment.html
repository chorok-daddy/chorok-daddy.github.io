6주차 · State Transition과 시스템 응답 실습

실습 전에

01 출발 상태의 영향

같은 물체라도 멈춘 상태에서 시작할 때와 이미 움직이는 상태에서 시작할 때 결과가 다릅니다. 이 차이를 계산에 어떻게 반영할 수 있을까요?

설명
  • 출발 시점의 위치와 속도를 초기 State로 지정합니다. 이후 Input이 같아도 초기 State가 다르면 응답이 달라집니다.
  • State Transition은 이 초기 State가 시간에 따라 어떻게 변하는지 표현합니다.

02 움직임의 원인 구분하기

물체가 원래 가지고 있던 운동과 이후 가한 힘의 영향을 나누어 볼 수 있다면, 응답을 이해하는 데 어떤 도움이 될까요?

설명
  • 선형 모델에서 초기 State에 의한 응답과 Input에 의한 응답으로 분해
  • 초기 State가 0일 때의 Input 응답을 더하여 전체 응답 계산

아래 계산을 먼저 수행한 뒤 MATLAB 결과와 비교하세요.

  1. 아래 일반 모델을 실행하기 전에 A=[−100−2]A=\begin{bmatrix}-1&0\\0&-2\end{bmatrix}, 𝐱0=[21]\mathbf x_0=\begin{bmatrix}2\\1\end{bmatrix}, u(t)=0u(t)=0인 간단한 경우를 손으로 계산하세요. 대각행렬에서는 Φ(t)=diag⁡(ea1t,ea2t)\Phi(t)=\operatorname{diag}(e^{a_1t},e^{a_2t})입니다. Φ(t)\Phi(t)와 𝐱(t)=Φ(t)𝐱0\mathbf x(t)=\Phi(t)\mathbf x_0를 기호식으로 쓰고 t=0t=0에서 초기값이 되는지 확인하세요.
  2. 전체 응답 식에서 초기 State에 의한 항과 Input에 의한 적분항을 표시하고, 여기서 어느 항이 0인지 설명하세요. t=1t=1의 값은 지수함수 형태로 둔 뒤 MATLAB의 expm(A)*x0와 대조하세요. 이 계산을 첫 Section의 기준 예측으로 사용하세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. State Transition Matrix

t=0,0.5,1의 Phi를 구하고 Φ(1)=Φ(0.5)Φ(0.5)\Phi(1)=\Phi(0.5)\Phi(0.5)를 norm으로 검증하세요. State의 시간 변화를 계산할 때 expm을 써야 하는 이유를 설명하세요.

2. 초기 상태의 궤적

𝐱0\mathbf x_0=[0;1]로 바꾸고 두 상태를 비교하세요. 위치가 0으로 시작해도 이후 움직이는 이유를 속도와 연결해 설명하세요.

3. 전체 응답의 분해

Input 크기를 2로 바꾼 뒤 𝐱0\mathbf x_0=[0;1]도 적용해 두 경우를 각각 검증하세요. Input만 2배 했을 때 전체 응답도 항상 2배인지 판단하세요.
