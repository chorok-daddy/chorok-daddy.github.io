먼저 계산하고 MATLAB으로 확인하기

아래 계산을 먼저 수행한 뒤 MATLAB 결과와 비교하세요.
1. 첫 Section의 A,B,C,D를 읽어 두 State Equation을 손으로 쓰세요. Initial Condition 0에서 Laplace Transform한 뒤 State 하나를 소거하여 (Y(s))/(U(s))를 구하고, C=[0,1]이면 출력식이 어떻게 바뀌는지도 적으세요. 그 다음 tf 결과와 비교하세요.
2. 좌표변환 Section에서는 행렬 변환 코드를 실행하기 전에 𝐱=P𝐳 관계를 각 State Equation과 출력식에 직접 대입하세요. 한 번은 식으로 A_z,B_z,C_z를 구하고, 𝐱_0도 같은 관계로 바꾼 뒤 코드 결과와 대조하세요. 이 과정을 각 Section의 첫 조건에 적용하며 추가 반복은 하지 않습니다.
코드 실행 전 — 손으로 계산한 식과 값: ⟦여기에 계산을 적으세요⟧ 코드 실행 후 — 비교할 MATLAB 출력값: ⟦출력값을 적으세요⟧

1. 변환 전후의 응답

Initial Condition이 모두 0일 때의 Input–Output 비교입니다.
실행 전 예상: ⟦직접 입력⟧
A=[0 1;-2 -3];B=[0;1];C=[1 0];D=0;sys=ss(A,B,C,D);G=tf(sys);
t=(0:.01:10)';y1=step(sys,t);y2=step(G,t);
disp(size(A));disp(G);disp(max(abs(y1-y2)));assert(max(abs(y1-y2))<1e-8);
직접 수행: C=[0,1]로 바꾸어 같은 비교를 수행하세요. Output과 DC Gain이 바뀌는 이유를 적으세요.

2. State 좌표 스케일 변경

x=Pz 관계를 먼저 적습니다.
실행 전 예상: ⟦직접 입력⟧
A=[0 1;-2 -3];B=[0;1];C=[1 0];P=diag([2 .5]);
Az=P\(A*P);Bz=P\B;Cz=C*P;
sys=ss(A,B,C,0);transformed=ss(Az,Bz,Cz,0);
t=(0:.01:10)';err=max(abs(step(sys,t)-step(transformed,t)));disp(err);assert(err<1e-8);
직접 수행: P=diag⁡(3,2)로 바꾸고 A_z,B_z,C_z를 새로 계산하세요. 행렬 숫자가 달라져도 같은 Output인 이유를 설명하세요.

3. 초기값 변환 오류 수정

앞 Section에서 만든 모델을 사용합니다.
실행 전 예상: ⟦직접 입력⟧
x0=[1;1];z0=P\x0;
yx=initial(sys,x0,t);yz=initial(transformed,z0,t);wrong=initial(transformed,x0,t);
disp([max(abs(yx-yz)),max(abs(yx-wrong))]);assert(max(abs(yx-yz))<1e-8);
figure;plot(t,[yx,yz,wrong]);legend('original','correct transformed','wrong initial state');grid on;
직접 수행: 𝐱_0=[1;0], [0;1], [2;1]을 반복하세요. 올바른 변환과 초기값을 그대로 쓴 결과를 각각 비교하고 수치 차이를 표로 기록하세요.
