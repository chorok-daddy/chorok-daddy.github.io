필기시험 예시

인쇄 요금 비교

풀이 과정과 답안 작성 방식을 보여주는 형식 예시입니다. 인쇄 요금을 소재로 식·계산·조건·그래프를 작성합니다.

문항 예시

인쇄 서비스 A는 기본요금 1,200원과 1장당 40원, B는 기본요금 3,000원과 1장당 20원을 받습니다. n은 인쇄 매수이며 0 이상의 정수입니다. 세금과 할인은 없습니다.

제공 참고자료

총비용
기본요금 + (1장당 요금) × 인쇄 매수
  1. 두 서비스의 총비용 C_A(n), C_B(n)을 식으로 쓰고 각 변수의 단위를 표시하세요.
  2. 80장을 인쇄할 때 더 저렴한 서비스를 고르고 비용과 차액을 계산하세요.
  3. B가 A보다 엄밀히 저렴해지는 최소 매수를 구하고 판단 과정을 쓰세요.
  4. 두 비용을 같은 좌표축에 개략적으로 그리고, 절편과 교점을 표시하세요.
답안 작성 예시
  1. C_A(n)=1,200+40n, C_B(n)=3,000+20n. n의 단위는 장, C의 단위는 원입니다.
  2. C_A(80)=4,400원, C_B(80)=4,600원. A가 200원 저렴합니다.
  3. 3,000+20n < 1,200+40n에서 n>90입니다. n은 정수이므로 최소 91장입니다. 90장에서는 두 비용이 4,800원으로 같습니다.
  4. 가로축은 인쇄 매수 n [장], 세로축은 총비용 C [원]입니다. A의 절편은 1,200원, B는 3,000원이며 교점은 (90장, 4,800원)입니다. A의 직선을 B보다 가파르게 그립니다.

답안에 담을 내용

  • 계산 결과와 함께 사용한 식과 대입 과정을 남깁니다.
  • 단위, 부등호의 경계, 정수 조건을 답에 반영합니다.
  • 그래프에는 축·단위와 문제에서 요구한 주요 값을 표시합니다.
