MATLAB 코드 해석 시험 예시

일별 주문 수 집계

코드를 실행하지 않고 값·배열 크기·처리 과정을 손으로 설명하는 형식 예시입니다.

문항 예시

orders의 각 행은 1·2·3일차, 각 열은 매장·온라인·전화 주문 수입니다. 하루 총 주문 수가 6건 이상인 날을 고릅니다.

제공 참고자료

sum(X,1)
각 열의 합을 1×열 수 배열로 반환합니다.
sum(X,2)
각 행의 합을 행 수×1 배열로 반환합니다.
X(:,j)
j번째 열 전체를 선택합니다.
v(mask)
mask가 true인 위치의 원소를 선택합니다.
bar(x,y)
x 위치에 높이 y인 막대를 그립니다.
orders = [2 0 3;
          1 5 0;
          0 2 5];
daily = ________;       % 일별 총 주문 수: 3×1
online = orders(:,2);
busy = daily >= 6;
result = daily(busy);
bar(1:3, daily);
xlabel('Day');
ylabel('Orders');
  1. daily 계산의 빈칸을 한 줄로 채우세요.
  2. daily, online, busy, result의 값과 배열 크기를 각각 쓰세요.
  3. daily >= 6을 daily > 6으로 바꾸면 선택 결과가 어떻게 달라지는지 설명하세요.
  4. 막대그래프를 개략적으로 그리세요. sum(orders,1)을 썼을 때 일별 집계가 되지 않는 이유도 설명하세요.
답안 작성 예시
  1. sum(orders,2). 각 행이 하루이므로 같은 행의 세 주문 채널을 합합니다.
  2. daily=[5;6;7] (3×1), online=[0;5;2] (3×1), busy=[false;true;true] (logical, 3×1), result=[6;7] (2×1)입니다.
  3. busy=[false;false;true], result=7 (1×1)이 됩니다. 총 6건인 2일차가 제외됩니다.
  4. 가로축은 Day 1·2·3, 세로축은 Orders이고 막대 높이는 5·6·7입니다. sum(orders,1)은 채널별 3일 합계 [3,7,8] (1×3)이므로 행의 의미가 일별 합계와 다릅니다.

답안에 담을 내용

  • 행·열 방향이 보이도록 배열을 쓰고 크기를 함께 표시합니다.
  • 빈칸에는 필요한 한 줄만 쓰고, 판단 이유는 해당 연산과 연결합니다.
  • 그래프에는 축 이름과 막대 높이가 드러나도록 표시합니다.
