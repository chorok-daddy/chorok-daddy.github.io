시험 유형별 예시

시험 형식과 답안 작성 수준을 보여주는 공통 예시이며, 예상문제가 아닙니다. 시험 준비는 각 과목에 공지된 출제 범위를 기준으로 하세요.

문제풀이 시험 예시3개
관계식에서 모델·응답 구하기

문제 상황

작은 상자의 내부 온도 T(t)를 히터 전력 P(t)로 조절합니다. 외기 온도는 20 °C로 일정하고, 시작할 때 내부도 20 °C입니다. 내부 온도는 균일하다고 가정합니다. Heat Capacity C=400J/KC=400\,\mathrm{J/K}, Thermal Resistance R=0.5K/WR=0.5\,\mathrm{K/W}이며, 히터는 t=0부터 10 W를 일정하게 공급합니다. 출력은 외기 대비 온도 차 θ(t)=T(t)−20\theta(t)=T(t)-20입니다.

답안 작성 포인트

  • 입력·출력과 기준점을 정하고, 물리 관계식을 변화율 방정식으로 연결하기
  • Initial Condition·단위·평형값을 확인하고, 계수 변화가 응답에 미치는 영향을 설명하기

제공 참고자료

열수지
CdTdt=P−QoutC\frac{dT}{dt}=P-Q_{\mathrm{out}}. C [J/K]는 Heat Capacity, P [W]는 공급 전력, Q_out [W]는 단위 시간에 외기로 전달되는 열량입니다.
방열 관계
Qout=T−TaRQ_{\mathrm{out}}=\frac{T-T_a}{R}. R [K/W]는 Thermal Resistance, T_a는 일정한 외기 온도입니다. 온도 차 1 °C는 1 K와 같습니다.
Laplace Transform
ℒ{ḟ}=sF(s)−f(0),ℒ{1}=1s,ℒ{e−at}=1s+a,a>0\mathcal L\{\dot f\}=sF(s)-f(0),\quad\mathcal L\{1\}=\frac1s,\quad\mathcal L\{e^{-at}\}=\frac1{s+a},\ a>0.
지수함수 값
e−1≈0.368e^{-1}\approx0.368, e−2≈0.135e^{-2}\approx0.135. 그래프는 정확한 수치보다 초기값·최종값·변화 방향이 드러나도록 그립니다.

문항

  1. 열수지 식과 방열 관계를 결합해 입력 P, 출력 θ의 Differential Equation을 세우세요. Initial Condition과 각 항의 단위도 쓰세요.
  2. Initial Condition이 0인 θ에 대해 G(s)=Θ(s)P(s)G(s)=\frac{\Theta(s)}{P(s)}를 유도하고 수치를 대입하세요. 외기 온도 20 °C를 Transfer Function의 출력에 그대로 넣지 않는 이유를 설명하세요.
  3. Θ(s)를 부분분수로 정리하고 T(t)를 구하세요. 시작 온도, 최종 온도, 초기 온도 상승률을 식과 함께 쓰세요.
  4. Heat Capacity만 800 J/K로 바꾸었을 때의 T(t)를 쓰고 기준 응답과 같은 그래프에 개략적으로 그리세요. 축·단위·초기값·최종값을 표시하고, 더 느리게 가열되면서 최종 온도는 같은 이유를 설명하세요.
답안 작성 예시
  1. 열수지는 CdTdt=P−QoutC\frac{dT}{dt}=P-Q_{\mathrm{out}}, 방열은 Qout=T−20RQ_{\mathrm{out}}=\frac{T-20}{R}입니다. 외기가 일정하므로 θ̇=Ṫ\dot\theta=\dot T이며 400θ̇+2θ=P400\dot\theta+2\theta=P, θ(0)=0\theta(0)=0입니다. 400J/K×θ̇[K/s]400\,\mathrm{J/K}\times\dot\theta\,[\mathrm{K/s}]와 2W/K×θ[K]2\,\mathrm{W/K}\times\theta\,[\mathrm K]는 모두 W입니다.
  2. (400s+2)Θ(s)=P(s)(400s+2)\Theta(s)=P(s)이므로 G(s)=1400s+2=0.5200s+1G(s)=\frac1{400s+2}=\frac{0.5}{200s+1}입니다. 입력 단위는 W, 출력은 온도 차 K입니다. T=20+θT=20+\theta의 상수 기준 온도는 마지막에 더합니다. θ(0)=0\theta(0)=0은 T(0)=0∘CT(0)=0\,{}^\circ\mathrm C를 뜻하지 않습니다.
  3. P(s)=10sP(s)=\frac{10}{s}이므로 Θ(s)=5s(200s+1)=5s−5s+1/200\Theta(s)=\frac5{s(200s+1)}=\frac5s-\frac5{s+1/200}입니다. T(t)=20+5(1−e−t/200)[∘C]T(t)=20+5(1-e^{-t/200})\;[{}^\circ\mathrm C]. T(0)=20∘CT(0)=20\,{}^\circ\mathrm C, T(∞)=25∘CT(\infty)=25\,{}^\circ\mathrm C이며, 초기에는 방열이 0이어서 Ṫ(0+)=10400=0.025K/s\dot T(0^+)=\frac{10}{400}=0.025\,\mathrm{K/s}입니다.
  4. 변경 후 T(t)=20+5(1−e−t/400)[∘C]T(t)=20+5(1-e^{-t/400})\;[{}^\circ\mathrm C]입니다. 두 곡선은 20 °C에서 출발해 25 °C로 단조롭게 접근하고, C=800C=800인 곡선이 같은 시각에 더 낮습니다. 초기 상승률은 0.0125 K/s입니다. 저장되는 열의 양은 C에 비례하지만, 평형에서는 저장량의 변화가 0이므로 P=T−20RP=\frac{T-20}{R}만으로 최종 온도가 정해집니다.

문제 상황

High byte=0xE0, Low byte=0x00인 signed 16-bit 측정값입니다. 감도는 16384 LSB/g입니다.

답안 작성 포인트

  • 바이트 순서·부호·감도를 분리해 측정값을 해석하기
  • 설정이나 규격이 바뀌었을 때 같은 원시값의 물리적 의미를 판단하기

제공 참고자료

레지스터 순서
이 사례의 16-bit 센서는 High byte를 먼저 제공합니다. U=256high+lowU=256\,\mathrm{high}+\mathrm{low}입니다.
2의 보수 해석
U<32768이면 signed=U, 그 외는 signed=U−65536입니다.
감도
가속도 a[g]=signed16384a\,[g]=\frac{\mathrm{signed}}{16384}입니다. 바이트는 0x 접두사의 16진수로 적습니다.

문항

  1. 0xE0,0x00의 결합값 U·signed 값·가속도를 변환 과정과 함께 쓰세요.
  2. 바이트 순서를 바꾸어 읽으면 결합값과 가속도가 무엇이 되는지 구하세요.
  3. High=0x20, Low=0x00인 새 측정의 가속도를 구하세요.
  4. 측정 범위를 바꾸어 감도가 8192 LSB/g가 되었다면 원래 0xE0,0x00 기록의 환산값은 무엇인지 쓰고, 함께 저장해야 할 설정 정보를 설명하세요.
답안 작성 예시
  1. U=224×256+0=57344U=224\times256+0=57344. U≥32768이므로 signed=57344−65536=−8192\mathrm{signed}=57344-65536=-8192. a=−819216384=−0.5ga=\frac{-8192}{16384}=-0.5\,g입니다.
  2. U=0×256+224=224U=0\times256+224=224, signed=224, a=22416384≈0.01367ga=\frac{224}{16384}\approx0.01367\,g입니다. 각 바이트의 자리 가중치가 달라집니다.
  3. U=32×256=8192U=32\times256=8192, signed=8192이므로 0.5 g입니다.
  4. −81928192=−1g\frac{-8192}{8192}=-1\,g입니다. 원시값과 함께 측정 범위·감도 설정을 기록해야 올바른 단위로 복원할 수 있습니다.
지표 비교·선택 근거

문제 상황

실제 이상 5개·정상 95개입니다. 모델 A는 항상 정상, B는 TP=4, FP=6, FN=1, TN=89입니다.

답안 작성 포인트

  • 불균형 자료에서 지표가 어떤 오류를 가리는지 판단하기
  • 미탐지와 오경보의 비용을 반영해 모델을 비교하기

제공 참고자료

지표
Accuracy=TP+TNN\mathrm{Accuracy}=\frac{TP+TN}{N}, Recall=TPTP+FN\mathrm{Recall}=\frac{TP}{TP+FN}, Precision=TPTP+FP\mathrm{Precision}=\frac{TP}{TP+FP}.
오류
TP: 이상을 이상으로, TN: 정상을 정상으로, FN: 이상을 정상으로, FP: 정상을 이상으로 판단한 개수입니다.
비용
Cost=20FN+FP\mathrm{Cost}=20FN+FP. Precision 분모가 0이면 이 사례에서는 미정의로 기록합니다.

문항

  1. 모델 A·B의 Accuracy와 Recall을 계산하고 분모가 무엇인지 설명하세요.
  2. B의 Precision과, 항상 정상인 A의 Precision을 어떻게 기록할지 쓰세요.
  3. 주어진 비용으로 두 모델을 비교하고 선택 근거를 쓰세요.
  4. 미탐지 비용이 1로 바뀌면 선택이 달라지는지 계산하세요. 무엇을 확인하고 지표를 골라야 하는지도 설명하세요.
답안 작성 예시
  1. A는 TP=0,FN=5,TN=95,FP=0으로 Accuracy=95100=0.95\mathrm{Accuracy}=\frac{95}{100}=0.95, Recall=05=0\mathrm{Recall}=\frac05=0입니다. B는 Accuracy=93100=0.93\mathrm{Accuracy}=\frac{93}{100}=0.93, Recall=45=0.8\mathrm{Recall}=\frac45=0.8입니다. Accuracy의 분모는 전체, Recall은 실제 이상입니다.
  2. B의 Precision=44+6=0.4\mathrm{Precision}=\frac4{4+6}=0.4. A는 이상으로 예측한 표본이 없어 분모가 0이므로 미정의로 기록합니다.
  3. A 비용=20×5=10020\times5=100, B 비용=20×1+6=2620\times1+6=26으로 B를 선택합니다. Accuracy만 높은 A는 이상을 모두 놓칩니다.
  4. FN 비용이 1이면 A=5, B=7로 A가 더 작습니다. 어느 오류가 얼마나 중요한지와 운영의 이상 비율을 확인해야 하며, 지표 하나가 모든 조건의 최선 모델을 정하지 않습니다.

문제 상황

히터 전력 입력 P [W]에 대한 외기 대비 온도 차 θ[K]\theta\,[\mathrm K]의 Transfer Function은 G(s)=24s+1G(s)=\frac2{4s+1}입니다. 시간 단위는 s이며 초기 온도 차는 0입니다. 입력 크기 1 W인 Step Response를 t=0,2,4,6,8t=0,2,4,6,8에서 읽습니다.

제공 참고자료

tf(num,den)
s의 내림차순 계수로 Transfer Function을 만듭니다. tf(2,[4 1])은 24s+1\frac2{4s+1}입니다.
[y,t_out]=step(g,t)
이 사례의 단일 입력·단일 출력 모델에서 지정한 시간의 단위 Step Response를 반환합니다. 열벡터 t를 주면 y와 t_out은 같은 길이의 열벡터입니다.
dcgain(g)
연속시간 모델의 s=0s=0 이득을 반환합니다. 이 사례의 단위는 K/W입니다. 안정한 모델의 일정 입력에 대한 최종 출력은 이 이득과 입력 크기를 곱한 값입니다.
연산·응답식
(0:2:8)'은 [0;2;4;6;8]. y(mask)는 참인 위치를 고릅니다. G(s)=Kτs+1G(s)=\frac K{\tau s+1}의 Initial Condition이 0일 때의 단위 Step Response는 y(t)=K(1−e−t/τ)y(t)=K(1-e^{-t/\tau})입니다.
계산용 지수값
e−0.5≈0.6065e^{-0.5}\approx0.6065, e−1≈0.3679e^{-1}\approx0.3679, e−1.5≈0.2231e^{-1.5}\approx0.2231, e−2≈0.1353e^{-2}\approx0.1353. 소수 넷째 자리 수준의 근삿값이면 충분합니다.

  • MATLAB dcgain

  4. 분모를 [8 1]로 바꾼 두 번째 모델의 응답을 같은 좌표축에 개략적으로 그리세요. 초기값·최종값·상대적인 응답 속도를 표시하고, t=8의 값이 최종값과 다른 이유도 설명하세요.

v(v>=c)는 c 이상인 원소를 원래 순서대로 고릅니다. >는 경계값을 제외하고 >=는 포함합니다.
빈 배열
[]의 원소 수는 0입니다. 행벡터에 스칼라를 끝에 추가하면 행벡터로 유지됩니다.
duration_s = [2 0 3];
elapsed = 0;
ends = [];
for k = 1:numel(duration_s)
    if duration_s(k) > 0
        elapsed = elapsed + duration_s(k);
        ends(end+1) = ____;
    end
end
active = ends(ends >= 3);

문항

  1. 각 구간의 종료 시각을 기록하도록 빈칸을 채우고, 반복별 k·duration_s(k)·elapsed·ends를 표로 쓰세요.
  2. 반복이 끝난 뒤 ends와 active의 값·배열 크기를 쓰세요.
  3. 조건을 >=0으로 바꾸면 elapsed와 ends가 어떻게 바뀌는지 쓰세요. 총 시간과 기록 수의 변화가 다른 이유를 설명하세요.
답안 작성 예시
  1. 빈칸은 elapsed입니다. 0초 구간에서는 if 내부를 실행하지 않으므로 누적값과 목록이 그대로 남습니다.
    kduration_s(k) [s]elapsed [s]ends
    122[2]
    202[2]
    335[2 5]
  2. ends=[2 5], 1×2입니다. active=5로 1×1입니다. 최종 elapsed는 5 s입니다.
  3. elapsed는 여전히 5 s이고 ends=[2 2 5], 1×3이 됩니다. 0초를 더해도 총 시간은 같지만, 종료 시각 2 s를 한 번 더 기록합니다.

Tensor의 축·shape 해석

문제 상황

행은 세 번의 측정, 열은 같은 온도를 측정하는 두 센서의 출력 [°C]입니다. torch는 import되어 있습니다.

답안 작성 포인트

  • 축마다 무엇을 나타내는지 설명하고, 줄어드는 축과 남는 축을 추적하기
  • 같은 평균 연산도 집계 축에 따라 다른 질문에 답한다는 점을 해석하기

제공 참고자료

x[:, j]
0부터 세는 열 인덱스 j를 선택합니다. 행 전체를 유지합니다.
x.mean(dim=k, keepdim=False)
k축을 평균 내고 그 축을 제거합니다. keepdim=True이면 크기 1인 축을 유지합니다.
원문 문서
  • PyTorch mean
x=torch.tensor([[2.,6.],[4.,8.],[6.,10.]])
a=x[:,0]
b=x.mean(dim=0)

문항

  1. a와 b의 값·shape를 각각 쓰고, b의 각 원소가 뜻하는 것을 설명하세요.
  2. 측정별로 두 센서의 평균을 내는 한 줄을 쓰고 결과·shape를 구하세요.
  3. b 계산에 keepdim=True를 추가했을 때 값과 shape를 쓰세요.
  4. 첫 센서 측정에서 그 센서의 전체 평균을 빼려 합니다. a−b[0]의 값·shape를 쓰고, a−b가 적절하지 않은 이유를 설명하세요.
답안 작성 예시
  1. a=[2,4,6], shape (3,). b=[4,8], shape (2,). dim=0인 측정 축이 줄어 각 센서의 세 측정 평균이 남습니다.
  2. x.mean(dim=1)=[4,6,8], shape (3,). 센서 축을 줄이므로 각 행의 측정별 평균입니다.
  3. 값은 [[4,8]], shape (1,2)입니다. 평균을 낸 측정 축이 크기 1로 남습니다.
  4. a−b[0]=[−2,0,2], shape (3,). a−b는 길이 3과 2의 축 크기가 맞지 않아 Broadcasting되지 않습니다. 측정 축과 센서 축의 의미도 서로 다릅니다.
조건문·빈칸·상태 갱신

문제 상황

상승 Edge가 10,13,18,31,45 ms에 검출됐습니다. 마지막으로 허용한 Edge와 20 ms 이상 떨어져야 허용합니다. 첫 Edge는 허용합니다.

답안 작성 포인트

  • State Variable 갱신 시점과 허용/거절 판단을 차례대로 추적하기
  • 시간 단위와 임계값의 경계를 확인하기

제공 참고자료

허용 규약
첫 Edge는 허용합니다. 이후 t−last_accepted≥20 ms인 Edge만 허용하고, 허용할 때만 last_accepted를 갱신합니다.
상태
last_accepted는 마지막으로 허용한 시각입니다. 거절한 Edge에서는 바꾸지 않습니다.
타이머 단위
이 사례에서는 시각이 ms이며, 오버플로는 발생하지 않습니다.
edges_ms = [10, 13, 18, 31, 45]
last_accepted = None
for t in edges_ms:
    if last_accepted is None or (____):
        last_accepted = t

문항

  1. 참고자료의 허용 규약에 맞게 빈칸을 채우세요. 각 Edge의 허용/거절 여부와 처리 후 last_accepted를 표로 쓰세요.
  2. 거절한 Edge에서도 시각을 갱신하는 잘못된 구현이 31 ms를 어떻게 처리하는지 설명하세요.
  3. 새 Edge가 51 ms에 들어오면 원래 규약으로 허용되는지 근거와 함께 쓰세요.
  4. 타이머를 μs로 바꾸면 같은 정책의 임계값은 얼마인지 쓰세요. 수치 20을 유지했을 때의 문제도 설명하세요.
답안 작성 예시
  1. 빈칸은 t - last_accepted >= 20입니다. 거절한 시각은 다음 비교의 기준으로 남기지 않습니다.
    Edge [ms]허용 여부처리 후 last_accepted [ms]

  3. 51−31=20ms51-31=20\,\mathrm{ms}로 경계를 포함하므로 허용하고 상태를 51로 갱신합니다. 45 ms는 거절했으므로 기준이 아닙니다.

전처리 코드·평가 오류 설명

문제 상황

자료를 Train/Test로 나눈 뒤 StandardScaler와 모델을 학습합니다.

답안 작성 포인트

  • fit으로 배우는 통계와 transform을 적용하는 기준을 구분하기
  • 모델 선택과 최종 평가에 쓰이는 자료의 역할을 구분하기

제공 참고자료

fit / transform
fit(X)는 특징별 평균 μ와 표준편차 σ를 저장합니다. transform(X)는 저장된 값으로 X−μσ\frac{X-\mu}{\sigma}를 계산합니다. fit_transform은 두 동작을 함께 합니다.
평가 규약
Train으로 학습하고 Validation으로 선택한 뒤, Test는 최종 평가에 사용합니다.
수치 예시
한 특징의 Train=[0,4], Test=[6,10]. 표준편차는 모집단 방식(ddof=0)이며 Train의 μ=2,σ=2\mu=2,\ \sigma=2입니다.
원문 문서
  • scikit-learn StandardScaler
scaler.fit(X_train)
X_train2=scaler.transform(X_train)
X_test2=scaler.transform(X_test)

  2. Test에 별도로 fit_transform하면 Test 변환값이 어떻게 바뀌는지 구하고 비교 조건의 차이를 설명하세요.
  3. Train과 Test를 먼저 합쳐 fit한 뒤 나누면 어떤 정보가 전처리에 들어가는지 설명하세요.
  4. Test 성능을 반복해서 보고 모델을 선택했다면 추가 평가를 어떻게 구성해야 하는지 설명하세요.
답안 작성 예시

  2. Test 자체의 μ=8,σ=2\mu=8,\ \sigma=2를 쓰므로 [−1,1]이 됩니다. Test의 분포를 새 기준으로 삼아 학습 때와 다른 좌표로 입력하게 됩니다.

응답·배열 인덱싱

문제 상황

히터 전력 입력 P [W]에 대한 외기 대비 온도 차 θ[K]\theta\,[\mathrm K]의 Transfer Function은 G(s)=24s+1G(s)=\frac2{4s+1}입니다. 시간 단위는 s이며 초기 온도 차는 0입니다. 입력 크기 1 W인 Step Response를 t=0,2,4,6,8t=0,2,4,6,8에서 읽습니다.

답안 작성 포인트

  • Transfer Function의 계수·입력 크기와 응답의 최종값·속도를 연결하기
  • 반환 배열의 시간 대응과 선택 조건을 추적하고, 일부 시점의 값과 Steady State 값을 구분하기

제공 참고자료

ct.tf(num,den)
s의 내림차순 계수로 Transfer Function을 만듭니다. ct.tf([2],[4,1])은 24s+1\frac2{4s+1}입니다.
ct.step_response(g,timepts=t,squeeze=True)
지정한 시간의 Initial Condition이 0일 때의 단위 Step Response를 반환합니다. 이 단일 입력·단일 출력 사례에서 response.time과 response.outputs는 길이가 같은 1차원 배열입니다.
ct.dcgain(g)
연속시간 모델의 s=0s=0 이득을 반환합니다. 이 사례의 단위는 K/W입니다. 안정한 모델의 일정 입력에 대한 최종 출력은 이 이득과 입력 크기를 곱한 값입니다.
배열·응답식
np.arange(0,9,2)는 9 미만까지 2씩 증가하는 [0,2,4,6,8]입니다. y[mask]는 참인 위치를 선택합니다. G(s)=Kτs+1G(s)=\frac K{\tau s+1}의 단위 Step Response는 y(t)=K(1−e−t/τ)y(t)=K(1-e^{-t/\tau})입니다.
계산용 지수값
e−0.5≈0.6065e^{-0.5}\approx0.6065, e−1≈0.3679e^{-1}\approx0.3679, e−1.5≈0.2231e^{-1.5}\approx0.2231, e−2≈0.1353e^{-2}\approx0.1353. 소수 넷째 자리 수준의 근삿값이면 충분합니다.
원문 문서
  • Python Control step_response
  • Python Control dcgain
import control as ct
import numpy as np
import matplotlib.pyplot as plt

g = ct.tf([2],[4,1])
t = np.arange(0,9,2)
response = ct.step_response(g,timepts=t,squeeze=True)
t_out = response.time
y = response.outputs
gain = ct.dcgain(g)
picked = y[t_out >= 4]
plt.plot(t_out,y)
plt.xlabel('Time [s]')
plt.ylabel('Temperature rise [K]')

  2. t_out과 y의 값·shape를 쓰세요. 응답식에 t=4를 대입한 계산을 보이세요.
  3. picked의 값·shape를 쓰고, 조건을 t_out>4로 바꾸면 어떤 시점이 빠지는지 설명하세요.
  4. 분모를 [8,1]로 바꾼 두 번째 모델의 응답을 같은 좌표축에 개략적으로 그리세요. 초기값·최종값·상대적인 응답 속도를 표시하고, t=8의 값이 최종값과 다른 이유도 설명하세요.
답안 작성 예시
