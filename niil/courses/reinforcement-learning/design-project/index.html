연구 도메인 설계과제

7–8주 주제 안내·확정 · 12주 실험계획 점검 · 13–15주 구현·평가·발표

설계주제 정하기

  • 본인의 연구 문제를 자유주제로 선택하거나 제어·전력·로봇 등 제시된 분야 안에서 선택합니다. 기존 공개 환경이나 데이터를 사용해도 됩니다.
  • 어떤 판단·제어를 개선하려는지, 현재의 기준 방법이 무엇인지 먼저 적습니다. 환경·데이터·장비를 실제로 확보할 수 있는 범위로 정합니다.

문제와 비교 기준

  • 상태·관측, 행동, 보상 또는 평가 목적, 제약 조건을 정의합니다. 공개 데이터만 사용하는 경우에는 무엇을 학습·평가할 수 있고 무엇은 확인할 수 없는지 구분합니다.
  • 기준 정책·제어기·모델과 제안 방법 하나를 정하고, 개선 여부를 판단할 지표와 실패 조건을 적습니다.

실험계획 점검

  • 학습·평가 환경 또는 데이터 분할, 비교군, 학습 예산, 평가 조건을 정합니다.
  • CPU에서 가능한 기준 실험부터 준비합니다. GPU·Jetson·로봇 장비 사용은 주제에 필요한 경우 추가합니다.

기준 구현

  • 확보한 환경·데이터에서 기준 방법을 실행하고, 실행 명령·설정·seed와 결과를 함께 저장합니다.
  • 환경·데이터를 바꾸지 않고도 결과를 다시 확인할 수 있도록 코드를 정리합니다.

비교 실험과 실패 분석

  • 한 가지 개선을 적용하고 같은 평가 조건에서 기준 방법과 비교합니다. 결과의 변동이 결론에 영향을 주면 여러 seed나 평가 Episode로 확인합니다.
  • 성공 사례와 함께 성능이 나빠지거나 제약을 위반한 조건을 찾아 원인을 분석합니다.

결과 정리와 발표

  • 실행 가능한 코드·설정, 비교 표·핵심 그래프, 문제 정의·방법·결과·한계를 설명하는 자료를 정리합니다.
  • 사용한 공개 환경·데이터·기존 구현의 출처를 남기고, 직접 변경한 부분과 확인한 기여를 구분합니다.
