텍스트 분류는 자연어 처리의 일종으로, 텍스트에 레이블 또는 클래스를 지정하는 작업이며, 다양한 실용적인 응용 분야에서 텍스트 분류사용한다.

이 강의자료에서 학습할 내용은:

  1. IMDb 데이터셋을 이용해, 오픈소스로 공유된 사전학습 모델을 이용해 영화 리뷰가 긍정적인지 부정적인지 판단합니다.
  2. 이 강의자료에서는 DistillBert 기반의 사전학습모델을 사용합니다. jzonthemtn/distilbert-imdb

Accuracy

import numpy as np

def classification_accuracy(predictions, labels):
    return {'accuracy': float(np.mean(np.asarray(predictions) == np.asarray(labels)))}

def compute_metrics(eval_pred):
    predictions, labels = eval_pred
    predictions = np.argmax(predictions, axis=1)
    return classification_accuracy(predictions, labels)
