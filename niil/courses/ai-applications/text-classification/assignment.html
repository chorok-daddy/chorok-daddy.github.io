14주차 · Text Classification과 Sentiment Analysis

실습 전에

01 문장을 계산 가능한 형태로 바꾸기

컴퓨터가 문장의 감정을 분류하려면, 단어와 문장을 어떤 형태로 바꾸어 주어야 할까요?

설명
  • Token ID: 단어 또는 Token의 식별자
  • Embedding과 분류 모델: 예측에 유용한 표현을 학습

02 문장마다 다른 길이

길이가 다른 문장들을 한 번에 계산하려면 어떻게 묶어야 할까요? 길이를 맞추기 위해 채운 부분은 실제 단어와 어떻게 구분해야 할까요?

설명
  • 문장 표현에 불필요한 Padding 값이 반영됨. Mask로 제외
  • 평균 기반 표현은 단어 순서를 직접 보존하지 않음

실습

1. 토큰과 vocabulary

  1. 길이가 다른 두 영어 문장을 Token → Index → PAD 순서로 출력하세요.
  2. 학습 사전에 없는 단어 하나를 넣고 UNK 위치를 확인하세요.
  3. 실제 단어를 뜻하는 Index와 PAD·UNK를 구별해 적으세요.

2. 마스킹한 평균과 학습

  1. 같은 문장을 혼자 처리할 때와 긴 문장과 묶을 때 Mask 적용 전후 평균을 비교하세요.
  2. 다른 문장 쌍으로 한 번 더 확인하고, 단어 순서를 바꾼 두 문장의 Logit도 비교하세요.
  3. 차이가 0에 가까운 이유를 설명하세요.

3. 새 문장 직접 입력

  1. 학습 사전의 단어로 긍정·중립·부정 영어 문장을 하나씩 my_reviews에 작성하세요.
  2. 의도한 감정·예측·Token을 기록하고, 모르는 단어나 문장부호를 하나 넣어 UNK 처리를 확인하세요.
  3. 예측이 의도와 달라도 원인을 설명하면 됩니다.
