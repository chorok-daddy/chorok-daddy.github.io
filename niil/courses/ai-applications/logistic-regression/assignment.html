7주차 · 확률과 분류 기준을 구분하기 실습

실습 전에

01 숫자 예측과 분류

예시 상황 내일의 온도를 예측하는 일과 장치가 정상인지 판단하는 일은, 모델에서 얻고 싶은 결과가 어떻게 다를까요?

설명
  • 온도 예측은 수치를, 정상·이상 판단은 범주를 얻는 문제입니다. 원하는 결과에 따라 모델의 출력과 학습 기준을 정합니다.
  • Binary Classification에서는 두 범주 중 하나를 고르기 위한 점수를 학습합니다. Logistic Regression은 이를 위한 기본 모델입니다.

관련 학습자료 ↗

02 예측을 판단으로 바꾸기

예시 상황 모델이 고장 가능성을 숫자로 알려주었습니다. 실제 경보를 울릴 기준은 어떻게 정하면 좋을까요?

설명
  • 모델의 점수를 경보 여부로 바꾸는 Threshold가 필요합니다.
  • 고장을 놓치는 비용과 불필요한 경보의 비용을 함께 고려합니다. 점수를 내는 모델과 행동을 정하는 기준은 구분합니다.

관련 학습자료 ↗

실습 안내로 이동 ↓

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. CSV의 입력 확인

전처리 전후 shape·dtype·처음 다섯 표본을 확인하세요. 평균과 표준편차를 새 입력에도 동일하게 적용해야 하는 이유를 쓰세요.

2. 기준 학습 실행

같은 초기화와 1000 epoch에서 Learning Rate 0.001·0.01·0.1을 비교하세요. 마지막 Training Loss·Accuracy를 표로 기록하고 가장 빨리 Loss가 줄어드는 조건을 설명하세요. 특정 Accuracy를 얻을 때까지 무제한 반복하지 않습니다.

3. 출력을 해석하기

한 번 학습한 동일 모델에서 Threshold 0.3·0.5·0.7의 Accuracy와 Positive 예측 개수를 구하세요. 예측이 바뀐 표본을 최대 3개 골라 Probability·정답·판정을 비교하세요. 바뀐 표본이 없으면 없다고 기록하세요.
