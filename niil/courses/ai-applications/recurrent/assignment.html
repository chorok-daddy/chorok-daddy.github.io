실습 전에

01 현재 문자만으로 충분할까

hello의 두 l 뒤에는 서로 다른 문자가 옵니다. 현재 문자 하나만 보고 다음 문자를 맞힐 수 있을까요?

설명
  • 첫 l 뒤에는 l, 둘째 l 뒤에는 o가 옵니다. 현재 문자만으로 두 상황을 구별할 수 없습니다.
  • 앞에서 읽은 정보를 함께 사용하면 두 위치를 구별할 수 있습니다. 순서가 예측에 필요한 정보가 되는 사례입니다.

관련 개념 복습 ↗

02 분류에 기억을 더하기

다음 문자를 고르는 데에도 앞서 배운 분류 방법을 사용할 수 있을까요?

설명
  • 후보 문자별 점수를 계산하고 정답 문자와 비교하는 것은 분류와 같습니다.
  • RNN은 이전 정보를 Hidden State로 전달해 예측에 활용합니다. 이번 실습에서는 각 위치의 Input·Target과 예측을 나란히 확인합니다.

관련 개념 복습 ↗

실습

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. 문자 Batch(배치) 구성

각 문장의 Input과 Target을 문자로 출력하고 한 글자씩 대응하는지 확인하세요. X·Y의 각 축과 문자 사전 크기를 적으세요. 공백과 문장부호도 세어야 합니다.

2. RNN 학습

학습 전후 예측 문자열을 Target과 비교하고 달라진 위치를 적으세요. 같은 학습 모델에 X[:, :4, :], X[:, :6, :], X[:, :8, :]을 넣어 출력의 Sequence 길이를 확인하세요. 세 조건을 반복 기록표에 정리하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.
