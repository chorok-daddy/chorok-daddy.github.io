다음 문자 정답을 맞추기

기말시험 · 예시 2

문제 상황

토큰 ID 0,1,2는 각각 A,B,C입니다. 아래는 다음 문자 예측용 입력·정답을 만듭니다.

이해하고 적용할 내용

  • 시퀀스의 입력과 정답이 시간상 어떻게 대응하는지 추적하기
  • Batch·시간·Class 축과 인덱스 정답을 구분하기

제공 참고자료

시퀀스 슬라이스
v[:-1]은 마지막 원소를 빼고, v[1:]은 첫 원소를 뺍니다.
분류 출력 규약
이 예시는 각 시점의 CrossEntropyLoss 입력을 (시점 수, Class 수) Logits, 정답을 (시점 수,) 정수 Class 인덱스로 둡니다.
Class 사전
0=A, 1=B, 2=C. 사전 크기는 3입니다.
원문 문서
  • PyTorch CrossEntropyLoss
ids=torch.tensor([0,2,1,2])
x=ids[:-1]
y=ids[1:]

문항

  1. x·y의 값과 shape를 쓰고 입력→정답의 문자 쌍을 나열하세요.
  2. y=x로 바꾸면 모델이 무엇을 맞히도록 학습하는지 설명하세요.
  3. 주어진 세 시점의 Logits와 정답에 필요한 shape를 쓰세요.
  4. 문자 D를 사전에 추가하되 현재 시퀀스는 유지할 때, 바뀌는 출력 크기와 유지되는 입력·정답 크기를 구분하세요.
답안 작성 예시
  1. x=[0,2,1], y=[2,1,2], 각각 shape (3,). A→C, C→B, B→C입니다.
  2. 다음 문자 대신 현재 문자를 복원하는 목표가 됩니다. 시퀀스 길이가 맞아도 학습 의미가 달라집니다.
  3. Logits (3,3), 정답 (3,). 앞의 3은 예측 시점 수, 뒤의 3은 Class 수입니다.
  4. 사전이 4 Class가 되어 Logits (3,4)가 필요합니다. 현재 토큰·시점은 그대로이므로 x와 y는 여전히 (3,)입니다.
