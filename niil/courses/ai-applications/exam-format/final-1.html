이미지의 중간 shape 추적

기말시험 · 예시 1

문제 상황

입력은 Batch 4개, 단일 채널 12×12 영상입니다. Conv는 kernel=3, stride=1, padding=0, 출력 채널=2입니다.

이해하고 적용할 내용

  • Batch·채널·공간 축을 구분하고 층 사이에 연결되는 shape를 추적하기
  • 계산 규칙을 새 입력 크기에 적용해 Linear 입력과 모델 연결을 판단하기

제공 참고자료

공간 크기
dilation=1일 때 각 축의 출력 크기 O=floor((L+2p−k)/s)+1. Conv와 Pool의 H·W에 각각 적용합니다.
축과 채널
Conv2d의 입력/출력은 (N,C,H,W). 출력 C는 out_channels이며 Batch N은 유지됩니다.
flatten(start_dim=1)
Batch 다음 축들을 곱해 한 특징 축으로 합칩니다. Linear(in_features,out_features)는 마지막 특징 축을 바꿉니다.
원문 문서
  • PyTorch Conv2d
Conv2d(1,2,3) → MaxPool2d(2,2) → flatten(start_dim=1)

문항

  1. Conv·Pool·Flatten 후 shape를 쓰고, 공간 크기 계산을 한 축에 대해 보이세요.
  2. 세 Class로 분류할 마지막 Linear의 in_features·out_features를 쓰고 Batch가 in_features에 들어가지 않는 이유를 설명하세요.
  3. Conv의 padding만 1로 바꾸면 각 단계의 shape와 필요한 Linear가 어떻게 달라지는지 쓰세요.
  4. 기준 모델에서 Batch만 1로 바꾸면 어떤 크기가 달라지는지 쓰고, Linear(50,3)을 그대로 쓸 수 있는지 설명하세요.
답안 작성 예시
  1. Conv (4,2,10,10): floor((12−3)/1)+1=10. Pool (4,2,5,5): floor((10−2)/2)+1=5. Flatten (4,50).
  2. Linear(50,3)입니다. 한 표본의 특징은 2×5×5=50개이며 Batch 4는 함께 처리하는 표본 수입니다.
  3. Conv (4,2,12,12), Pool (4,2,6,6), Flatten (4,72)이므로 Linear(72,3)이 필요합니다.
  4. 각 단계의 첫 축만 1로 바뀝니다. Flatten은 (1,50), 최종 출력은 (1,3)이므로 기존 Linear를 쓸 수 있습니다.
