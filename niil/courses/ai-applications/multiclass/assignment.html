8주차 · 클래스별 점수를 읽고 비교하기 실습

실습 전에

01 여러 범주를 구분하기

예시 상황 사진을 고양이, 개, 새 중 하나로 분류하려고 합니다. 모델이 이 세 범주를 구분하도록 정답과 예측을 어떻게 표현하면 좋을까요?

설명
  • 각 범주에 Class ID를 부여하고, 모델은 범주별 점수를 출력하도록 구성할 수 있습니다.
  • Class ID는 식별자입니다. 번호의 크기가 범주의 순서나 거리를 뜻하지는 않습니다.

02 예측의 확신

모델이 하나의 범주를 골랐다고 해서 확실하게 구분했다고 볼 수 있을까요? 어떤 경우에 판단을 유보하고 싶을까요?

설명
  • 최대 점수의 위치는 예측 Class를 지정
  • 점수 차이와 별도의 신뢰도 평가 필요. Logit 자체는 확률이 아님

실습

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. CSV의 입력 확인

전처리 전후 shape·dtype·처음 다섯 표본을 확인하세요. 평균과 표준편차를 새 입력에도 동일하게 적용해야 하는 이유를 쓰세요.

2. 기준 학습 실행

같은 초기화와 1000 epoch에서 Learning Rate 0.001·0.01·0.1을 비교하세요. 마지막 Training Loss·Accuracy를 표로 기록하고 Loss와 Accuracy의 변화가 항상 같은지 해석하세요. 이 값은 별도 Test Accuracy가 아닙니다.

3. 출력을 해석하기

첫 10개 표본의 Logit·Probability·예측·정답을 비교하세요. Softmax 합이 표본마다 1인지, Logit과 Probability의 argmax가 같은지 검증하세요. 오분류를 최대 3개 골라 실제 Label과 예측 Label을 적고, 없으면 없다고 기록하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.
