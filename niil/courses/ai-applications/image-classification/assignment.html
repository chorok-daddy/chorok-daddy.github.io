10주차 · 이미지 분류의 학습과 평가 분리하기 실습

실습 전에

01 새로운 데이터에서의 성능

예시 상황 연습한 사진을 잘 맞히는 모델이 처음 보는 사진도 잘 구분할지, 어떻게 확인할 수 있을까요?

설명
  • 학습 데이터의 적합도와 Generalization을 구분
  • 학습에 사용하지 않은 데이터로 성능 평가

02 틀린 예측에서 얻는 정보

예시 상황 모델이 몇 개를 맞혔는지 아는 것과 어떤 사진을 틀렸는지 보는 것은, 각각 무엇을 알려줄까요?

설명
  • 특정 Class나 입력 조건에 집중되는 오류
  • 데이터·Label의 문제와 모델의 한계

실습

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. MNIST와 실행 규모

이미지 한 장의 shape와 label을 확인하고 DataLoader의 마지막 Batch(배치) 크기를 조사하세요.

2. CNN 학습과 평가

이번 실습은 QUICK_RUN=True로 진행하고 사용 epoch와 학습·평가 데이터 수를 기록하세요. 더 많은 데이터로 비교하려면 전체 데이터 학습을 실행할 수 있습니다. train과 eval, no_grad의 서로 다른 역할을 설명하세요.

3. 그래프와 오분류

맞힌 예와 틀린 예를 보고 결과를 해석하세요. subset 결과와 전체 test accuracy를 혼동하지 않았는지 점검하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.
