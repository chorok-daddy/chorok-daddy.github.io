6주차 · 예측 오차를 줄이며 직선 찾기 실습

실습 전에

01 식에서 데이터로

직선의 식으로 값을 계산하는 것과, 측정값에서 직선의 식을 찾는 것은 무엇이 다를까요?

설명
  • 앞에서는 기울기를 알고 결과를 계산했다면, 이번에는 데이터의 경향을 설명할 기울기를 찾습니다.
  • 실습에서는 절편을 0으로 고정하고 기울기 하나를 조절합니다. 모델이 허용하는 직선의 범위를 단순하게 정한 것입니다.

관련 개념 복습 ↗

02 학습과 가정

기울기를 계속 조절하면 어떤 데이터든 오차 없이 설명할 수 있을까요?

설명
  • 원점을 지나는 직선만 허용하면, 원점을 지나지 않는 관계나 곡선 형태의 데이터를 정확하게 표현하기 어렵습니다.
  • Loss와 Gradient로 선택한 모델 안에서 오차를 줄입니다. 반복 횟수를 늘리는 것과 모델의 가정을 바꾸는 것은 다릅니다.

관련 개념 복습 ↗

실습 안내로 이동 ↓

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. 원점을 지나는 회귀 문제

A의 첫 열은 입력 x이고 두 번째 열의 1은 Bias를 계산할 때 쓸 상수입니다. 이번에는 Bias를 쓰지 않으므로 첫 열만 A_prime으로 선택합니다. 이 선택과 bias=False의 관계를 설명하세요. 데이터가 원점을 정확히 지나지 않으면 어떤 오차가 남을지 예측하세요.

2. 학습과 기록

Learning Rate(학습률) 0.001·0.01·0.1로 같은 epoch 수를 비교하세요. loss.backward 직후 weight.grad를 출력하여 Gradient(기울기)를 관찰하고 zero_grad가 빠지면 생기는 문제를 설명하세요.

3. 직접 해와 대조

이 실습의 A_prime을 사용해 A_prime.T@A_prime이 가역인지 확인하세요. torch.linalg.inv(A_prime.T@A_prime)@A_prime.T@B_prime과 pinv(A_prime)@B_prime, Gradient 학습 결과를 비교하세요. x=0,1,2,3의 wx와 실제 Target의 차이를 기록하세요.
