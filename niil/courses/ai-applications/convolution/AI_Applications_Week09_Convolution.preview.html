1. 간단한 CNN으로 각 층의 shape 확인하기

먼저 Conv Layer가 하나인 모델을 실행한 뒤, Conv Layer가 세 개인 CNN을 직접 만들어봅니다.

A. 기준 예제 · 먼저 읽고 실행

import sys, numpy as np, matplotlib.pyplot as plt
import torch
from torch import nn
import torch.nn.functional as F
torch.manual_seed(42)
torch.set_num_threads(2)
print('Python:', sys.version.split()[0], '| PyTorch:', torch.__version__)
small=nn.Sequential(nn.Conv2d(1,4,3,padding=1),nn.ReLU(),nn.MaxPool2d(2),nn.Flatten(1),nn.Linear(4*14*14,10))
x=torch.randn(8,1,28,28)
for layer in small:
    x=layer(x);print(type(layer).__name__,tuple(x.shape))
assert x.shape==(8,10)

B. 직접 수행

Input (N,1,28,28)에 Conv2d(1,32,3,padding=1)→ReLU→MaxPool2d(2)→Conv2d(32,64,3,padding=1)→ReLU→MaxPool2d(2)→Conv2d(64,128,3,padding=1)→ReLU→MaxPool2d(2,padding=1)→Flatten(start_dim=1)→Linear(2048,625)→ReLU→Dropout→Linear(625,10)을 구현하세요. 각 단계의 예상 shape를 먼저 적고 실제 출력으로 확인하세요.

예상은 정확한 수치 대신 shape나 증가·감소 방향으로 적어도 됩니다. 코드는 위 예제를 참고해 작성하고, 설명만 묻는 항목은 아래 Text Cell에 답하세요.

2. Batch(배치) 크기와 parameter

Batch 크기는 한 번에 넣는 이미지 수입니다. 이미지 수를 바꿔도 Filter와 Weight의 개수는 바뀌지 않는지 확인합니다.

A. 기준 예제 · 먼저 읽고 실행

for batch in [1,8,32]:
    print('batch:',batch,'output:',small(torch.randn(batch,1,28,28)).shape)
print('parameters:',sum(p.numel() for p in small.parameters()))

B. 직접 수행

앞에서 직접 만든 CNN에 N=1·8·32를 각각 넣어 최종 (N,10)을 확인하세요. Parameter 수는 sum(p.numel() for p in model.parameters())로 구해 N을 바꿔도 같은지 검사하세요. model.eval() 상태에서 비교하고 학습 가능한 Layer와 그렇지 않은 Layer를 구분하세요.
