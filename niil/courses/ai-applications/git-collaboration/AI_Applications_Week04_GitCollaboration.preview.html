실습 목적

수정 내용을 Commit으로 기록하고, PR에서 변경을 검토한 뒤 Merge했을 때 main에 반영되는 과정을 확인합니다. 이번 실습은 본인 Repository에서 수행하며, 동료 Repository의 Fork·PR은 선택 실습입니다.

외부 기여자의 수정 제안 사례와 각 단계가 필요한 이유는 학습자료의 설명을 참고하세요.

실습 순서와 이유: 먼저 Colab의 임시 Repository에서 로그인·권한 설정 없이 파일 수정·Commit·Branch의 관계를 확인합니다. 이어서 GitHub 웹에 별도 저장소를 만들어 PR의 검토와 Merge를 연습합니다. Colab에서 만든 저장소를 업로드하는 과정이 아니라, Git의 변경 기록을 이해한 뒤 GitHub의 협업 기능을 사용하는 구성입니다.

실행·작성 방법

위에서부터 Code Cell의 ▶ 또는 Shift+Enter로 실행하세요. Text Cell은 더블클릭해 ⟦직접 입력⟧을 작성하고 Shift+Enter로 표시합니다. 직접 작성 셀에는 본인 코드를 넣으세요. 값을 바꾸면 해당 셀과 뒤의 관련 셀을 다시 실행합니다.

실행 환경: Colab CPU. 외부 다운로드는 해당 셀에 안내합니다. 라이브러리 오류가 나면 새 런타임에서 확인한 뒤 조교에게 문의하세요.

1. 내 작업 공간에서 Git 연습하기

임시 폴더에서 commit과 branch만 연습합니다. 실제 협업 과제는 과제 안내에서 이어갑니다.

A. 기준 예제 · 먼저 읽고 실행

import tempfile, pathlib, subprocess
repo=pathlib.Path(tempfile.mkdtemp(prefix='course-git-'))
def git(*args):
    return subprocess.check_output(['git','-C',str(repo),*args],text=True,stderr=subprocess.STDOUT)
git('init','-b','main');git('config','user.name','Student Example');git('config','user.email','example@example.invalid')
(repo/'README.md').write_text('# Practice\nBaseline\n')
git('add','README.md');git('commit','-m','Add baseline')
git('switch','-c','practice-change')
(repo/'README.md').write_text('# Practice\nBaseline\nMy change\n')
print(git('diff'));git('add','README.md');git('commit','-m','Describe one change')
print(git('log','--oneline','--all','--graph'))

B. 직접 수행

Branch는 별도로 변경을 기록하는 작업 흐름입니다. 이번에는 기본 Branch인 main에서 practice를 만들어 수정합니다. Pull Request(PR)는 이 변경을 main에 합치기 전에 검토해 달라는 요청이고, Merge는 검토한 변경을 실제로 합치는 작업입니다. PR을 만드는 것만으로 main이 바뀌지는 않습니다.

  1. Colab에서 변경 이력 연습: 로컬 예제의 문장을 한 줄 수정하고 git diff → add → commit → log를 직접 반복하세요.

  2. GitHub에 연습 Repository 만들기: README를 포함한 개인 연습 Repository를 만드세요.

  3. Branch에서 수정하고 Commit하기: 새 Branch practice를 만들고 README에 이번 주 배운 내용을 추가하여 Commit하세요.

  4. PR 검토 후 Merge하기: practice → main의 Pull Request를 열고 Files changed에서 변경을 검토한 뒤 Merge하세요.

  5. 변경 전후 설명하기: 조교 또는 동료에게 두 Branch의 역할과 Merge 전후 차이를 설명하세요.

  6. 결과 기록하기: Repository URL, Commit 이력, PR 변경 내용과 Merge 완료 화면을 Notebook에 기록하세요.

선택 실습: 동료의 연습 Repository를 Fork하고 한 줄 수정하여 원본으로 PR을 제안해 Collaborator 방식과 비교하세요.

각 단계에서 변경이 어느 Branch에 기록되어 있는지 확인하세요. PR을 열었을 때와 Merge했을 때 main의 내용이 어떻게 다른지 비교합니다.
