이미지 분류 정확도 뒤의 오답을 살펴보며 전처리와 자료 분리의 영향을 확인합니다.

이미지 표본의 구조

load_digits의 작은 Gray 영상도 픽셀 배열·정답·표본 구분을 갖습니다. 정규화와 학습·평가 분리를 먼저 정하고, 실제 오답 영상을 봅니다.

평균 정확도 다음에 볼 것

어떤 클래스나 흐린 입력에서 오류가 모이는지 확인합니다. 작은 잡음을 넣은 결과는 별도 조건으로 평가하며, 변형된 표본과 원래 표본이 학습·평가에 섞이지 않게 합니다.

풀이 예제

외부 다운로드 없는 sklearn load_digits의 8×8 영상 중 Class 0~4를 사용합니다. 분할은 stratified 70/30, seed=7입니다. 

from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
D=load_digits();mask=D.target<5;X=D.data[mask];y=D.target[mask]
Xtr,Xte,ytr,yte=train_test_split(X,y,test_size=.3,random_state=7,stratify=y)
scaler=StandardScaler().fit(Xtr);clf=LogisticRegression(max_iter=1000).fit(scaler.transform(Xtr),ytr)
print(clf.score(scaler.transform(Xte),yte))
