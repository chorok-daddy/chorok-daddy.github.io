군집 수와 관성값

시작 조건

make_blobs(n_samples=180,centers=3,cluster_std=.8,random_state=7), K∈{2,3,4}K\in\{2,3,4\}를 사용합니다.

진행 방법

  1. 각 K에서 KMeans(random_state=7,n_init=10)를 학습하세요.
  2. 군집 중심·배정 결과를 그리고 Inertia와 Silhouette를 적으세요.

남길 결과

  • 세 군집 그림과 지표 표. 
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
X,_=make_blobs(n_samples=180,centers=3,cluster_std=.8,random_state=7)
model=KMeans(n_clusters=3,random_state=7,n_init=10).fit(X)
print(model.inertia_,silhouette_score(X,model.labels_))
