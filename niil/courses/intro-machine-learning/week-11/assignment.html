군집 수와 스케일을 바꾸면 같은 자료의 묶음도 달라집니다. 군집 번호 자체에 의미를 부여하지 않고 구조를 읽습니다.

실습 코드 앞의 코드 셀에서 import numpy as np, import matplotlib.pyplot as plt를 실행하세요. 배열 연산에는 np, 그림에는 plt를 사용합니다.

실습 전에

01 군집 번호 0은 특별한 의미가 있을까요?

설명

번호는 임의의 식별자이므로 중심과 배정 구조로 군집을 비교합니다.

02 특징의 단위가 다르면 거리도 달라질까요?

설명
