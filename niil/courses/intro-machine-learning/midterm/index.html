시험 유형·답안 예시

수업 개념을 다른 수치·상황에 적용하는 공개 연습 예시입니다. 실제 시험문항과 구분해 활용하세요.

1. 회귀 예측과 외삽

관측 입력 범위는 0–4이고 모델은 y_hat=2x+3입니다. 기준값은 x=[0,2,4]에서 y=[3,8,11]입니다.

prediction=2*x+3
  1. 세 예측과 절댓값 오차의 평균을 쓰세요.
  2. x=8 예측이 맞는지 이 자료만으로 확신할 수 있는지 설명하세요.
답안 예시와 풀이
  1. 예측 [3,7,11], MAE=1/3.
  2. x=8은 관측 범위 밖의 외삽입니다. 계산값 19와 실제 정확성을 구분해야 합니다.

2. 불균형 자료의 경보 평가

실제 이상 5개·정상 95개입니다. 모델 A는 항상 정상, B는 TP=4, FP=6, FN=1, TN=89입니다.

accuracy=(TP+TN)/100
  1. 두 모델의 Accuracy와 이상 검출 Recall을 쓰세요.
  2. Accuracy만으로 A를 선택하기 어려운 이유를 쓰세요.
답안 예시와 풀이
  1. A: Accuracy=.95, Recall=0. B: Accuracy=.93, Recall=.8.
  2. A는 모든 이상을 놓칩니다. 이상 미탐지의 비용도 고려해야 합니다.
