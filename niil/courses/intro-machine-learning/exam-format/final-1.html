기말시험 · 예시 1

문제 상황

자료를 Train/Test로 나눈 뒤 StandardScaler와 모델을 학습합니다.

이해하고 적용할 내용

  • fit으로 배우는 통계와 transform을 적용하는 기준을 구분하기
  • 모델 선택과 최종 평가에 쓰이는 자료의 역할을 구분하기

참고자료로 확인할 정보

StandardScaler의 API·표준화 식은 참고자료로 제공합니다.

제공 참고자료

fit / transform
fit(X)는 특징별 평균 μ와 표준편차 σ를 저장합니다. transform(X)는 저장된 값으로 (X−μ)/σ를 계산합니다. fit_transform은 두 동작을 함께 합니다.
평가 규약
Train으로 학습하고 Validation으로 선택한 뒤, Test는 최종 평가에 사용합니다.
수치 예시
한 특징의 Train=[0,4], Test=[6,10]. 표준편차는 모집단 방식(ddof=0)이며 Train의 μ=2, σ=2입니다.
원문 문서
  • scikit-learn StandardScaler
scaler.fit(X_train)
X_train2=scaler.transform(X_train)
X_test2=scaler.transform(X_test)

문항

  1. 제시된 올바른 코드로 수치 예시의 Train·Test 변환값을 구하세요.
  2. Test에 별도로 fit_transform하면 Test 변환값이 어떻게 바뀌는지 구하고 비교 조건의 차이를 설명하세요.
  3. Train과 Test를 먼저 합쳐 fit한 뒤 나누면 어떤 정보가 전처리에 들어가는지 설명하세요.
  4. Test 성능을 반복해서 보고 모델을 선택했다면 추가 평가를 어떻게 구성해야 하는지 설명하세요.
답안 작성 예시
  1. Train은 [−1,1], Test는 [(6−2)/2,(10−2)/2]=[2,4]입니다. 둘 다 같은 Train 기준을 씁니다.
  2. Test 자체의 μ=8,σ=2를 쓰므로 [−1,1]이 됩니다. Test의 분포를 새 기준으로 삼아 학습 때와 다른 좌표로 입력하게 됩니다.
  3. 아직 보지 않아야 할 Test의 평균·분산 정보가 학습 전처리에 섞입니다. 실제 새 자료에 적용할 조건과 다른 평가가 되어 정보 누출이 발생합니다.
  4. 모델 선택은 별도 Validation이나 교차 검증으로 하고, 선택 후 한 번 평가할 독립 Test를 확보합니다. 이미 선택에 사용한 Test는 최종 독립 평가 자료로 취급하지 않습니다.
