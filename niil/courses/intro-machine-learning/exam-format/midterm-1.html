머신러닝의 이해

회귀 예측과 외삽

중간시험 · 예시 1

문제 상황

관측 입력 범위는 0–4이고 모델은 ŷ=2x+3\hat y=2x+3입니다. 기준값은 x=[0,2,4]에서 y=[3,8,11]입니다.

이해하고 적용할 내용

  • 모델의 계산값과 관측 오차를 구분하고 지표를 적용하기
  • 관측 범위 밖 예측의 불확실성을 판단하기

제공 참고자료

모델
ŷ=2x+3\hat y=2x+3, 관측 범위 0≤x≤4입니다.
MAE
MAE=1n∑i=1n|yi−ŷi|\mathrm{MAE}=\frac1n\sum_{i=1}^n|y_i-\hat y_i|. 오차의 단위는 y와 같습니다.
오차 부호
이 사례의 잔차는 y−ŷ로 정의합니다.
prediction=2*x+3

문항

  1. 세 예측과 잔차를 쓰고 MAE를 계산 과정과 함께 구하세요.
  2. x=8의 계산값을 쓰고, 이 값의 정확성을 현재 자료로 확정할 수 있는지 설명하세요.
  3. 두 번째 정답 y=8이 실제로 10이었다면 MAE와 잔차 평균을 다시 구하세요.
  4. 새 관측 x=3,y=9를 추가하면 이 한 점의 오차와 전체 네 점의 MAE가 어떻게 되는지 쓰세요.
답안 작성 예시
  1. 예측 [3,7,11], 잔차 [0,1,0]. MAE=0+1+03=13\mathrm{MAE}=\frac{0+1+0}3=\frac13입니다.
  2. 계산값은 19입니다. x=8은 관측 범위 밖 외삽이므로 계산 가능성과 실제 예측 정확성은 별도 판단입니다.
  3. 잔차 [0,3,0]으로 MAE=1, 잔차 평균도 1입니다. 우연히 같은 값이며, 양·음 오차가 섞이면 잔차 평균은 상쇄될 수 있습니다.
  4. 새 예측은 9로 오차 0입니다. 원래 자료에 더하면 전체 MAE=0+1+0+04=0.25\mathrm{MAE}=\frac{0+1+0+0}4=0.25입니다.
