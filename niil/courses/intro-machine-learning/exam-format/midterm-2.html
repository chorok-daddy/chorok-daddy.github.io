머신러닝의 이해

불균형 자료의 경보 평가

중간시험 · 예시 2

문제 상황

실제 이상 5개·정상 95개입니다. 모델 A는 항상 정상, B는 TP=4, FP=6, FN=1, TN=89입니다.

이해하고 적용할 내용

  • 불균형 자료에서 지표가 어떤 오류를 가리는지 판단하기
  • 미탐지와 오경보의 비용을 반영해 모델을 비교하기

제공 참고자료

지표
Accuracy=(TP+TN)/N, Recall=TP/(TP+FN), Precision=TP/(TP+FP).
오류
TP: 이상을 이상으로, TN: 정상을 정상으로, FN: 이상을 정상으로, FP: 정상을 이상으로 판단한 개수입니다.
비용
총비용=20×FN+FP. Precision 분모가 0이면 이 사례에서는 미정의로 기록합니다.
accuracy=(TP+TN)/100

문항

  1. 모델 A·B의 Accuracy와 Recall을 계산하고 분모가 무엇인지 설명하세요.
  2. B의 Precision과, 항상 정상인 A의 Precision을 어떻게 기록할지 쓰세요.
  3. 주어진 비용으로 두 모델을 비교하고 선택 근거를 쓰세요.
  4. 미탐지 비용이 1로 바뀌면 선택이 달라지는지 계산하세요. 무엇을 확인하고 지표를 골라야 하는지도 설명하세요.
답안 작성 예시
  1. A는 TP=0,FN=5,TN=95,FP=0으로 Accuracy=95/100=0.95, Recall=0/5=0입니다. B는 Accuracy=93/100=0.93, Recall=4/5=0.8입니다. Accuracy의 분모는 전체, Recall은 실제 이상입니다.
  2. B의 Precision=4/(4+6)=0.4. A는 이상으로 예측한 표본이 없어 분모가 0이므로 미정의로 기록합니다.
  3. A 비용=20×5=100, B 비용=20×1+6=26으로 B를 선택합니다. Accuracy만 높은 A는 이상을 모두 놓칩니다.
  4. FN 비용이 1이면 A=5, B=7로 A가 더 작습니다. 어느 오류가 얼마나 중요한지와 운영의 이상 비율을 확인해야 하며, 지표 하나가 모든 조건의 최선 모델을 정하지 않습니다.
