이번에 배울 내용

행과 열을 혼동하지 않고 표본별·특징별 집계를 계산하는 연습입니다.

배열 축에 의미 붙이기

행을 측정 시점, 열을 센서 채널로 정하면 axis=0 집계는 채널별 요약입니다. Shape가 맞는다고 의도한 계산인 것은 아닙니다. 원소별 곱과 행렬곱을 물리적 의미에 맞게 선택합니다.

시간과 잡음

차분을 속도로 해석하려면 측정 시간 간격으로 나눠야 합니다. 이동평균은 잡음을 줄이지만 급격한 변화를 뭉개고 경계에서 표본 수가 달라질 수 있습니다. Filter 전후를 같은 시간 구간에서 비교합니다.

풀이 예제

X=[246135024357]X=\begin{bmatrix}2&4&6\\1&3&5\\0&2&4\\3&5&7\end{bmatrix}이며 행은 표본, 열은 특징입니다. 

import numpy as np
import matplotlib.pyplot as plt
X=np.array([[2,4,6],[1,3,5],[0,2,4],[3,5,7]])
print(X.mean(axis=0),X.mean(axis=1))
