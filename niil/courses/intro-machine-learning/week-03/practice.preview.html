학습 목표

측정 표를 분석 가능한 배열로 바꾸고 누락·단위·그림을 함께 확인합니다. Python 문법은 이 작업에 필요한 부분만 복습합니다.

한 표본과 여러 표본

시작 조건

학생 3명의 (시간,점수)는 (2,55),(4,70),(6,85)입니다. 시간은 h입니다.

진행 방법

  1. 각 표본을 Dictionary로 만들고 List로 묶으세요.
  2. 시간만·점수만 선택한 List와 평균을 구하세요.

남길 결과

  • 3행 자료 표와 필드별 평균. 
records=[{'hours':2,'score':55},{'hours':4,'score':70},{'hours':6,'score':85}]
print([r['hours'] for r in records])

결측 표본

시작 조건

네 번째 표본은 hours=3, score=None입니다. 평균에서 결측 표본을 구분합니다.

진행 방법

  1. records에 {"hours":3,"score":None}을 추가해 records2를 만드세요. hours와 score를 필드별로 꺼내세요.
  2. 각 필드에서 None인 값만 제외하고 평균을 계산하세요. 필드명·원래 값 수·평균에 쓴 값 수·평균을 두 행으로 기록하세요.
  3. 추가 전후의 평균을 대조하고, 결측인 점수가 시간 값까지 제외해야 하는 이유가 되는지 설명하세요.

남길 결과

  • 자료 추가 전후의 필드별 값 수·평균 표. 
records2=records+[{'hours':3,'score':None}]

정리한 자료로 판단하기

시작 조건

새 장치의 기록 [(0,18),(1,19),(2,None)]을 같은 필드 이름으로 정리합니다.

진행 방법

  1. 새 기록의 각 쌍에서 첫 값을 앞 활동의 입력 필드, 둘째 값을 측정 필드에 대응시켜 Dictionary List로 만드세요. None은 그대로 보존하세요.
  2. 유효한 측정값의 개수·평균과 입력–측정값 산점도를 구하세요. 결측 처리 규칙 하나를 바꿔 같은 항목을 다시 구하세요. 예를 들어 결측 제외와 0 대체를 비교할 수 있습니다.
  3. 선택한 두 처리 규칙·유효값 수·평균을 기록하고, 원본에서 결측의 뜻을 알아야 하는 이유를 이 결과와 연결해 적으세요.
