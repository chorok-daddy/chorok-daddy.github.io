이번에 배울 내용

측정 표를 분석 가능한 배열로 바꾸고 누락·단위·그림을 함께 확인합니다. Python 문법은 이 작업에 필요한 부분만 복습합니다.

측정 한 건의 의미

장치 ID·측정 시각·값·단위가 있어야 센서 숫자를 해석할 수 있습니다. Dictionary는 필드의 이름을, List는 여러 측정을 담습니다. None은 실제 값 0과 다른 관측 실패 표시입니다.

처리 규칙을 함수로 고정하기

정상값·누락값·빈 자료를 각기 다른 곳에서 임시 처리하면 결과가 어긋납니다. 입력 검사와 요약 계산을 작은 함수로 묶고 경계 사례 두세 개로 확인합니다.

풀이 예제

학생 3명의 (시간,점수)는 (2,55),(4,70),(6,85)입니다. 시간은 h입니다. 

records=[{'hours':2,'score':55},{'hours':4,'score':70},{'hours':6,'score':85}]
print([r['hours'] for r in records])

[2, 4, 6]
