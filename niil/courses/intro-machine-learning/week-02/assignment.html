특징 표현과 모델 비교

같은 밝기의 그림도 구조는 다를 수 있습니다. 특징을 무엇으로 표현하느냐가 구분 가능성을 바꿉니다.

실습 전에

01 평균 밝기 하나로 방향을 구분할 수 있을까요?

설명

세로·가로 무늬의 평균 밝기가 같으면 구조를 나타내는 다른 특징이 필요합니다.

02 그림을 옆으로 옮겨도 같은 특징을 얻을까요?

설명

위치에 민감한 특징이라면 달라질 수 있습니다. Label을 유지한 이동으로 확인합니다.

실습

실습용 노트북 미리보기실습용 노트북 다운로드

1. 픽셀 표현과 단순 특징

시작 조건

8×8 영상 A는 중앙 두 열, B는 중앙 두 행만 1이고 나머지는 0입니다.

진행 방법

  1. 두 영상을 그린 뒤 전체 평균 픽셀값과 행·열 합을 구하세요.
  2. 평균 밝기만으로 두 영상을 구분할 수 있는지 확인하고 추가 특징을 하나 정하세요.

2. 위치가 바뀐 입력

시작 조건

A와 B를 오른쪽으로 1칸 옮긴 영상에서 같은 특징을 계산합니다.

진행 방법

  1. np.roll(A,1,axis=1)과 np.roll(B,1,axis=1)로 오른쪽으로 한 칸씩 옮기세요. 이번 예제에서는 오른쪽 끝 열이 왼쪽으로 돌아옵니다.
  2. 앞 활동에서 선택한 특징과 전체 평균·행 합·열 합을 옮긴 영상에서도 계산하세요. 영상별로 이동 전후 특징값을 나란히 기록하세요.
  3. 특징값이 유지되는 항목과 달라지는 항목을 구분하고, 선택한 특징으로 두 영상을 계속 구분할 수 있는지 설명하세요.

3. 다른 입력에서도 확인하기

시작 조건

A와 B 각각의 픽셀 하나를 반대로 바꾸어 선택한 특징의 강건성을 봅니다.

진행 방법

  1. A와 B에서 픽셀 하나씩을 선택해 0은 1로, 1은 0으로 바꾸세요. 바꾼 행·열 Index와 변경 전후 값을 적으세요.
