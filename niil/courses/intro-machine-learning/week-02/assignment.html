특징 표현과 모델 비교

같은 밝기의 그림도 구조는 다를 수 있습니다. 특징을 무엇으로 표현하느냐가 구분 가능성을 바꿉니다.

실습 전에

01 평균 밝기 하나로 방향을 구분할 수 있을까요?

설명

세로·가로 무늬의 평균 밝기가 같으면 구조를 나타내는 다른 특징이 필요합니다.

02 그림을 옆으로 옮겨도 같은 특징을 얻을까요?

설명

1. 픽셀 표현과 단순 특징

시작 조건

8×8 영상 A는 중앙 두 열, B는 중앙 두 행만 1이고 나머지는 0입니다.

진행 방법

  1. 두 영상을 그린 뒤 전체 평균 픽셀값과 행·열 합을 구하세요.
  2. 평균 밝기만으로 두 영상을 구분할 수 있는지 확인하고 추가 특징을 하나 정하세요.
  3. 표·그림에서 읽은 사실을 간단히 정리하세요.

2. 위치가 바뀐 입력

시작 조건

  1. 바뀐 입력·조건을 명시하고 첫 활동과 같은 절차를 적용하세요.

  3. 차이가 생긴 이유와 아직 확실하지 않은 점을 각각 한 문장으로 적으세요.
