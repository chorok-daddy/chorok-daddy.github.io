이번에 배울 내용

같은 밝기의 그림도 구조는 다를 수 있습니다. 특징을 무엇으로 표현하느냐가 구분 가능성을 바꿉니다.

전체 흐름

표본·특징 → 정리·자료 분리 → 기준 모델 → 새 자료의 오류

평균 밝기가 같아도 다른 영상

세로 막대와 가로 막대는 밝기의 평균이 같아도 방향이 다릅니다. 구분에 필요한 정보를 보존하는 특징이 있어야 모델이 차이를 이용할 수 있습니다.

위치 변화에 견디는 표현

영상을 한 칸 옮겨도 정답 방향은 같습니다. 위치에 민감한 특징이라면 값이 크게 달라질 수 있습니다. 작은 변형으로 표현이 유지하는 정보와 버리는 정보를 확인합니다.

풀이 예제

8×8 영상 A는 중앙 두 열, B는 중앙 두 행만 1이고 나머지는 0입니다. 

import numpy as np
import matplotlib.pyplot as plt
A=np.zeros((8,8));B=A.copy();A[:,3:5]=1;B[3:5,:]=1
print(A.mean(),B.mean(),A.sum(axis=0),B.sum(axis=0))
import matplotlib.pyplot as plt
fig,axes=plt.subplots(1,2,figsize=(6,3))
axes[0].imshow(A,cmap="gray",vmin=0,vmax=1);axes[0].set_title("A")
axes[1].imshow(B,cmap="gray",vmin=0,vmax=1);axes[1].set_title("B")
