측정 데이터로 시작하는 Machine Learning

온도 측정 기록에서 경보를 만들고, 센서 보정식의 예측 오차를 비교합니다.

실습 전에

01 온도가 높다는 판단과 온도를 예측하는 일은 어떻게 다를까요?

설명

기준을 정해 경보를 내는 것은 규칙에 따른 판단입니다. 보정식으로 기준 온도를 추정하는 것은 수치 예측입니다. Machine Learning에서는 이 예측식의 계수를 데이터로 찾게 됩니다.

02 코드가 실행되면 측정값도 올바른가요?

설명

결측값·측정 범위를 벗어난 값·단위가 다른 값도 코드에 들어갈 수 있습니다. 입력을 확인한 뒤 예측과 판단을 해석해야 합니다.

실습

실습용 노트북 미리보기실습용 노트북 다운로드

1. 측정값과 Alarm Label 비교

시작 조건

시각 [0,5,10,15,20,25] min, 온도 [24,25,29,23,30,26] °C입니다. 경보는 온도가 기준을 초과할 때 켭니다.

진행 방법

  1. 학습 예제를 실행해 경보가 발생한 시각과 온도를 대조하세요.
  2. 기준을 28°C에서 26°C로 바꾸고 경보가 추가된 시각을 찾으세요.
  3. 같은 그래프에 기준선과 경보 지점을 표시하고 기준을 바꾼 영향을 설명하세요.

2. 보정식이 오차를 줄이는지 확인하기

시작 조건

센서 입력 x=[20222426]x=\begin{bmatrix}20&22&24&26\end{bmatrix} °C, 기준 온도 y=[22.524.726.829.1]y=\begin{bmatrix}22.5&24.7&26.8&29.1\end{bmatrix} °C입니다. 보정식은 y_hat=1.1*x+0.5입니다.

진행 방법

  1. 입력 그대로의 예측과 보정식의 예측을 각각 계산하세요.
  2. 각 예측과 기준값의 차이, 절댓값 오차의 평균을 구하세요.
  3. 새 입력 28°C, 기준 온도 31.4°C에서도 두 방법의 오차를 비교하세요.

3. 잘못된 측정값을 구분하고 기록하기

시작 조건

같은 시각의 기록 [24,None,29,100,26,28] °C를 사용합니다. 센서의 유효 온도 범위는 15–40°C이며 None은 측정 실패입니다.

진행 방법

  1. 측정 실패와 범위 밖의 값을 구분해 원래 시각과 함께 기록하세요.
  2. 유효한 값으로 평균과 28°C 초과 경보를 계산하세요. ≥ 조건으로 바꾼 경우와 비교하세요.
  3. 그래프에서 빠진 시각을 없애지 말고 측정이 없다는 사실이 드러나게 표시하세요.
