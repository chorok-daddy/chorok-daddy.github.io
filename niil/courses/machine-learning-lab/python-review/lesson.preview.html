이번에 배울 내용

같은 자료 정리를 여러 분석에 재사용할 수 있도록, 누락 처리와 배열 변환을 작은 함수로 묶습니다.

전체 흐름

결측 행 선택 → NumPy 배열과 함수 → 통계 계산 → 원본 행과 그림의 대응

배열로 바꾸기 전에

표본 수·특징 수·누락 규칙을 정합니다. 같은 측정에 서로 다른 정리 규칙을 적용하지 않도록 자료 처리 함수를 재사용합니다.

요약과 그림의 역할

평균 하나는 분포·이상값을 가릴 수 있습니다. 숫자 요약 옆에 같은 자료의 그림을 두고, 누락 제거로 표본이 어떻게 달라졌는지 함께 확인합니다.

풀이 예제

3특징 자료 rows=[[1,2,3],[2,None,4],[3,4,5],[4,5,6]]입니다. None이 있는 행은 별도 목록으로 둡니다. 

import numpy as np
import matplotlib.pyplot as plt
rows=[[1,2,3],[2,None,4],[3,4,5],[4,5,6]]
complete=[row for row in rows if None not in row]
X=np.asarray(complete,dtype=float)
print(X.shape,X.mean(axis=0))

(3, 3) [2.66666667 3.66666667 4.66666667]
