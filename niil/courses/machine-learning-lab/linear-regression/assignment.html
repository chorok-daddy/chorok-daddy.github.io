1. Bias가 있는 센서 보정

시작 조건

제공 코드는 x=0,.5,...,3.5에서 y=1.8x+.7에 작은 노이즈를 더한 합성 자료를 만듭니다. seed=7입니다.

진행 방법

  1. 제공한 200 epoch 기준 예제를 실행하고 Loss 곡선과 예측 직선을 그리세요.
  2. 학습된 w·b와 데이터 생성 계수를 나누어 표에 적으세요.
  3. 노이즈가 있으므로 학습 계수가 생성 계수와 완전히 같아야 하는지 설명하세요.

2. 같은 모델의 학습률 비교

시작 조건

bias=True와 epoch=200을 고정하고 lr=.01,.05,.1을 비교합니다.

진행 방법

  1. 모든 실행의 초기 seed와 데이터는 고정하세요.
  2. 마지막 MSE와 1·20·200 epoch의 Loss를 기록하세요.
  3. 가장 작은 마지막 Loss와 가장 빠른 초기 감소를 구분하세요.

3. Bias를 빼면 남는 오차

시작 조건

같은 자료에서 lr=.05, epoch=200을 유지하고 bias=True/False를 비교합니다.

진행 방법

  1. 두 예측 직선을 같은 그림에 표시하세요.
