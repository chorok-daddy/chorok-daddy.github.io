Multiclass Classification

클래스별 점수·확률·정답 Label의 관계를 알아야 다중 분류의 오류와 잘못된 Label을 해석할 수 있습니다.

실습 전에

01 각 클래스의 확률을 독립적으로 해석해도 될까요?

설명

Softmax는 Class Score를 합이 1인 Probability로 변환하므로 한 점수의 변화가 다른 확률에도 영향을 줍니다.

02 잘못된 Label 하나가 학습과 평가에 어떤 차이를 만들까요?

설명

학습은 변경 Label을 따르지만 원래 Label 기준 평가에서는 오류가 늘 수 있습니다.

실습

실습용 노트북 미리보기실습용 노트북 다운로드

1. Multiclass Logits와 Prediction 비교

시작 조건

제공된 중심 (-2,0),(2,0),(0,2) 주변에서 Class별 6표본, 총 18개를 만듭니다. seed=7입니다.

진행 방법

  1. Linear(2,3)와 CrossEntropy의 입력·Label shape를 확인하세요.
  2. 첫 6개 표본의 Logit 3개·확률 3개·예측을 기록하세요.
  3. 자료 산점도와 Loss 곡선을 그리세요.

2. Class별 결과와 모호한 입력

시작 조건

query=[(-2,0),(2,0),(0,2),(0,0)]을 학습 모델에 입력합니다.

진행 방법

  1. 18개 Training 표본의 3×3 Confusion Matrix를 작성하세요.
  2. query 4개의 확률·예측을 표에 적으세요.
  3. 중심 표본과 (0,0)의 확률 분포를 비교하세요.

3. Label 하나가 바뀐 자료

시작 조건

표본 0의 Label만 0에서 1로 바꾸고 같은 조건으로 다시 학습합니다.

진행 방법

  1. 변경한 Label과 위치를 먼저 표시하세요.
  2. 기준·변경 모델의 Loss, 원래 Label 기준 오류, 변경 Label 기준 오류를 비교하세요.
  3. 학습의 어려움을 반복 횟수 문제와 자료 문제로 나누어 설명하세요.
