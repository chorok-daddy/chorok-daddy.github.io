Logistic Regression

확률을 계산하는 모델과 최종 경보를 내리는 기준을 구분해야, 놓침과 오경보의 비용을 조절할 수 있습니다.

실습 전에

01 Logit과 확률은 같은 값일까요?

설명

Sigmoid를 거친 확률과 그 이전의 실수 점수는 범위와 Loss 입력이 다릅니다.

02 Threshold 조절과 재학습은 같은 작업일까요?

설명

Threshold는 같은 확률의 판정을 바꾸고, 재학습은 확률을 만드는 Parameter를 바꿉니다.

실습

실습용 노트북 미리보기실습용 노트북 다운로드

1. Logit·확률

시작 조건

입력은 제공한 12×2 합성 특징이며, 두 특징 합이 1을 넘는 표본이 Class 1입니다.

진행 방법

  1. BCEWithLogitsLoss에 들어가는 값과 Sigmoid를 적용한 값을 구분해 실행하세요.
  2. 각 표본의 두 특징·정답·Logit·확률·.5 판정을 표에 적으세요.
  3. Loss 곡선과 2차원 자료의 Class를 표시하세요.

2. Threshold와 오류의 종류

시작 조건

같은 학습 모델의 확률에 Threshold=.35,.5,.65를 적용합니다.

진행 방법

  1. TP·FP·FN·TN을 각각 구하세요.
  2. Accuracy와 Precision·Recall을 계산하고 분모가 0인 경우 표시 규칙을 정하세요.
  3. 센서 경보에서 미탐지를 줄이고 싶은 상황에 어떤 Threshold를 선택할지 근거를 적으세요.

3. 오류 비용이 달라진 경우

시작 조건

Class 1 표본의 학습 Loss에 가중치 3을 주고 기준 모델과 비교합니다. 입력·초기 seed·epoch는 같습니다.

진행 방법

  1. weights를 Class 1은 3, Class 0은 1로 정하세요.
  2. 가중 모델의 .5 판정과 기준 모델의 .35 판정을 비교하세요.
  3. 학습 Loss의 가중과 판정 Threshold 변경이 서로 다른 조작임을 설명하세요.
