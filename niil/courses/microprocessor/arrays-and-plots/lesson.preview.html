이번에 배울 내용

배열 축이나 시간 간격을 잘못 해석하면 계산이 실행돼도 물리적 의미가 틀릴 수 있습니다.

전체 흐름

센서·요청 → 형식·단위 검사 → 저장·상태 변경 → 조회·응답 확인

배열 축에 의미 붙이기

행을 측정 시점, 열을 센서 채널로 정하면 axis=0 집계는 채널별 요약입니다. Shape가 맞는다고 의도한 계산인 것은 아닙니다. 원소별 곱과 행렬곱을 물리적 의미에 맞게 선택합니다.

시간과 잡음

차분을 속도로 해석하려면 측정 시간 간격으로 나눠야 합니다. 이동평균은 잡음을 줄이지만 급격한 변화를 뭉개고 경계에서 표본 수가 달라질 수 있습니다. Filter 전후를 같은 시간 구간에서 비교합니다.

풀이 예제

A=[123456]A=\begin{bmatrix}1&2&3\\4&5&6\end{bmatrix}, B=[201301]B=\begin{bmatrix}2&0\\1&3\\0&1\end{bmatrix}입니다. 

import numpy as np
A=np.array([[1,2,3],[4,5,6]])
B=np.array([[2,0],[1,3],[0,1]])
print(A@B)

[[ 4  9]
 [13 21]]
