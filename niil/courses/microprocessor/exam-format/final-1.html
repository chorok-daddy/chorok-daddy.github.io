시험 형식과 답안 작성 예시

측정 중복과 조회 결과 · 기말시험 · 예시 1

이 자료는 시험 형식과 답안 작성 수준을 보여주는 예시이며, 예상문제가 아닙니다. 시험 준비는 공지된 출제 범위를 기준으로 하세요.

문제 상황

Key는 (device,time)이며 중복 Key는 최신 값으로 갱신합니다. 순서대로 (a,0,10),(a,1,12),(a,1,13),(b,1,20)을 저장합니다.

이해하고 적용할 내용

  • 복합 Key와 갱신 정책을 읽고 저장 상태를 추적하기
  • 조회 조건의 경계와 여러 장치의 독립성을 구분하기

제공 참고자료

저장 규약
Key=(device,time). 같은 Key로 저장하면 이전 값을 덮어씁니다. 다른 Key는 별도 행입니다.
조회 규약
query(device,start,end)는 해당 장치의 start≤time≤end\mathrm{start}\le\mathrm{time}\le\mathrm{end} 행을 시간 오름차순으로 반환합니다. start/end 단위는 s입니다.
출력 규약
조회 결과는 (time,value) 목록이며 없으면 []입니다.
query(device="a", start=0, end=1)

문항

  1. 순차 저장 후 전체 행 수와 query(a,0,1)의 결과를 쓰세요.
  2. 이어 (b,1,21)을 저장하면 전체 행 수와 b의 조회 결과가 어떻게 바뀌는지 쓰세요.
  3. query(a,1,1)의 결과를 쓰고 양끝 포함 규약을 설명하세요.
  4. time만 Key로 두었을 때 최초 네 저장 작업의 최종 상태를 쓰고, 잃는 정보를 설명하세요.
답안 작성 예시
  1. 중복 (a,1)은 13으로 갱신되어 총 3행입니다. a의 조회는 [(0,10),(1,13)]입니다.
  2. 행 수는 3으로 같고 b의 time=1 값만 21로 바뀝니다. query(b,0,1)=[(1,21)]입니다.
  3. [(1,13)]입니다. start와 end가 같아도 경계를 포함하므로 해당 시각의 행이 조회됩니다.
  4. 시간 Key 0은 (a,0,10), 1은 마지막 기록 (b,1,20)으로 남아 총 2행입니다. 장치 a의 time=1 값이 b의 값에 덮여 장치별 기록을 분리할 수 없습니다.
