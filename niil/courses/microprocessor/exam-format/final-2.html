잘못된 API 요청 구분

기말시험 · 예시 2

문항 예시

device는 필수 문자열이고 start는 정수인 FastAPI 경로입니다. 정상 형식이지만 없는 장치는 빈 목록을 반환한다고 정했습니다.

/readings?device=a&start=abc
/readings?device=missing&start=0
  1. 첫 요청과 둘째 요청의 상태·결과를 구분하세요.
  2. 없는 URL 경로에 대한 응답과도 구분하세요.
답안 작성 예시
  1. 첫 요청은 정수 검증 오류 422. 둘째는 정상 요청 200과 빈 목록.
  2. 등록되지 않은 URL 경로는 404입니다.
