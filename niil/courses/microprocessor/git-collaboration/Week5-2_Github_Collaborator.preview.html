1. 내 Repository에 Collaborator 추가하기

  • Repository - Settings - Manage access - Invite a collaborator
  • 초대 받은 사람이 수락하면 Collaborator가 된다
  • 아래부터는 ‘초대받은 사람’ 기준으로 설명한다

6. Branch 만들기

  • !git checkout [브랜치명] : 해당 브랜치로 시점을 옮긴다
  • -b 옵션 : 브랜치를 새로 만든 후 그 브랜치로 이동
!git checkout -b branch01
Switched to a new branch 'branch01'

!git status

nothing to commit, working tree clean

!git branch
