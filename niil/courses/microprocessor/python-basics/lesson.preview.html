이번에 배울 내용

센서 기록에는 누락과 경계값이 섞입니다. 정상 자료와 예외 자료를 같은 함수로 처리해 봅니다.

전체 흐름

센서·요청 → 형식·단위 검사 → 저장·상태 변경 → 조회·응답 확인

측정 한 건의 의미

장치 ID·측정 시각·값·단위가 있어야 센서 숫자를 해석할 수 있습니다. Dictionary는 필드의 이름을, List는 여러 측정을 담습니다. None은 실제 값 0과 다른 관측 실패 표시입니다.

처리 규칙을 함수로 고정하기

정상값·누락값·빈 자료를 각기 다른 곳에서 임시 처리하면 결과가 어긋납니다. 입력 검사와 요약 계산을 작은 함수로 묶고 경계 사례 두세 개로 확인합니다.

풀이 예제

기록은 [(0,21.0),(1,21.5),(2,None),(3,22.0),(4,20.5)]이며, 각 쌍은 시간[s]·온도[°C]입니다. 

records=[(0,21.),(1,21.5),(2,None),(3,22.),(4,20.5)]
valid=[value for _,value in records if value is not None]
print('valid count',len(valid),'mean',sum(valid)/len(valid))

valid count 4 mean 21.25
