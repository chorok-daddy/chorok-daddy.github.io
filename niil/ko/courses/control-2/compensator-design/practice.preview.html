실행 준비

Python 경로는 python-control을 사용합니다. 모듈이 없으면 Colab·Jupyter의 코드 셀에서 %pip install control==0.10.2를 실행하세요.

학습 목표

빠르기·감쇠·Steady-State Error를 함께 맞춰야 할 때 Lead와 Lag 중 무엇을 조정할지 판단합니다.

기준 Plant와 Lead 설계점

시작 조건

G(s)=40s(s+2)G(s)=\frac{40}{s(s+2)}. 목표는 ζ=.4\zeta=.4, ωn=10\omega_n=10 rad/s입니다.

진행 방법

  1. 목표 복소 Pole의 실수부·허수부를 계산하고 Root Locus 위에 표시하세요.
  2. Lead 보상기의 Zero·Pole을 정하고, 목표점의 각도 조건과 크기 조건으로 Gain을 계산해 보상기 식을 적으세요.
  3. 선택한 지점과 실제 Closed-loop Pole의 거리를 계산하세요.

남길 결과

import numpy as np
import matplotlib.pyplot as plt
import control as ctl
s = ctl.tf('s')
G=40/(s*(s+2));zeta=.4;wn=10.
p_desired=-zeta*wn+1j*wn*np.sqrt(1-zeta*zeta)
print('desired pole',p_desired)
