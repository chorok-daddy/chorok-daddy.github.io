02 학습과 가정

기울기를 계속 조절하면 어떤 데이터든 오차 없이 설명할 수 있을까요?

설명
  • 원점을 지나는 직선만 허용하면, 원점을 지나지 않는 관계나 곡선 형태의 데이터를 정확하게 표현하기 어렵습니다.
  • Loss와 Gradient로 선택한 모델 안에서 오차를 줄입니다. 반복 횟수를 늘리는 것과 모델의 가정을 바꾸는 것은 다릅니다.

실습

1. 원점을 지나는 회귀 문제

A의 각 행은 입력값과 상수 1로 구성됩니다.

  1. 데이터 셀에서 A와 A_prime을 나란히 출력하고, 어느 열이 선택되었는지 표시하세요.
  2. 식 ŷ=wx\hat y=wx와 ŷ=wx+b\hat y=wx+b에서 상수 열의 역할을 설명하세요. 이번 모델의 bias=False에 해당하는 식을 고르세요.
  3. 입력 x=0x=0인 표본의 Target과 모델이 낼 수 있는 값을 비교해, 학습으로 없앨 수 없는 오차가 있는지 적으세요.

2. 학습과 기록

  1. train_linear를 Learning Rate η∈{0.001,0.01,0.1}\eta\in\{0.001,0.01,0.1\}, 각각 1000 epoch로 호출하세요. 함수 안의 동일한 Seed와 모델 초기화를 유지하세요.
  2. 세 Loss 곡선을 한 그래프에 그리고, Learning Rate별 마지막 Weight·MSE를 표로 기록하세요. Loss가 줄어드는 속도를 곡선과 연결해 설명하세요.
  3. train_linear의 loss.backward() 바로 다음 줄에 첫 epoch에서만 model.weight.grad를 출력하는 코드를 추가하세요. Gradient의 부호와 Weight 갱신 방향을 연결하고, 다음 epoch 전에 zero_grad()가 필요한 이유를 설명하세요.

3. 직접 해와 대조

  1. A_prime.T @ A_prime의 값과 Determinant를 출력하고 Inverse가 존재하는지 판단하세요.
  2. torch.linalg.inv(A_prime.T @ A_prime) @ A_prime.T @ B_prime, torch.linalg.pinv(A_prime) @ B_prime, Learning Rate 0.01·1000 epoch로 학습한 Weight를 세 행의 표에 적으세요. 직접 계산한 해와 학습 결과의 절대 차이도 적으세요.
  3. x∈{0,1,2,3}x\in\{0,1,2,3\}에 대해 입력·Target·예측값·예측값−Target을 한 표로 기록하세요.
