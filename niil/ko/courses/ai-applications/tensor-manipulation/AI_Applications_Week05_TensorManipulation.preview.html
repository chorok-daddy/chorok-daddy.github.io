1. Tensor 만들기

축과 dtype을 출력하고 예측과 비교합니다.

A. 기준 예제 · 먼저 읽고 실행

import sys, numpy as np, matplotlib.pyplot as plt
import torch
from torch import nn
import torch.nn.functional as F
torch.manual_seed(42)
torch.set_num_threads(2)
print('Python:', sys.version.split()[0], '| PyTorch:', torch.__version__)
x=torch.arange(12,dtype=torch.float32).reshape(4,3)
print(x,'\nshape:',x.shape,'dtype:',x.dtype)
print('features mean:',x.mean(dim=0));print('samples mean:',x.mean(dim=1))

B. 직접 수행

  1. 0~5의 1D Tensor, 0~11의 (4,3) Tensor, 0~23의 (2,3,4) Tensor를 float로 생성하세요.
  2. (4,3)을 표본 4개·특징 3개로 보고 특징별 평균과 표본별 평균의 예상 shape를 적은 뒤 dim=0·1로 검증하세요.

2. cat·stack·reshape

같은 입력에 다른 결합 방법을 적용합니다.

A. 기준 예제 · 먼저 읽고 실행

a=torch.arange(6).reshape(2,3);b=a+10
print('cat0:',torch.cat([a,b],0).shape)
print('cat1:',torch.cat([a,b],1).shape)
print('stack:',torch.stack([a,b],0).shape)
print('reshape:',x.reshape(2,2,3).shape)
print('unsqueeze:',x.unsqueeze(0).shape)
print('restore:',x.unsqueeze(0).squeeze(0).shape)

B. 직접 수행

  1. 연결 예제의 a,b를 사용해 torch.cat([a,b],dim=0)과 dim=1을 각각 실행하세요. torch.stack([a,b],dim=0)과 dim=1도 실행하세요.

3. 축과 연산 오류 찾기

A의 열 수와 B의 행 수가 같아야 A@B를 계산할 수 있습니다. 먼저 두 배열의 shape를 출력해 곱셈이 가능한지 확인합니다.

A. 기준 예제 · 먼저 읽고 실행

A=torch.arange(6,dtype=torch.float32).reshape(2,3)
B=torch.arange(12,dtype=torch.float32).reshape(3,4)
print((A@B).shape)
print((A+torch.tensor([10,20,30])).shape)
assert (A@B).shape==(2,4)

B. 직접 수행

  1. A.shape=(2,3), B.shape=(3,4)인 기준 예에서 A*B와 A@B 중 실행 가능한 연산과 그 이유를 쓰세요.
  2. A+torch.tensor([10,20])가 실패하는 이유를 설명하고, 행별로 10과 20을 더하도록 Tensor shape를 수정하세요.
