1. State Equation 유도

아래 계산을 먼저 수행한 뒤 MATLAB 결과와 비교하세요.
  • R, L, C가 같은 두 Node 사이에 병렬로 연결된 회로입니다. 아래 Node를 기준 전위로 두고, 위 Node의 전압을 v, 위에서 아래로 흐르는 인덕터 전류를 , 공급 전류를 u로 정하세요.
  • 에서 KCL과 를 이용해 의 두 Differential Equation과 출력 를 직접 쓰고 를 구하세요.
  • Initial Condition을 0으로 놓고 두 식을 Laplace Transform하세요. Inductor 관계식에서 를 로 나타낸 뒤 KCL 식에 대입하세요. 가 포함된 항을 모아 를 구하세요.
  • 일정 전류 1 A를 충분히 오래 공급하면 v와 이 각각 얼마가 되는지 먼저 적으세요.
  • 직접 구한 행렬로 ss 모델을 만들고 tf·dcgain으로 검증하세요.
  • 이 병렬 회로는 아래 RL 직렬 가지 회로와 구성이 다릅니다.
  • 이번에는 RL 회로의 R 반복 세 값 중 한 값을 이 비교로 대신하세요.

2. Mechanical State Space

기준 모델을 함수 없이 매번 새로 만듭니다.
실행 전 예상: ⟦직접 입력⟧
M=1;b=2;k=5;
A=[0 1;-k/M -b/M];B=[0;1/M];Cout=[1 0];D=0;
sys=ss(A,B,Cout,D);disp(size(A));disp(tf(sys));
figure;step(sys,10);grid on;
assert(abs(dcgain(sys)-1/k)<1e-10);
직접 수행:
  1. 기계 모델의 , 는 유지하고 에서 A와 sys를 다시 만드세요. Position의 Step Response 세 개를 같은 시간축에 그리고 범례에 b를 적으세요.
  2. 각 곡선의 진동 유무와 수렴하는 양상을 대조하세요. 어떤 b의 곡선을 근거로 판단했는지 적으세요.
  3. 같은 State 순서에서 출력만 Linear Velocity로 선택하세요. 사용한 Cout과 dcgain(sys)를 Position 출력일 때의 값과 나란히 기록하세요.

3. Electrical State Space

전류원 입력, 커패시터 병렬의 RL 가지, 저항 전압 Output입니다.
실행 전 예상: ⟦직접 입력⟧
R=3;L=1;Ccap=.5;
A=[0 -1/Ccap;1/L -R/L];B=[1/Ccap;0];Cout=[0 R];D=0;
sys=ss(A,B,Cout,D);
figure;step(sys,15);grid on;
assert(abs(dcgain(sys)-R)<1e-10);
직접 수행:
이 회로의 State는 입니다. 는 커패시터 전압 [V], 은 RL 직렬 가지의 전류 [A]입니다.
  1. 기준 회로의 다른 계수는 유지하고 에서 A, Cout, sys를 다시 만드세요.
  2. 입력 1 A에 대한 최종 출력 전압을 dcgain(sys)로 구하고, R과 전압을 두 열로 기록하세요.
  3. Ccap은 Capacitance, Cout은 출력 행렬임을 적으세요. State의 순서와 Cout을 사용해 출력식 를 쓰고, 원하는 저항 전압을 나타내는지 판단하세요.

4. State 좌표와 초기값

위치와 속도에 초기값을 주면 입력 없이도 응답합니다.
실행 전 예상: ⟦직접 입력⟧
sys=ss([0 1;-5 -2],[0;1],[1 0],0);
figure;initial(sys,[1;0],0:.01:10);grid on;
직접 수행:
  1. 기준 모델과 같은 시간축에서 initial(sys,[0;1],0:0.01:10)와 initial(sys,[1;0],0:0.01:10)를 그리세요. 두 곡선의 범례에 Initial State를 적으세요.
  2. 어느 State가 0이 아닌 값에서 시작하는지와 외부 입력 유무를 적으세요. Initial State가 0인 Step Response와 Initial State에 의한 출력을 구별해 설명하세요.
