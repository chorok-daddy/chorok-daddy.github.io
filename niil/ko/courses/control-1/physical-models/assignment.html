실습 전에

01 이미 배운 운동 모델

등속·등가속 운동 식으로 위치를 계산할 때, 무엇이 변하지 않는다고 두었나요?

설명
  • 등속에서는 속도를, 등가속에서는 가속도를 일정하게 둡니다. 변화에 제한을 두었기 때문에 위치를 간단한 식으로 계산할 수 있습니다.
  • 스프링이나 마찰 때문에 힘이 달라진다면 그 관계를 모델에 포함해야 합니다. 이번 실습은 그 힘들이 움직임에 미치는 영향을 비교합니다.

관련 개념 복습 ↗

02 모델과 실제 특성

물체를 더 무겁게 하거나 스프링을 바꾸면, 모델의 무엇을 바꿔야 할까요?

설명
  • 질량이나 스프링의 강성을 나타내는 Parameter를 바꿉니다. 식에 들어가는 숫자는 실제 장치의 특성과 연결됩니다.
  • 한 번에 한 특성을 바꿔 응답을 비교하면, 움직임이 달라지는 이유를 구분하기 쉽습니다.

실습

1. 물리 모델 유도

입력 u(t)u(t)는 외력 [N], 출력 y(t)y(t)는 질량의 변위 [m]입니다.

  • 기계 모델의 M=1,b=2,k=5M=1,\ b=2,\ k=5를 사용하세요.
  • 코드 실행 전에 힘의 방향을 표시하고 Newton 법칙으로 Differential Equation을 세우세요.
  • Initial Condition을 0으로 놓고 Laplace Transform하여 Y(s)U(s)\frac{Y(s)}{U(s)}를 구한 뒤, 일정한 힘 1 N이 작용할 때의 최종 변위를 계산하세요.
  • MATLAB의 Transfer Function과 최종 응답을 자신의 식과 대조하세요.
  • 기계 모델 비교 세 경우 중 기준 경우의 예측란에 이 계산을 기록하면 됩니다.

모델의 한 파라미터를 바꾸고, 응답의 변화가 물리적으로 무엇을 뜻하는지 설명합니다.

2. 병렬 RLC 회로

기준값은 R=0.5R=0.5 Ω, L=1L=1 H, C=5C=5 F입니다. 입력은 전류 [A], 출력은 전압 [V]입니다.

  1. 기준 모델의 Unit Step을 실행한 뒤, parameter를 "R", "L", "C"로 하나씩 지정하세요. 각 Parameter에서 factor=2와 factor=0.5로 실습용 Live Script의 ‘R, L, C를 한 가지씩 바꾸기’ 코드을 각각 다시 실행하세요. 선택하지 않은 두 Parameter는 기준값을 유지합니다.
  2. 각 실행의 기준·변경 곡선에서 Peak 전압, 진동 유무와 수렴하는 양상을 대조하세요. 바꾼 Parameter·변경 전후 값·관찰한 차이를 관찰표의 해당 행에 기록하세요.
  3. Parameter별로 관찰한 변화 한 가지를 회로의 저항·인덕턴스·커패시턴스 역할과 연결해 설명하세요. 그림에는 조건을 구분하는 범례와 시간·전압 단위를 표시하세요.
