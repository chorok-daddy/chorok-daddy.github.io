2. 변환 전후의 응답

Initial Condition이 모두 0일 때의 Input–Output 비교입니다.
실행 전 예상: ⟦직접 입력⟧
A=[0 1;-2 -3];B=[0;1];C=[1 0];D=0;sys=ss(A,B,C,D);G=tf(sys);
t=(0:.01:10)';y1=step(sys,t);y2=step(G,t);
disp(size(A));disp(G);disp(max(abs(y1-y2)));assert(max(abs(y1-y2))<1e-8);
직접 수행:
  1. 첫 코드 Section의 A,B,D는 유지하고 C=[0 1]로 바꾼 뒤 sys와 G=tf(sys)를 다시 만드세요.
  2. 같은 시간축에서 step(sys,t)와 step(G,t)를 계산하고, 두 출력의 최대 절대 차이를 기록하세요. 최대 절대 차이가 보다 작은지 판정하세요.
  3. 변경 전후의 출력식 와 DC Gain을 나란히 적고, 선택한 State가 달라져 출력과 DC Gain이 바뀌는 이유를 설명하세요.

3. State 좌표 스케일 변경

x=Pz 관계를 먼저 적습니다.
실행 전 예상: ⟦직접 입력⟧
A=[0 1;-2 -3];B=[0;1];C=[1 0];P=diag([2 .5]);
Az=P\(A*P);Bz=P\B;Cz=C*P;
sys=ss(A,B,C,0);transformed=ss(Az,Bz,Cz,0);
t=(0:.01:10)';err=max(abs(step(sys,t)-step(transformed,t)));disp(err);assert(err<1e-8);
직접 수행:
  1. P=diag([3 2])로 바꾸고, Az=P\(A*P), Bz=P\B, Cz=C*P로 Az,Bz,Cz를 다시 계산해 행렬을 기록하세요.
  2. 같은 시간축에서 원래 모델과 변환한 모델의 Step Response를 구하고, 두 출력의 최대 절대 차이를 기록하세요. 최대 절대 차이가 보다 작은지 판정하세요.
  3. 행렬의 원소는 달라져도 출력이 같은 이유를 와 출력식의 관계로 설명하세요.

4. 초기값 변환 오류 수정

앞 Section에서 만든 모델을 사용합니다.
실행 전 예상: ⟦직접 입력⟧
x0=[1;1];z0=P\x0;
yx=initial(sys,x0,t);yz=initial(transformed,z0,t);wrong=initial(transformed,x0,t);
disp([max(abs(yx-yz)),max(abs(yx-wrong))]);assert(max(abs(yx-yz))<1e-8);
figure;plot(t,[yx,yz,wrong]);legend('original','correct transformed','wrong initial state');grid on;
직접 수행:
  1. Initial State를 , , 로 각각 지정하세요. 나머지 모델·좌표변환 행렬 P·시간축은 해당 Section의 값을 유지합니다.

  3. Initial State별로 올바르게 변환한 출력과 원래 출력의 최대 절대 차이, 초기값을 그대로 사용한 출력과 원래 출력의 최대 절대 차이를 두 열로 기록하세요. 두 경우가 다른 이유를 와 연결해 설명하세요.
