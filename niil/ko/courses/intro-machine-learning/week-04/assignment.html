제어문과 함수

경계값 하나에서 판단이 달라집니다. 조건문을 함수로 만들고 정상·경계 입력을 대조합니다.

실습 전에

01 Threshold와 정확히 같은 값은 어디에 속할까요?

설명

비교 연산의 등호 유무로 경계의 판정이 달라집니다.

02 같은 판단을 여러 입력에 적용하려면 무엇을 함수로 묶을까요?

설명

입력과 판단 규칙을 함수로 묶고, Threshold는 인자로 분리합니다.

실습

실습용 노트북 미리보기실습용 노트북 다운로드

1. 조건과 반복

시작 조건

점수=[45,60,75,90]이고 합격 기준은 60 이상입니다.

진행 방법

  1. 각 점수에 대한 합격 여부를 for와 if로 계산하세요.
  2. 동일 처리를 pass_flags(scores,threshold) 함수로 만들고 두 결과를 비교하세요.

2. 기준값 변화

시작 조건

threshold=50,60,80에서 합격자 수와 경계 표본을 비교합니다.

진행 방법

  1. pass_flags를 Threshold 50,60,8050,60,80으로 각각 호출하세요. 점수 네 개는 바꾸지 않습니다.
  2. Threshold별 합격 여부 네 개와 합격자 수를 표로 적으세요. Threshold와 점수가 같은 표본에서 사용하는 비교 연산자가 >=인지 확인하세요.
  3. Threshold가 바뀌어 판정이 달라진 점수를 지목하고, 바뀐 이유를 설명하세요.

3. 다른 입력에서도 확인하기

시작 조건

점수 [59,60,61]과 빈 List로 함수의 경계값을 확인합니다.

진행 방법

  1. Threshold 60을 유지하고 점수 [59,60,61]과 빈 List에 대한 함수 반환값을 실행 전에 적으세요.
  2. 두 입력에 pass_flags를 호출하고 예상·실제 반환값을 나란히 기록하세요. 점수 60의 판정과 빈 입력의 반환 형태를 설명하세요.
