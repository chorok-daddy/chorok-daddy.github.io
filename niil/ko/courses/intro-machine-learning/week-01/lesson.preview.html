이번에 배울 내용

어떤 기준으로 나누는지가 예측 결과를 바꿉니다. 간단한 Threshold로 입력·정답·판정의 차이를 확인합니다.

전체 흐름

표본·특징 → 정리·자료 분리 → 기준 모델 → 새 자료의 오류

규칙과 학습할 기준

입력 x와 정답 y, 예측 ŷ를 따로 둡니다. Threshold 규칙도 자료를 나누는 작은 모델입니다. 기준을 바꿨을 때 어떤 표본에서 판정이 달라지는지 먼저 확인합니다.

틀린 표본에서 문제 읽기

정답을 한 개 바꾸면 모든 기준을 만족하기 어려울 수 있습니다. 오답 수를 줄이는 것과 정답의 품질을 확인하는 것은 다른 작업입니다.

풀이 예제

x=[12345678]x=\begin{bmatrix}1&2&3&4&5&6&7&8\end{bmatrix}, y=[00001111]y=\begin{bmatrix}0&0&0&0&1&1&1&1\end{bmatrix}입니다. x는 센서 특징, y는 두 상태의 Label입니다. 

import numpy as np
import matplotlib.pyplot as plt
x=np.arange(1,9);y=(x>4).astype(int)
pred=(x>4).astype(int)
print(np.mean(pred==y))
