Machine Learning 소개

어떤 기준으로 나누는지가 예측 결과를 바꿉니다. 간단한 Threshold로 입력·정답·판정의 차이를 확인합니다.

실습 전에

01 예측을 잘한다는 기준은 무엇일까요?

설명

정답과 판정을 분리해야 오답 수를 셀 수 있습니다.

02 Threshold를 바꾸면 어떤 표본의 판정이 달라질까요?

설명

Threshold의 양쪽에 있던 표본 중 경계가 지나간 표본의 판정이 달라집니다.

실습

실습용 노트북 미리보기실습용 노트북 다운로드

1. 규칙과 데이터

시작 조건

x=[12345678]x=\begin{bmatrix}1&2&3&4&5&6&7&8\end{bmatrix}, y=[00001111]y=\begin{bmatrix}0&0&0&0&1&1&1&1\end{bmatrix}입니다. x는 센서 특징, y는 두 상태의 Label입니다.

진행 방법

  1. x>4라는 규칙의 예측과 정답을 표로 적으세요.
  2. Threshold를 3,4,5로 바꾸고 틀린 표본과 Accuracy를 기록하세요.

남길 결과

확인할 점

  • 입력 특징·정답·예측을 서로 다른 열로 분리했는가?

2. Label 하나가 바뀐 자료

시작 조건

원래 y는 보존하고 y2=y.copy(); y2[3]=1로 Label 하나를 바꾸어 Threshold 3,4,5를 다시 비교합니다.

진행 방법

  1. x와 Threshold 3,4,53,4,5는 유지하고 y2=y.copy(); y2[3]=1로 변경본을 만드세요. 각 Threshold의 x > threshold 예측을 다시 구하세요.
  2. 기존 Label과 바꾼 Label 각각에 대해 오분류 표본의 Index·개수와 Accuracy를 구해, Threshold별 한 행의 표로 기록하세요.
  3. 바꾼 Label 하나가 어떤 Threshold의 오분류 여부를 바꿨는지 해당 표본의 입력값·예측·정답을 짚어 설명하세요.

3. 다른 입력에서도 확인하기

시작 조건

x=[0.52.54.56.5]x=\begin{bmatrix}0.5&2.5&4.5&6.5\end{bmatrix}, y=[0011]y=\begin{bmatrix}0&0&1&1\end{bmatrix}에 선택한 Threshold를 고정해 적용합니다.

진행 방법

  1. 앞의 세 Threshold 중 사용할 값 하나를 고르고, 선택한 값을 먼저 적으세요. 새 입력 네 개에 같은 x > threshold 규칙을 적용하세요.
  2. 입력·예측·제공된 Label·일치 여부를 네 행으로 기록하고 Accuracy를 계산하세요. 활동 1의 원래 8개 표본·원래 Label에서 같은 Threshold로 계산한 Accuracy와 나란히 적어 차이를 설명하세요.
