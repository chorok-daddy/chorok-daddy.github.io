행과 열을 혼동하지 않고 표본별·특징별 집계를 계산하는 연습입니다.

실습 전에

01 axis=0과 axis=1은 무엇을 모을까요?

설명

2차원 배열에서 각각 행 방향과 열 방향으로 값을 줄여 집계합니다.

02 값이 모두 같은 열을 Standardization하면 어떤 문제가 생길까요?

설명

표준편차가 0이므로 나눗셈 규칙을 별도로 정해야 합니다.

2. 스케일이 다른 특징

시작 조건

마지막 열만 100배 한 자료를 만들고, 열별 Standardization 전후 평균·표준편차를 비교합니다.

진행 방법

  1. X는 보존하고 복사본 X2의 마지막 열만 100배 하세요. 변경 전후의 열별 평균·표준편차를 기록하세요.
  2. X2의 각 열에서 그 열의 평균을 빼고 표준편차로 나누세요. NumPy 기본값과 같은 ddof=0을 사용합니다.
  3. 열별 Standardization 전후 평균·표준편차를 나란히 적고, 100배 한 열이 다른 열과 같은 척도가 되었는지 두 통계량으로 설명하세요.

3. 다른 입력에서도 확인하기

시작 조건

상수인 특징 열을 하나 추가했을 때 Standardization 분모가 0인 경우를 처리합니다.

진행 방법

  1. 모든 행에서 같은 값을 갖는 열 하나를 X에 붙이고 그 값과 열 위치를 적으세요. 예를 들어 값 1인 열을 붙일 수 있습니다.
  2. 열별 평균과 표준편차를 구하고, 표준편차가 0인 열을 표시하세요. 그 열을 나누는 데 사용할 처리 규칙을 코드에 넣으세요. 예를 들어 해당 분모만 1로 둘 수 있습니다.
  3. 상수 열의 변환 결과와 전체 결과의 np.isfinite(...).all()을 기록하세요. 상수 열에서 표준편차를 그대로 나누면 무엇이 달라지는지 설명하세요.
