놓침과 오경보 중 무엇을 줄일지는 확률을 얻은 뒤 Threshold로 결정합니다.

실습 전에

01 확률 0.6이면 반드시 양성으로 판정해야 할까요?

설명

판정 기준은 오경보와 놓침의 목적에 따라 달라질 수 있습니다.

02 클래스 수가 치우치면 정확도만으로 충분할까요?

설명

다수 클래스만 맞혀도 높게 나올 수 있어 클래스별 놓침·오경보를 함께 확인합니다.

2. 틀리는 종류 선택

시작 조건

미탐지(FN)를 더 줄여야 하는 센서 경보 상황을 가정하고 세 Threshold 중 하나를 선택합니다.

진행 방법

  1. 앞 활동의 Threshold 0.3,0.5,0.70.3,0.5,0.7별 TP·FP·FN·TN·Accuracy 표를 재사용하세요. 같은 Logit과 Label을 사용합니다.
  2. FN이 가장 적은 Threshold 후보를 찾으세요. 동률인 후보가 있으면 FP도 비교한 뒤 사용할 값 하나를 선택하고, 선택 근거가 된 FN·FP를 함께 적으세요.
  3. 선택한 값과 Threshold 0.5의 판정을 표본별로 대조해, 어떤 표본의 경보가 달라졌는지 설명하세요.

시작 조건

진행 방법

  1. Class 1이 10개, Class 0이 90개인 Label 배열과 모두 0인 예측 배열을 만드세요.
