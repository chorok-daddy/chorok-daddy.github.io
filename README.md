# 강의자료 사이트

https://chorok-daddy.github.io/

정적 HTML로 게시합니다. 메인 → courses/index.html → 과목별 목차 → 강의 자료로 연결됩니다.

HTML은 개편 교재의 편집 원고에서 생성된 배포본입니다. 생성된 페이지를 따로 수정하지 않고 원고를 수정한 뒤 다시 생성합니다. 과목/강의 목록을 기준으로 내비게이션과 이전·다음 링크를 생성합니다. 작성된 강의만 목차에 포함합니다.

과제 안내·학기 일정·실습 파일을 과목 폴더에서 관리합니다. Colab은 이 블로그 저장소의 Notebook을 엽니다. 임시 검토 저장소는 이전 이력으로 남깁니다. 이전 Jekyll 블로그는 Git 이력에 보존되어 있습니다.
