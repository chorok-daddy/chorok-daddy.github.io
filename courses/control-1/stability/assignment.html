14주차 · 안정성을 먼저 확인하고 성능 비교하기 실습

아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

먼저 계산하고 MATLAB으로 확인하기

아래 계산을 먼저 수행한 뒤 MATLAB 결과와 비교하세요.

  1. Tracking Error Section의 G(s)=1s+2G(s)=\frac1{s+2}, H(s)=2s+4H(s)=\frac2{s+4}를 사용하되 먼저 K=2K=2인 경우를 손으로 계산하세요. U=K(R−HY)U=K(R-HY), Y=GUY=GU에서 Y/RR을 구하고 분모의 Pole이 안정한지 확인하세요.
  2. Unit Step의 최종 출력과 센서 측정값을 구한 뒤 r−yr-y와 r−Hyr-Hy의 최종값을 각각 계산하세요. 그 다음 K를 2로 설정해 코드를 실행하고 두 결과를 대조하세요. 이미 계산한 K=2K=2는 반복하지 않고 K=4,8K=4,8로 이어갑니다. Routh 활동도 기존 안내대로 첫 열을 직접 유도한 뒤 roots로 확인하세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. Stability 판별

s3+3s2+2s+Ks^3+3s^2+2s+K의 Routh 첫 열을 유도하고 K=1,6,7을 비교하세요. K=6에서 Pole을 구하고 실수부가 0인 Pole이 있는지 확인하세요. 모든 Pole의 실수부가 음수인 경우와 응답이 어떻게 다른지 설명하세요.

2. Tracking Error와 비교점 Error

K=2,4,8에서 목표값에서 실제 출력을 뺀 r−yr-y와, 목표값에서 센서 측정값을 뺀 r−Hyr-Hy를 각각 계산하세요. 실제 출력이 목표값에 가까운지 판단할 때 사용할 오차가 어느 쪽인지 적으세요.

3. 유한 구간 Performance Index

구간을 10초·20초·40초로 바꾸어 ISE가 달라지는 이유를 설명하세요. 종료 시간을 늘려도 적분값이 일정한 값에 가까워지는지 확인하고, 현재 계산한 값이 어느 시간 구간의 결과인지 적으세요.

4. Optimization과 Approximation

K3의 검색 간격을 바꾸어 최적값 오차를 비교하세요. GL의 계수 하나를 10% 바꾸고 Approximation 오차를 기록하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 기준 예제만 실행한 파일은 직접 수행 항목을 완료한 것이 아닙니다. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.
