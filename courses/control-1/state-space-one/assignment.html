5주차 · 상태를 선택해 행렬 모델 만들기 실습

아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

먼저 계산하고 MATLAB으로 확인하기

코드를 실행하기 전에 아래 계산을 종이나 Live Script 설명란에 적으세요. 실행 후 자신의 식과 출력값을 비교하고, 다르면 계수·부호·초기조건부터 확인하세요.

  1. 병렬 RLC에서 위 Node의 전압을 v, 위에서 아래로 흐르는 인덕터 전류를 iLi_L, 공급 전류를 u로 정하세요. R=1, L=1, C=1에서 KCL과 v=L·diL/dt를 이용해 𝐱=[v,iL]T\mathbf x=[v,i_L]^T의 두 미분방정식과 출력 y=v를 직접 쓰고 A,B,C,D를 구하세요. 초기조건 0에서 두 식을 Laplace Transform하고 IL(s)I_L(s)를 소거하여 V(s)U(s)\frac{V(s)}{U(s)}를 구하세요.
  2. 일정 전류 1 A를 충분히 오래 공급하면 v와 iLi_L이 각각 얼마가 되는지 먼저 적으세요. 직접 구한 행렬로 ss 모델을 만들고 tf·dcgain으로 검증하세요. 이 병렬 회로는 아래 RL 직렬 가지 회로와 구성이 다릅니다. 이번에는 RL 회로의 R 반복 세 값 중 한 값을 이 비교로 대신하세요.

기록 방법: 종이나 Live Script의 설명란에 손으로 계산한 식과 값을 먼저 적으세요. 코드를 실행한 뒤 출력값을 옆에 적어 비교하세요. 두 값이 다르면 어느 식이나 코드가 달랐는지와 수정한 내용을 적고, 같으면 “일치함”이라고 적으세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. Mechanical State Space

b=0.5,2,10을 각각 다시 모델링하고 응답을 비교하세요. Output을 속도로 바꾼 경우 Cout과 DC Gain도 확인하세요.

2. Electrical State Space

R=1,3,10에서 모델을 다시 만들고 일정 입력 1A에 대한 최종 출력 전압을 비교하세요. Ccap은 Capacitance 값, Cout은 State에서 출력 전압을 계산하는 행렬임을 적고, Cout이 원하는 전압을 선택하는지 확인하세요.

3. State 좌표와 초기값

초기 상태 [0;1]과 [1;0]을 비교하세요. 이 결과가 초기조건을 모두 0으로 두고 계산한 Step Response과 다른 이유를 적으세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 기준 예제만 실행한 파일은 직접 수행 항목을 완료한 것이 아닙니다. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.
