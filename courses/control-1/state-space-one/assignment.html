5주차 · 상태를 선택해 행렬 모델 만들기 실습

아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 본인 사본을 새 세션에서 검증하고 저장합니다.

1. Mechanical State Space

b=0.5,2,10을 각각 다시 모델링하고 응답을 비교하세요. Output을 속도로 바꾼 경우 Cout과 DC Gain도 확인하세요.

2. Electrical State Space

R=1,3,10을 비교하세요. Ccap과 Cout이 다른 양이라는 것을 설명하고 Input 1A에 대한 최종 Output Voltage를 검증하세요.

3. State 좌표와 초기값

초기 상태 [0;1]과 [1;0]을 비교하세요. 이 결과가 초기조건을 모두 0으로 두고 계산한 Step Response과 다른 이유를 적으세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 기준 예제만 실행한 파일은 직접 수행 항목을 완료한 것이 아닙니다. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.

파일명: 이름_학번_5주차.mlx.

선택 실습

시간이 남으면 코드의 계수나 배열 크기를 하나 바꿔보고, 예상과 다른 결과가 나면 원인을 찾아 수정하세요. 추가 활동은 필수 60분 실습을 완료한 뒤 진행합니다.
