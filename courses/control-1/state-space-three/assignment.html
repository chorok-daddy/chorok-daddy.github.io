7주차 · 모델 표현을 바꾸어도 같은 응답일까? 실습

아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

먼저 계산하고 MATLAB으로 확인하기

코드를 실행하기 전에 아래 계산을 종이나 Live Script 설명란에 적으세요. 실행 후 자신의 식과 출력값을 비교하고, 다르면 계수·부호·초기조건부터 확인하세요.

  1. 첫 Section의 A,B,C,DA,B,C,D를 읽어 두 State Equation을 손으로 쓰세요. 초기조건 0에서 Laplace Transform한 뒤 State 하나를 소거하여 Y(s)U(s)\frac{Y(s)}{U(s)}를 구하고, C=[0,1]C=[0,1]이면 출력식이 어떻게 바뀌는지도 적으세요. 그 다음 tf 결과와 비교하세요.
  2. 좌표변환 Section에서는 행렬 변환 코드를 실행하기 전에 𝐱=P𝐳\mathbf x=P\mathbf z 관계를 각 State Equation과 출력식에 직접 대입하세요. 한 번은 식으로 Az,Bz,CzA_z,B_z,C_z를 구하고, 𝐱0\mathbf x_0도 같은 관계로 바꾼 뒤 코드 결과와 대조하세요. 이 과정을 각 Section의 첫 조건에 적용하며 추가 반복은 하지 않습니다.

기록 방법: 종이나 Live Script의 설명란에 손으로 계산한 식과 값을 먼저 적으세요. 코드를 실행한 뒤 출력값을 옆에 적어 비교하세요. 두 값이 다르면 어느 식이나 코드가 달랐는지와 수정한 내용을 적고, 같으면 “일치함”이라고 적으세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. 변환 전후의 응답

C=[0,1]C=[0,1]로 바꾸어 같은 비교를 수행하세요. Output과 DC Gain이 바뀌는 이유를 적으세요.

2. State 좌표 스케일 변경

P=diag⁡(3,2)P=\operatorname{diag}(3,2)로 바꾸고 Az,Bz,CzA_z,B_z,C_z를 새로 계산하세요. 행렬 숫자가 달라져도 같은 Output인 이유를 설명하세요.

3. 초기값 변환 오류 수정

𝐱0\mathbf x_0=[1;0], [0;1], [2;1]을 반복하세요. 올바른 변환과 초기값을 그대로 쓴 결과를 각각 비교하고 수치 차이를 표로 기록하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 기준 예제만 실행한 파일은 직접 수행 항목을 완료한 것이 아닙니다. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.
