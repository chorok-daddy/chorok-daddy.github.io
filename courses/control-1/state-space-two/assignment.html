6주차 · State Transition으로 응답 따라가기 실습

아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

먼저 계산하고 MATLAB으로 확인하기

기준 예제를 읽는 10분 중 5–8분을 사용하세요. 설명에 나온 식은 참고해도 되지만, 결과를 출력하는 코드는 계산을 적은 뒤 실행하세요. 종이 또는 Live Script의 설명란에 식을 쓰고, 기존 기준 예측·반복 기록에 포함하세요. 전체 실습 시간은 약 60분입니다.

  1. 아래 일반 모델을 실행하기 전에 A=diag([-1,-2]), x0=[2;1], Input=0인 간단한 경우를 손으로 계산하세요. 대각행렬에서는 Phi(t)=diag([exp(a1*t),exp(a2*t)])입니다. Phi(t)와 x(t)=Phi(t)x0를 기호식으로 쓰고 t=0에서 초기값이 되는지 확인하세요.
  2. 전체 응답 식에서 초기 State에 의한 항과 Input에 의한 적분항을 표시하고, 여기서 어느 항이 0인지 설명하세요. t=1의 값은 지수함수 형태로 둔 뒤 MATLAB의 expm(A)*x0와 대조하세요. 이 계산을 첫 Section의 기준 예측으로 사용하세요.

작성란: 계산 과정 · 실행 결과 · 차이가 난 이유: ⟦직접 입력⟧

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. State Transition Matrix

t=0,0.5,1의 Phi를 구하고 Phi(1)=Phi(0.5)*Phi(0.5)를 norm으로 검증하세요. State의 시간 변화를 계산할 때 expm을 써야 하는 이유를 설명하세요.

2. 초기 상태의 궤적

x0=[0;1]로 바꾸고 두 상태를 비교하세요. 위치가 0으로 시작해도 이후 움직이는 이유를 속도와 연결해 설명하세요.

3. 전체 응답의 분해

Input 크기를 2로 바꾼 뒤 x0=[0;1]도 적용해 두 경우를 각각 검증하세요. Input만 2배 했을 때 전체 응답도 항상 2배인지 판단하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 기준 예제만 실행한 파일은 직접 수행 항목을 완료한 것이 아닙니다. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.
