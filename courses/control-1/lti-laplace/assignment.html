3주차 · Linearity(선형성)에서 Laplace Transform(라플라스 변환)까지 실습

아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. Linearity 반례

3x, x², 3x+1, cos(t)x, dx/dt의 Linearity와 Time Invariance를 각각 판별하고 이유를 적으세요.

2. Linear Approximation

|sin(x)−x|≤0.01을 만족하는 0 주변 범위를 코드로 조사하세요. 0.1,0.5,1 rad의 오차를 표로 비교하세요.

3. Laplace Transform

exp(−2t), sin(4t)의 Transform·Inverse를 확인하고 ẍ+4ẋ+3x=6u(t)\ddot x+4\dot x+3x=6u(t), 초기조건이 모두 0일 때의 해를 구하세요. 얻은 해를 원래 식에 대입해 검증하세요. Toolbox가 없으면 X(s)=6s(s+1)(s+3)X(s)=\frac6{s(s+1)(s+3)}을 As+Bs+1+Cs+3\frac As+\frac B{s+1}+\frac C{s+3}으로 분해하여 계수를 구한 뒤 exp 형태의 해와 도함수를 직접 작성해 검증하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 기준 예제만 실행한 파일은 직접 수행 항목을 완료한 것이 아닙니다. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.

선택 실습

시간이 남으면 코드의 계수나 배열 크기를 하나 바꿔보고, 예상과 다른 결과가 나면 원인을 찾아 수정하세요. 추가 활동은 필수 60분 실습을 완료한 뒤 진행합니다.
