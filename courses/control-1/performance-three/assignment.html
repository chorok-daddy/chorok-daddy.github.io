13주차 · P와 PI의 Steady-state Error(정상상태 오차) 비교하기 실습

아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

먼저 계산하고 MATLAB으로 확인하기

기준 예제를 읽는 10분 중 5–8분을 사용하세요. 설명에 나온 식은 참고해도 되지만, 결과를 출력하는 코드는 계산을 적은 뒤 실행하세요. 종이 또는 Live Script의 설명란에 식을 쓰고, 기존 기준 예측·반복 기록에 포함하세요. 전체 실습 시간은 약 60분입니다.

  1. P와 PI의 Step 추종 Section에서 PI=10+5/s와 G=1/(0.5*s+1)를 사용하세요. 실행 전에 L=PI*G와 1+L=0에서 얻는 특성다항식을 손으로 쓰세요. 2차 다항식의 세 계수가 양수이면 두 Pole의 실수부가 음수라는 기준으로 안정성을 확인하세요.
  2. L의 원점 Pole 수로 System Type을 정하고 Kp=lim(s→0)L(s), Kv=lim(s→0)sL(s)를 구하세요. 안정성을 확인한 뒤 Unit Step 오차 1/(1+Kp)와 Unit Ramp 오차 1/Kv를 계산하고 실행 결과와 비교하세요. 이 계산을 Ki=5의 기준 기록으로 사용합니다.

작성란: 계산 과정 · 실행 결과 · 차이가 난 이유: ⟦직접 입력⟧

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. Pole 위치 비교

같은 zeta를 유지하고 wn만 바꾸는 모델 쌍을 만들어 비교하세요. 원래 두 모델과 어떤 조건이 다른지 적으세요.

2. P와 PI의 Step 추종

Kp를 20으로 바꾸어 P의 이론 오차를 검증하세요. Ki=2,5,10에서 PI의 Step 오차와 Transient Response(과도 응답)을 비교하세요.

3. Ramp 추종

Loop Transfer Function에서 원점 Pole을 세어 System Type을 구하세요. 해당 Type의 Unit Ramp 오차 공식을 적용한 뒤, Ki=10에서 계산한 오차가 시뮬레이션에서 충분히 시간이 지난 뒤의 오차와 같은지 비교하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 기준 예제만 실행한 파일은 직접 수행 항목을 완료한 것이 아닙니다. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.

선택 실습
