12주차 · 2차 시스템의 감쇠와 속도 조절하기 실습

이 페이지와 실습 파일이 개편된 실습 원본입니다. 아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 한 유형에서 세 가지 조건을 더 바꾸어 반복합니다.
  4. 본인 사본을 새 세션에서 검증하고 저장합니다.

1. 표준형 변환

K1=9,K2=3과 K1=16,K2=8을 반복 계산하고 Damping 유형을 판별하세요.

2. Damping Ratio 비교

동일한 zeta에서 wn을 2배로 바꾸어 Overshoot와 시간 지표가 어떻게 달라지는지 비교하세요.

3. 설계 후 검증

다른 zeta·wn 조합 두 개를 찾아 같은 조건을 만족하는지 검증하세요. 만족하지 않는 조합도 하나 기록하고 어느 지표에서 실패했는지 설명하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 기준 예제만 실행한 파일은 직접 수행 항목을 완료한 것이 아닙니다. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.

파일명: 이름_학번_12주차.mlx. 이 개편본에서는 수업 주차를 사용합니다.

선택 실습

시간이 남으면 작은 오류 사례를 만들고 원인과 수정 과정을 설명하세요. 추가 활동은 필수 60분 실습을 완료한 뒤 진행합니다.
