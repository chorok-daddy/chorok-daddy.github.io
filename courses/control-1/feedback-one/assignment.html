9주차 · Feedback으로 Gain 변화 줄이기 실습

아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

먼저 계산하고 MATLAB으로 확인하기

코드를 실행하기 전에 아래 계산을 종이나 Live Script 설명란에 적으세요. 실행 후 자신의 식과 출력값을 비교하고, 다르면 계수·부호·초기조건부터 확인하세요.

  1. 변화율 검증 Section을 실행하기 전에 Ka=5000,β=0.05,δ=0.1K_a=5000,\quad\beta=0.05,\quad\delta=0.1을 사용해 손으로 계산하세요. T(Ka)=Ka1+βKaT(K_a)=\frac{K_a}{1+\beta K_a}를 미분하고 S=KaTdTdKaS=\frac{K_a}{T}\frac{dT}{dK_a}에 대입하여 기준 Sensitivity S0S_0를 구하세요.
  2. 근사 계산: S0S_0에 KaK_a의 상대 증가 비율 0.1을 곱하세요. 정확 계산: T0=T(5000)T_0=T(5000), T1=T(5500)T_1=T(5500)을 각각 구한 뒤 T1−T0T0\frac{T_1-T_0}{T_0}를 계산하세요. 두 답은 분수로 두어도 됩니다.
  3. 손으로 쓴 두 계산을 저장한 뒤 Section을 실행해 approx·exact와 대조하세요. 차이가 나면 분모에 변경 전 T0T_0를 썼는지 확인하세요. 이후 1%·20% 조건을 반복합니다. 10% 조건은 이미 수행했으므로 다시 할 필요가 없습니다.

기록 방법: 종이나 Live Script의 설명란에 손으로 계산한 식과 값을 먼저 적으세요. 코드를 실행한 뒤 출력값을 옆에 적어 비교하세요. 두 값이 다르면 어느 식이나 코드가 달랐는지와 수정한 내용을 적고, 같으면 “일치함”이라고 적으세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. 기준 Gain과 Sensitivity

KaK_a=1000,5000,10000에서 Open-loop·Closed-loop Gain과 Sensitivity를 표로 계산하세요.

2. 변화율 검증

delta=0.01,0.1,0.2를 비교하세요. 각 delta에서 근사 변화율과 정확한 변화율의 차이를 표로 적으세요. 변화가 클 때 두 값이 더 벌어지는지, Feedback이 없을 때와 비교해 전체 Gain이 얼마나 덜 변하는지 설명하세요.

3. 반복 검사

β\beta=0.01과 0.1을 추가하고 곡선을 비교하세요. 전체 Gain의 값과 Sensitivity를 각각 기록하세요. 출력의 크기가 작아진 것인지, KaK_a를 바꿨을 때 출력이 덜 변하는 것인지 설명하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 기준 예제만 실행한 파일은 직접 수행 항목을 완료한 것이 아닙니다. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.
