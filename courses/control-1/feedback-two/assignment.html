10주차 · DC 모터의 Disturbance(외란) 경로 읽기 실습

아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

먼저 계산하고 MATLAB으로 확인하기

코드를 실행하기 전에 아래 계산을 종이나 Live Script 설명란에 적으세요. 실행 후 자신의 식과 출력값을 비교하고, 다르면 계수·부호·초기조건부터 확인하세요.

  1. 모터의 Va=−KaKtωV_a=-K_aK_t\omega, i=Va−KbωRai=\frac{V_a-K_b\omega}{R_a}, Jdωdt+bω=Kmi+TdJ\frac{d\omega}{dt}+b\omega=K_mi+T_d에서 VaV_a와 i를 손으로 소거하세요. 초기조건 0에서 Ω(s)Td(s)\frac{\Omega(s)}{T_d(s)}를 구한 뒤 타코 Feedback Section의 모델과 비교하세요.
  2. 목표 조건 Section의 기존 값(D=0.2, limit=0.5 및 해당 모터 계수)을 사용하세요. 속도가 더 이상 변하지 않을 때의 식에서 최종 속도를 구하고, |최종 속도|≤limit를 KaK_a의 부등식으로 정리하세요. 완성된 Ka_min 코드는 그 뒤 실행해 확인하세요. 이 계산이 기준 조건의 수행 기록을 대신합니다.

작성란: 계산 과정 · 실행 결과 · 차이가 난 이유: ⟦직접 입력⟧

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. Disturbance의 Open-loop 경로

D=0.1,0.2,0.3의 최종 속도 편차를 구하고 선형 비례 관계를 확인하세요.

2. 타코 Feedback 추가

KaK_a=10,20,40에서 외란 토크를 입력으로 하는 모델의 DC Gain을 구하세요. 각 DC Gain에 외란 크기 D를 곱해 최종 속도 편차를 구하고 두 값을 별도 열에 기록하세요.

3. 목표 조건 검사

limit=0.25와 1rad/s로 바꾸어 최소 KaK_a를 계산하고 Feedback 모델로 검증하세요. 구한 최소 KaK_a보다 조금 작은 값과 큰 값을 각각 넣어 목표를 만족하는지 확인하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 기준 예제만 실행한 파일은 직접 수행 항목을 완료한 것이 아닙니다. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.
