9주차 · CNN을 shape로 따라가기 실습

아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 한 유형에서 세 가지 조건을 더 바꾸어 반복합니다.
  4. 본인 사본을 새 세션에서 검증하고 저장합니다.

1. 간단한 CNN으로 각 층의 shape 확인하기

Input (N,1,28,28)에 Conv2d(1,32,3,padding=1)→ReLU→MaxPool2d(2)→Conv2d(32,64,3,padding=1)→ReLU→MaxPool2d(2)→Conv2d(64,128,3,padding=1)→ReLU→MaxPool2d(2,padding=1)→Flatten(start_dim=1)→Linear(2048,625)→ReLU→Dropout→Linear(625,10)을 구현하세요. 각 단계의 예상 shape를 먼저 적고 실제 출력으로 확인하세요.

2. Batch(배치) 크기와 parameter

앞에서 직접 만든 CNN에 N=1·8·32를 각각 넣어 최종 (N,10)을 확인하세요. Parameter 수는 sum(p.numel() for p in model.parameters())로 구해 N을 바꿔도 같은지 검사하세요. model.eval() 상태에서 비교하고 학습 가능한 Layer와 그렇지 않은 Layer를 구분하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 기준 예제만 실행한 파일은 직접 수행 항목을 완료한 것이 아닙니다. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.

선택 실습
