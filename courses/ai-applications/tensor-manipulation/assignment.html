5주차 · Tensor의 모양을 먼저 예측하기 실습

실습 전에

01 값과 자리의 의미

예시 상황 학생별 측정값을 행과 열로 정리하듯이, 사진의 숫자들은 무엇을 기준으로 구분해야 할까요?

설명
  • 학생별 표는 학생과 측정 항목을 구분합니다. 사진은 픽셀의 세로·가로 위치와 색 성분을 구분해야 합니다.
  • Tensor는 이렇게 여러 축으로 수치를 배치한 배열입니다. 값이 놓인 자리가 무엇을 뜻하는지 함께 정해야 합니다.

관련 개념 복습 ↗

02 사진 한 장에서 여러 장으로

예시 상황 컬러 사진 여러 장을 묶으면, 사진 한 장을 표현할 때보다 무엇을 더 구분해야 할까요?

설명
  • 사진 번호를 구분할 축이 필요합니다. 예를 들어 사진 수·색 성분 수·높이·너비의 순서로 배치할 수 있습니다.
  • Tensor의 축 개수는 실제 공간의 차원이 아니라 데이터에서 구분하는 항목과 관련됩니다. 축 순서는 사용하는 모델에서 확인합니다.

관련 개념 복습 ↗

03 연산의 의미

학생별 평균과 측정 항목별 평균은 각각 어떤 값들을 모아 계산하나요?

설명
  • 학생별 평균은 한 학생의 항목들을, 항목별 평균은 여러 학생의 같은 항목을 모아 계산합니다.
  • 이번 실습은 축 번호를 바꿨을 때 어떤 정보가 남는지 확인하는 과정입니다. 같은 원리가 사진 묶음과 AI 모델의 데이터 처리에도 적용됩니다. PyTorch Tensor에서는 이 배열 계산을 GPU 연산과 자동미분으로 이어갈 수 있습니다.

1. Tensor 만들기

0~5의 1D Tensor, 0~11의 (4,3) Tensor, 0~23의 (2,3,4) Tensor를 float로 생성하세요. (4,3)을 표본 4개·특징 3개로 보고 특징별 평균과 표본별 평균의 예상 shape를 적은 뒤 dim=0·1로 검증하세요.

2. cat·stack·reshape

dim 값을 바꾸어 결과를 비교하고 cat과 stack의 차이를 쓰세요. 원소 수 12를 유지하는 세 가지 reshape와 -1 사용 예를 작성하세요.

3. 축과 연산 오류 찾기

A.shape=(2,3), B.shape=(3,4)인 기준 예에서 A*B와 A@B 중 실행 가능한 연산과 그 이유를 쓰세요. A+torch.tensor([10,20])가 실패하는 이유를 설명하고, 행별로 10과 20을 더하도록 Tensor shape를 수정하세요. 실패 코드는 Markdown에만 남기고 수정한 Code Cell을 실행하세요.
