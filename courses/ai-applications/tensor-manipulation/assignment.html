5주차 · Tensor의 모양을 먼저 예측하기 실습

실습 전에

01 데이터를 숫자로 표현하기

사진이나 측정값을 AI가 계산할 수 있게 만들려면, 숫자의 값 외에 어떤 정보도 함께 표현해야 할까요?

설명
  • 픽셀의 위치와 색 성분
  • Tensor: 값을 여러 축의 수치 배열로 배치하여 표현

02 데이터를 묶는 방법

사진 한 장을 표현하는 방법을 알고 있다면, 여러 장의 컬러 사진은 어떻게 구분해서 묶을 수 있을까요?

설명
  • 세로·가로에 색 성분과 사진 번호를 구분하는 축 추가
  • 예: (사진 수, 색 성분 수, 높이, 너비). 축 순서는 환경에 따라 다름

03 Tensor가 필요한 이유

숫자를 저장하는 방법은 이미 여러 가지가 있습니다. AI 학습에서 Tensor를 사용하는 이유는 무엇일까요?

설명
  • 여러 데이터에 대한 효율적인 수치 연산
  • PyTorch Tensor의 GPU 연산·자동미분 지원
  • 축의 의미는 별도 정의 필요. 같은 shape가 같은 의미를 보장하지 않음

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.

1. Tensor 만들기

0~5의 1D Tensor, 0~11의 (4,3) Tensor, 0~23의 (2,3,4) Tensor를 float로 생성하세요. (4,3)을 표본 4개·특징 3개로 보고 특징별 평균과 표본별 평균의 예상 shape를 적은 뒤 dim=0·1로 검증하세요.

2. cat·stack·reshape

dim 값을 바꾸어 결과를 비교하고 cat과 stack의 차이를 쓰세요. 원소 수 12를 유지하는 세 가지 reshape와 -1 사용 예를 작성하세요.

3. 축과 연산 오류 찾기

A.shape=(2,3), B.shape=(3,4)인 기준 예에서 A*B와 A@B 중 실행 가능한 연산과 그 이유를 쓰세요. A+torch.tensor([10,20])가 실패하는 이유를 설명하고, 행별로 10과 20을 더하도록 Tensor shape를 수정하세요. 실패 코드는 Markdown에만 남기고 수정한 Code Cell을 실행하세요.
