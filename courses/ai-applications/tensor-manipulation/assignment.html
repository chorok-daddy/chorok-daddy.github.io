오늘의 대화

시작하며 생각해보기

먼저 각자의 생각을 나눈 뒤, 질문 아래의 정리를 펼쳐보세요.

01 사진을 모델에 준다는 것은 무엇을 주는 걸까?

모델에 사진을 넣을 때 실제로 전달하는 것은 무엇일까요? 픽셀값을 순서 없이 섞어도 같은 사진일까요?

함께 정리하기

사진은 픽셀의 수치로 표현할 수 있습니다. 하지만 값뿐 아니라 어느 위치의 어떤 색 성분인지도 정보입니다.

Tensor는 여러 축을 가진 수치 배열로, 이런 구조를 담아 계산할 때 사용합니다.

02 사진 여러 장은 어떻게 구분할까?

흑백 사진 한 장에서는 세로·가로를 구분합니다. 컬러 사진이 되면, 또 여러 사진을 한 번에 묶으면 무엇을 더 구분해야 할까요?

함께 정리하기

색 성분을 구분하는 축, 사진을 구분하는 축이 더 필요합니다. 예를 들어 (사진 수, 색 성분 수, 높이, 너비)로 표현할 수 있습니다.

4차원 공간을 상상할 필요는 없습니다. 값을 찾을 때 구분할 항목이 네 개라는 뜻입니다. 축의 순서는 사용하는 환경에 따라 달라질 수 있습니다.

03 리스트도 있는데 왜 Tensor를 쓸까?

숫자는 Python 리스트에도 넣을 수 있습니다. AI 학습에서 Tensor를 기본 자료형으로 사용하는 이유는 무엇일까요?

함께 정리하기

데이터를 담는 것에 더해, 많은 값의 연산과 여러 Sample의 처리를 효율적으로 수행해야 하기 때문입니다. PyTorch Tensor는 GPU 연산과 자동미분을 지원합니다.

다만 각 축의 의미는 사람이 정합니다. 같은 (100, 3)도 학생 100명의 세 과목 점수일 수도, 점 100개의 공간 좌표일 수도 있습니다.

실습 안내로 이동 ↓

아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. Tensor 만들기

0~5의 1D Tensor, 0~11의 (4,3) Tensor, 0~23의 (2,3,4) Tensor를 float로 생성하세요. (4,3)을 표본 4개·특징 3개로 보고 특징별 평균과 표본별 평균의 예상 shape를 적은 뒤 dim=0·1로 검증하세요.

2. cat·stack·reshape

dim 값을 바꾸어 결과를 비교하고 cat과 stack의 차이를 쓰세요. 원소 수 12를 유지하는 세 가지 reshape와 -1 사용 예를 작성하세요.

3. 축과 연산 오류 찾기

A.shape=(2,3), B.shape=(3,4)인 기준 예에서 A*B와 A@B 중 실행 가능한 연산과 그 이유를 쓰세요. A+torch.tensor([10,20])가 실패하는 이유를 설명하고, 행별로 10과 20을 더하도록 Tensor shape를 수정하세요. 실패 코드는 Markdown에만 남기고 수정한 Code Cell을 실행하세요.
