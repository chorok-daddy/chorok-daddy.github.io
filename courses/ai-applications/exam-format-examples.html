과목 목록과목 자료

인공지능응용 · 시험 유형 예시

실제 시험과 다른 소재로 제공 자료의 설명 수준과 답안 작성 분량을 보여 줍니다. 아래 3세트는 짧은 발췌 예시이며, 실제 시험 범위·문항 수·난이도·배점을 예고하지 않습니다. 중간·기말 안내에서 공통으로 참고할 수 있습니다.

먼저 참고자료를 읽고, 문제의 빈칸이나 요청한 값만 손으로 작성해 보세요. 설치·파일 불러오기·그림 꾸미기 같은 주변 코드는 작성하지 않습니다. 답안 예시의 ‘작성할 답’은 학생이 적을 분량을, ‘풀이’는 이해를 돕는 추가 설명을 뜻합니다.

이 예시에 제공하는 참고자료

실제 시험의 1페이지 문법·관계식 자료와 같은 역할입니다. 예시에서는 import torch가 완료되어 있고, Tensor는 모두 CPU에 있다고 봅니다. 아래 코드는 PyTorch 문법이며 정수 계산만 사용합니다.

torch.tensor([[1,2],[3,4]])  # 2행 2열 Tensor
x.shape                     # 축별 크기
x[:,j]                      # 모든 행의 j열; Index는 0부터 시작
x.sum(dim=1)                # 열 방향으로 합: (행,열) → (행,)
x.sum(dim=0)                # 행 방향으로 합: (행,열) → (열,)
x.T                         # 2차원 Tensor의 행과 열을 서로 바꿈
x * 2                       # 모든 원소에 2를 곱함
x * y                       # 같은 위치끼리 곱함
x.cumsum(dim=1)             # 각 행에서 왼쪽부터 누적합
values, indices=torch.sort(x,dim=1,descending=True)

torch.sort는 각 행을 큰 값부터 정렬하고, 정렬한 값과 원래 열 위치를 각각 반환합니다. 예를 들어 [4,9,2]는 값 [9,4,2], 위치 [1,0,2]가 됩니다. 두 반환값의 shape는 입력과 같습니다.

Broadcasting: 두 Tensor의 축을 오른쪽부터 맞춥니다. 크기가 같거나 한쪽이 1이면 계산할 수 있습니다. 예를 들어 (2,3)과 (3,)의 곱은 각 행에 같은 길이 3의 벡터를 곱하며 결과는 (2,3)입니다.

예시 1 · 품목별 구매 금액 계산

문제의 조건 · 두 사람이 각각 공책·펜·파일을 구매했습니다. qty의 행은 사람, 열은 공책·펜·파일 순서입니다. price에는 같은 순서로 물건 한 개의 가격을 100원 단위로 적었습니다. cost에는 품목별 금액, total에는 사람별 총금액을 저장합니다.

qty=torch.tensor([[1,2,1],
                  [3,0,2]])
price=torch.tensor([4,3,2])
cost=___A___
total=cost.sum(dim=___B___)

답할 내용

  1. A와 B를 채우세요.
  2. cost의 모든 값과 shape, total의 값과 shape를 쓰세요.
  3. price를 price[:,None]으로 바꾸면 shape가 (3,1)이 됩니다. qty와 곱할 수 있는지, 참고자료의 규칙으로 설명하세요.
답안 예시와 풀이

작성할 답

A: qty*price, B: 1
cost=[[4,6,2],[12,0,4]], shape=(2,3)
total=[12,16], shape=(2,)
곱할 수 없음: (2,3)과 (3,1)의 앞 축 2와 3이 다르고 둘 다 1이 아님.

풀이 · 가격 벡터를 각 사람의 수량에 곱한 뒤 품목 축을 합합니다. 첫 사람은 1,200원, 둘째 사람은 1,600원입니다. 마지막 질문은 실행 오류 문구를 외우는 문제가 아니라 shape 규칙을 적용하는 문제입니다.

예시 2 · 기록을 정렬한 뒤 원래 위치 찾기

문제의 조건 · 두 선수가 세 번씩 시도한 점수입니다. 각 행은 한 선수, 각 열은 시도 순서입니다. 선수별로 높은 점수부터 정렬한 뒤 최고 점수와 그것이 나온 시도를 확인합니다. 점수가 같은 경우는 없습니다.

scores=torch.tensor([[7,3,9],
                     [4,8,2]])
ordered,where=torch.sort(scores,dim=1,descending=True)
best=ordered[:,___A___]
attempt=where[:,0]+___B___

답할 내용

  1. ordered와 where의 값 및 각각의 shape를 쓰세요.
  2. A와 B를 채우세요. attempt는 첫 시도를 1번으로 표시해야 합니다.
  3. best와 attempt의 값, attempt[1]의 의미를 쓰세요.
답안 예시와 풀이

작성할 답

ordered=[[9,7,3],[8,4,2]], shape=(2,3)
where=[[2,0,1],[1,0,2]], shape=(2,3)
A: 0, B: 1
best=[9,8], attempt=[3,2]
attempt[1]: 둘째 선수의 최고 점수는 두 번째 시도에서 나옴.

풀이 · where는 정렬된 순위가 아니라 원래 열의 Index입니다. 가장 높은 점수는 정렬 결과의 첫 열에 있고, 시도 번호로 표현하려면 0부터 시작하는 Index에 1을 더합니다.

예시 3 · 주간 기록의 축과 누적합

문제의 조건 · 두 사람의 월·화·수 독서량을 기록했습니다. 원래 표의 행은 사람, 열은 날짜입니다. 사람별 누적 독서량을 계산하려는 코드에서 먼저 표를 Transpose했습니다.

pages=torch.tensor([[2,1,4],
                    [3,2,1]])
by_day=pages.T
running=by_day.cumsum(dim=1)  # 사람별 날짜 누적량을 구하려 함

답할 내용

  1. by_day의 값과 shape를 쓰세요.
  2. running을 계산하는 줄의 dim을 올바르게 고치세요.
  3. 수정 후 running의 값과 shape를 쓰세요. running[1,0]은 무엇을 뜻하나요?
답안 예시와 풀이

작성할 답

by_day=[[2,3],[1,2],[4,1]], shape=(3,2)
수정: dim=0
running=[[2,3],[3,5],[7,6]], shape=(3,2)
running[1,0]: 첫 사람이 화요일까지 읽은 누적량 3페이지

풀이 · Transpose 후에는 행이 날짜, 열이 사람입니다. 날짜가 늘어나는 0번 축으로 누적해야 같은 사람의 기록끼리 더합니다. cumsum은 각 위치까지의 합을 모두 남기므로 축이 사라지지 않습니다.
