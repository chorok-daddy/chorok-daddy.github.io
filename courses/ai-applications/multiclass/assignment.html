시작하며 생각해보기

먼저 각자의 생각을 나눈 뒤, 질문 아래의 정리를 펼쳐보세요.

01 번호에 크기 의미가 있을까?

고양이, 개, 새에 각각 0, 1, 2를 붙였습니다. 새는 고양이보다 두 배 크거나 더 높은 범주라는 뜻일까요?

함께 정리하기

Class ID는 범주를 구분하기 위한 약속입니다. 숫자의 크기에 순서나 거리 의미가 있는 것은 아닙니다.

데이터의 Label과 출력 위치가 같은 약속을 따라야 합니다.

02 가장 높은 점수는 무엇을 말해줄까?

세 Class 중 한 점수가 가장 높습니다. 이것만으로 모델이 아주 확신한다고 말할 수 있을까요?

함께 정리하기

최대 점수의 위치는 선택할 Class를 알려주지만 점수 차이나 예측의 신뢰도를 모두 설명하지는 않습니다. Logit은 그대로 확률이 아닙니다.

Class 선택과 점수의 해석을 구분합니다.

실습 안내로 이동 ↓

아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. CSV의 입력 확인

전처리 전후 shape·dtype·처음 다섯 표본을 확인하세요. 평균과 표준편차를 새 입력에도 동일하게 적용해야 하는 이유를 쓰세요.

2. 기준 학습 실행

같은 초기화와 1000 epoch에서 Learning Rate 0.001·0.01·0.1을 비교하세요. 마지막 Training Loss·Accuracy를 표로 기록하고 Loss와 Accuracy의 변화가 항상 같은지 해석하세요. 이 값은 별도 Test Accuracy가 아닙니다.

3. 출력을 해석하기

첫 10개 표본의 Logit·Probability·예측·정답을 비교하세요. Softmax 합이 표본마다 1인지, Logit과 Probability의 argmax가 같은지 검증하세요. 오분류를 최대 3개 골라 실제 Label과 예측 Label을 적고, 없으면 없다고 기록하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 기준 예제만 실행한 파일은 직접 수행 항목을 완료한 것이 아닙니다. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.
