실습 안내로 이동 ↓

아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. MNIST와 실행 규모

이미지 한 장의 shape와 label을 확인하고 DataLoader의 마지막 Batch(배치) 크기를 조사하세요.

2. CNN 학습과 평가

필수 실습은 QUICK_RUN=True로 진행하고 사용 epoch와 학습·평가 데이터 수를 기록하세요. 전체 데이터 학습은 시간이 남을 때 선택합니다. train과 eval, no_grad의 서로 다른 역할을 설명하세요.

3. 그래프와 오분류

맞힌 예와 틀린 예를 보고 결과를 해석하세요. subset 결과와 전체 test accuracy를 혼동하지 않았는지 점검하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 기준 예제만 실행한 파일은 직접 수행 항목을 완료한 것이 아닙니다. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.
