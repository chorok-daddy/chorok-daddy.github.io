14주차 · 문장을 Tensor로 바꾸어 감정 분류하기 실습

아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 앞에서 비교한 세 조건을 정리하고 부족한 비교만 보충합니다.
  4. 실행 환경을 다시 시작하고 위에서부터 실행해 결과가 다시 나오는지 확인한 뒤 저장합니다.

1. 토큰과 vocabulary

길이가 다른 두 영어 문장을 Token → Index → PAD 순서로 출력하세요. 학습 사전에 없는 단어 하나를 넣고 UNK 위치를 확인하세요. 실제 단어를 뜻하는 Index와 PAD·UNK를 구별해 적으세요.

2. 마스킹한 평균과 학습

같은 문장을 혼자 처리할 때와 긴 문장과 묶을 때 Mask 적용 전후 평균을 비교하세요. 다른 문장 쌍으로 한 번 더 확인하고, 단어 순서를 바꾼 두 문장의 Logit도 비교하세요. 차이가 0에 가까운 이유를 설명하세요.

3. 새 문장 직접 입력

학습 사전의 단어로 긍정·중립·부정 영어 문장을 하나씩 my_reviews에 작성하세요. 의도한 감정·예측·Token을 기록하고, 모르는 단어나 문장부호를 하나 넣어 UNK 처리를 확인하세요. 예측이 의도와 달라도 원인을 설명하면 됩니다.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 기준 예제만 실행한 파일은 직접 수행 항목을 완료한 것이 아닙니다. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.
