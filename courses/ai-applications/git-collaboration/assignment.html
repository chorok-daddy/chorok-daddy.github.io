4주차 · 변경 이력을 남기며 협업하기 실습

아래 필수 활동을 약 60분 동안 수행하며, 막히는 부분은 조교의 도움을 받으세요.

진행 순서

  1. 기준 예제를 읽고 결과를 예상한 뒤 실행합니다.
  2. 각 항목의 직접 수행 문제를 풀고 조건·결과·이유를 기록합니다.
  3. 한 유형에서 세 가지 조건을 더 바꾸어 반복합니다.
  4. 본인 사본을 새 세션에서 검증하고 저장합니다.

1. 내 작업 공간에서 Git 연습하기

① 로컬 예제의 문장을 한 줄 수정하고 git diff→add→commit→log를 직접 반복하세요. ② GitHub에서 README를 포함한 개인 연습 Repository를 만드세요. ③ 새 Branch practice를 만들고 README에 이번 주 배운 내용을 추가하여 Commit하세요. ④ practice→main의 Pull Request를 열고 Files changed에서 변경을 검토한 뒤 Merge하세요. ⑤ 조교 또는 동료에게 두 Branch의 역할과 Merge 전후 차이를 설명하세요. ⑥ Repository URL, Commit 이력, PR 변경 내용과 Merge 완료 화면을 Notebook에 기록하세요. 40분 안에 마치면 선택: 동료의 연습 Repository를 Fork하고 한 줄 수정하여 원본으로 PR을 제안해 Collaborator 방식과 비교하세요.

제출·저장

코드, 실제 Output·그래프, 직접 작성한 해석을 포함하세요. 기준 예제만 실행한 파일은 직접 수행 항목을 완료한 것이 아닙니다. 제출은 KLAS를 이용하며 기한은 학기 일정과 최신 공지를 확인합니다.

GitHub 협업 결과는 저장소·Branch·PR의 변경 내용과 Merge 이력이 보이는 캡처로 남기세요. 인증 정보는 포함하지 않습니다. Notebook은 연습·기록용입니다.

선택 실습

시간이 남으면 작은 오류 사례를 만들고 원인과 수정 과정을 설명하세요. 추가 활동은 필수 60분 실습을 완료한 뒤 진행합니다.
