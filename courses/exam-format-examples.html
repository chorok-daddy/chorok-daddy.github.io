손답안형 시험 · 유형 예시

답안을 어떻게 작성하는지 보여 주는 공통 예시입니다. 시험 범위·실제 문항·난이도·배점의 예고가 아닙니다. 실제 시험과 다른 일상 소재를 사용하며, 여기서 필요한 규칙은 모두 제시합니다.

아래 코드는 특정 언어의 문법을 묻지 않는 의사코드입니다. ←는 오른쪽 계산 결과를 왼쪽 이름에 저장한다는 뜻입니다. 실제 시험에서는 해당 과목의 수식·코드와 제공 참고자료를 사용합니다.

예시 1 · 택배 요금 계산

주어진 정보: 상자 하나의 배송 요금은 기본요금 2,000원에 무게 1kg당 500원을 더합니다. 무게는 소수도 그대로 계산하며 반올림하지 않습니다. 포장비 300원은 배송 요금과 별도로 한 번 더합니다.

무게 ← 3
배송요금 ← 2000 + 500 × 무게
결제금액 ← ___A___
  1. 빈칸 A를 배송요금을 이용한 계산식으로 채우세요.
  2. 코드 실행 후 배송요금과 결제금액을 각각 쓰세요.
  3. 무게가 w kg일 때 결제금액을 나타내는 식을 쓰세요.
답과 설명

A: 배송요금 + 300. 배송요금은 3,500원, 결제금액은 3,800원입니다.

일반식은 c=2300+500w (원)입니다. 기본요금과 포장비는 한 번씩 더하고, 무게에 따라 달라지는 항만 w에 곱합니다.

이 예시는 주어진 규칙을 식으로 옮기고, 앞 계산 결과를 다음 계산에서 사용하는 답안 형태를 보여 줍니다.

예시 2 · 이름표 만들기

주어진 정보: 참석자 이름은 쉼표로 구분한 문자열입니다. 나누기(문자열, 구분자)는 구분자를 기준으로 문자열을 목록으로 나눕니다. 붙이기(앞, 뒤)는 두 문자열을 그대로 이어 붙입니다. 목록은 적힌 순서대로 처리하고, 추가는 목록의 맨 뒤에 값을 넣습니다.

참석자 ← "민수,지연,서준"
이름목록 ← 나누기(참석자, ",")
이름표 ← 빈 목록
이름목록의 각 이름에 대해:
    이름표에 붙이기(이름, " 님")을 추가
  1. 이름목록에 저장된 내용을 순서대로 쓰세요.
  2. 첫 두 이름을 처리한 직후 이름표에 저장된 내용을 쓰세요.
  3. 마지막 줄을 붙이기(" 님", 이름)으로 잘못 작성했습니다. 첫 번째 이름표는 어떻게 나오며, 어느 부분을 고쳐야 하나요?
답과 설명

이름목록: ["민수", "지연", "서준"]
두 이름 처리 후: ["민수 님", "지연 님"]

잘못된 첫 이름표는 " 님민수"입니다. 붙이기에 전달하는 두 값의 순서를 바꾸면 됩니다. 문자열 앞의 공백도 그대로 붙습니다.

이 예시는 중간 결과를 적고, 제공된 규칙을 근거로 잘못된 코드 한 부분을 찾는 답안 형태를 보여 줍니다.

예시 3 · 도서관 좌석 수의 변화

주어진 정보: 오전 9시에 사용 중인 좌석은 4개입니다. 10시에 2명이 들어와 각각 빈 좌석을 사용하고, 11시에 3명이 퇴실합니다. 12시까지 다른 출입은 없습니다. 출입은 해당 시각에 한꺼번에 일어나며 그 사이 좌석 수는 일정합니다.

  1. 9시, 10시 직후, 11시 직후, 12시에 사용 중인 좌석 수를 순서대로 쓰세요.
  2. 가로축을 시각, 세로축을 사용 중인 좌석 수로 하여 그래프를 그리세요. 값이 바뀌는 시각을 표시하세요.
  3. 누군가 각 시각의 점을 기울어진 직선으로 연결했습니다. 이 표현이 주어진 상황과 맞지 않는 이유를 한 문장으로 설명하세요.
답과 설명

좌석 수는 차례로 4, 6, 3, 3입니다. 출입 시각에만 값이 바뀌므로 수평 구간과 수직 변화로 표현합니다.

기울어진 직선은 출입 시각 사이에도 사용 좌석 수가 계속 변하는 것처럼 보이므로 조건과 맞지 않습니다.

이 예시는 계산한 값뿐 아니라, 조건에 맞는 그래프의 모양과 그 이유를 표현하는 답안 형태를 보여 줍니다.
